# 원본 수치 규칙 (원칙서)

원래 게임 데이터에서 추론한 규칙. 변경 항목은 `따르는 원칙` / `어기는 원칙`에 이 ID를 적는다.
- **확정**: 해당 영웅·기술 전원에서 예외 없이 또는 적힌 예외만 빼고 일치
- **경향**: 상관관계 수준. 공식이 아니라 제작자가 손으로 정한 값의 흐름

모드는 이 규칙을 기본적으로 유지한다(intent.md P-03).

## 전투 기본

- **R-CMB-01 명중 판정 (확정)**: 명중률 = 기술 명중 − 대상 회피, 0~95% 범위로 자름.
- **R-CMB-02 치명타 (확정)**: 치명타 피해 ×1.5.
- **R-CMB-03 효과 적용 (확정)**: 적용 확률 = 효과 확률 − 대상 저항.
- **R-CMB-04 명중·회피 대칭 성장 (확정, 상세: `analysis/accuracy.md`)**: 몬스터 회피는 던전 레벨별 고정 가산이다. 견습→베테랑 +8.75, 베테랑→영웅 +11.25~13.75, 견습→영웅 합계 +20~22.5. 실제 전투 몬스터 91종 전원에 적용되고, 시체·석상 같은 오브젝트 12종만 0이다. 영웅 기술 명중은 1→5레벨 +20. 반대로 몬스터 명중 +20, 영웅 회피 1→5레벨 +20. 레벨이 맞으면 양쪽 평균 명중률이 거의 그대로 유지되도록 설계됨(영웅→몬스터 약 83%→82%, 몬스터→영웅 77.5%→77.5%).
- **R-CMB-05 저항·효과 확률 대칭 성장 (확정)**: 같은 몬스터의 견습→영웅 저항 중앙 +40(기절·중독·출혈·약화·이동), 영웅 효과 확률 1→5레벨 +40%p. 레벨이 맞으면 적용 확률이 그대로(기절 예: 약 50%).
- **R-CMB-06 명중 공급원 (확정)**: 영웅 명중은 기술 레벨(+5/레벨) 외에 기본 성장으로 오르지 않는다(무기 명중 0, 레벨 보너스 없음). 추가 명중은 장신구·기벽·버프뿐. 어둠(횃불 50 미만)은 몬스터 명중만 +5~+12.5 올린다(`shared/rules.json` darkness).
- **R-CMB-07 몬스터 명중 성장 (확정, 상세: `analysis/accuracy_laws.md`)**: 같은 기술이 견습→베테랑 +6.25(202개), 베테랑→영웅 +13.75(183개), 합계 +20. 몬스터 명중 값은 대부분 끝자리 .5(82.5·92.5·102.5). 레벨이 맞는 영웅 기준 명중 여유는 베테랑 +1.25 / 영웅 −1.25, 회피 여유는 베테랑 +3.75 / 영웅 0 → 확률로는 베테랑 던전이 영웅에게 가장 유리하다.

## 장비 성장 (레벨 n = 1~5, 반올림)

- **R-GROW-01 무기 피해 성장 (확정, 예외 있음)**
  - 공식: 최소/최대 피해(n) = 반올림(1레벨 값 × (1 + r × (n−1)))
  - 최대 피해 r = 15% ⟺ 매혹 시 열 = 1. 기본 영웅 15명 전원 일치.
  - 최소 피해 r = 15% ⟺ 헤비 태그 이면서 매혹 시 열 = 1. 기본 영웅 15명 전원 일치.
  - 그 외 r = 20%.
  - 현재 값: 15/15 나병환자·성전사·야만인·중보병·현상금 사냥꾼, 최소 20/최대 15 노상강도, 최소 15/최대 20 결투가, 나머지 20/20.
  - 예외: **고행자**(매혹 시 1열인데 최소·최대 모두 20%), **결투가**(매혹 시 3열·라이트인데 최소 15%. 반격 보유로 설명 가능: 반격 영웅 4명 전원 한쪽 이상 15%).
  - 참고: 매혹 시 열(`controlled: .target_rank`)은 세이렌의 "욕망의 노래"에 매혹됐을 때 서는 열이며 UI에 표시되지 않는다.
- **R-GROW-02 최대 체력 성장 (확정)**: 최대 체력(n) = 1레벨 값 + (n−1) × 반올림(1레벨 값 × 0.2).
- **R-GROW-03 회피·치명타·속도 성장 (확정, 예외 있음)**
  - 회피 +5/레벨, 치명타 +1/레벨.
  - 속도 = 1레벨 값 + 내림((n−1)/2) → +0/+0/+1/+1/+2.
  - 예외: 고행자 속도 6/6/8/8/9, 방패 파괴자 속도 5/6/8/8/9. 방패 파괴자 회피 1레벨 8(5 단위가 아님).
- **R-GROW-04 고정값 (확정)**: 무기 명중 보정, 방어, 갑옷 속도는 전 영웅 0.
- R-GROW-01~04를 전부 따르는 영웅: 20명 중 17명. 벗어나는 3명은 모두 DLC(고행자·방패 파괴자·결투가).

## 기본 능력치

- **R-PRESET-01 기본 피해 조합 (확정)**
  - 2명 이상이 쓰는 조합: 6-12(성전사·야만인), 5-10(방패 파괴자·현상금 사냥꾼·노상강도), 4-8(총사·석궁사수·성녀·도굴꾼), 4-7(도망자·조련사·광대·신비학자·역병 의사).
  - 한 명만 쓰는 조합: 8-16 나병환자, 6-11 괴인, 5-9 중보병, 5-7 결투가, 3-6 고행자, 3-5 유물수집상.
- **R-BASE-01 체력·속도·피해 (경향)**: 공식은 없다. 체력↔속도 −0.78(순위 상관 −0.73, 체력 약 3.4당 속도 −1, DLC 5명도 −0.85로 같은 경향), 체력↔평균 피해 +0.76. 체력을 고정하면 비피해 기술 수↔피해 −0.60(1개당 평균 피해 약 −0.58).
- **R-BASE-02 치명타 (경향)**: 공격 기술 비중과 +0.56, 종교 태그와 −0.55.
- **R-BASE-03 영웅 회피 (확정/경향)**: 1레벨 0/5/10이 기본(예외: 괴인 7.5, 방패 파괴자 8, 광대 15), 장비 레벨당 +5(80/80). 체력과 −0.50, 속도와 +0.42.

## 저항

- **R-RES-01 저항 배분 (확정/경향)**
  - 기본 30, ±10 단위.
  - 기절 = 이동: 20명 중 19명(도망자만 20/30).
  - 죽음의 일격 67(고행자만 73).
  - 튀는 저항은 다른 저항에서 41%만 되돌려 받는다(부분 상쇄).
  - 기본 능력치와는 상쇄 관계가 없다(−0.07).

## 기술 레벨 성장

- **R-SKILL-01 명중 +5/레벨 (확정)**: 104/104.
- **R-SKILL-02 치명타 보정 +1/레벨 (확정)**: 84개 일치, 19개는 0 고정. 예외: 노상강도 추적탄 0/0/0.5/0.5/1.
- **R-SKILL-03 피해 보정 레벨 불변 (확정)**: 예외: 나병환자 위협 −85→−80.
- **R-SKILL-04 레벨 불변 항목 (확정)**: 사용 열, 대상, 이동, 사용 제한.
- **R-SKILL-05 효과 성장 (확정/경향)**: 효과 확률 +10%p/레벨. 효과 크기는 1레벨→5레벨 직선이며 대부분 내림(효과 수열의 약 93%).
- **R-SKILL-06 성장하지 않는 효과 (확정)**: 표식, 보호, 반격, 상태 치료, 은신 해제, 자기 약화 비용.
- **R-SKILL-07 업그레이드 비용 (확정)**: 모든 기술의 업그레이드 비용이 같다.
- **R-SKILL-08 명중 상한 (확정)**: 명중 − 회피가 95를 넘는 부분은 낭비. 예: 광대 대단원 5레벨 140, 독주 125는 영웅 던전 몬스터 상대로도 +20이 전부 낭비.
- **R-SKILL-09 기술 기본 명중 (확정/경향, 상세: `analysis/accuracy_baseline.md`)**
  - 근접 단일 순수 피해 85 (20개 중 12개). 근접에 기절·약화·표식이 붙으면 90~95.
  - 근접 광역 90. 원거리는 85/90/95로 갈려 단일 기준이 없다(최빈 95, 중앙 90).
  - 피해 없는 약화 95, 표식 100, 무작위 대상 75.
  - 영웅 성향: 광대 +19, 결투가·고행자 +6.7, 성녀 −6.
- **R-SKILL-10 명중 결정 요인 (경향, 회귀 설명력 0.55, 상세: `analysis/accuracy_laws.md`)**
  - 명중 값은 전부 5의 배수. 기본 85.7(근접·피해 있음·효과 없음).
  - 가산: 피해 없음 +6, 기절 +3.9, 표식 +3.8, 약화 +3.6, 원거리 +2.6, DLC +2.4, 무작위 대상 −12.
  - 근접은 명중 +5 ≈ 피해 보정 약 −12%p. 치명타 보정과는 무관.
  - 무기 피해가 높은 영웅일수록 기술 명중이 낮다(−0.58).
  - 해석 기준: 기본 영웅만으로 학습한 모델에서 명중 ≈ 91.8 − 0.77 × 무기 평균 피해 + 효과 가산 − 대상 열당 1.0, 잔차 표준편차 3.7이다. ±4 안은 정상 범위. 명중은 피해 보정과 한 묶음 예산으로 본다(명중 1 ≈ 피해 보정 2.4%p, `analysis/accuracy_budget.md`).
- 명중+치명타만 성장하는 기술 17개(+명중만 1개): 순수 피해 기술은 무기 성장으로 강해진다는 원래 설계.

## 기술 가격표

- **R-TRADE-01 피해 보정 가격 (경향, 회귀 설명력 0.69)**
  - 기준: 근접 단일 = 피해 보정 0 / 명중 85 / 치명타 +4.
  - 특징 하나당 피해 보정 변화:

| 특징 | 피해 보정 |
|---|---|
| 기절 | −50%p |
| 반격 | −47%p (표본 2) |
| 적 표식 | −45%p |
| 추가 대상 1명 | −24%p |
| 약화 1개 | −19%p |
| 자기 강화 | −19%p |
| 원거리 | −12%p |
| 밀치기/당기기 | −9%p |
| 사용 열 1개 늘 때마다 | −5%p |
| 지속 피해 총량 1 | −1.9%p |
| 조건부 추가 피해 | +3 (사실상 공짜) |
| 자기 이동 | +17%p |
| 자기 약화 비용 | +26%p |

  - 유형별 중앙값(피해 보정 / 명중 / 치명타): 원거리 단일 −50/90/+5, 원거리 광역 −55/92.5/−4.5, 근접 광역 −50/90/−1.
  - 피해 없는 공격 기술의 명중은 95~100.

## 회복

- **R-HEAL-01 회복 성장 구조 (확정, 상세: `analysis/heal.md`)**
  - 고정량 체력 회복은 1→5레벨 약 ×1.7~2.2. 영웅 최대 체력(×1.8), 몬스터 피해(견습→영웅 ×1.86)와 비슷하게 성장한다.
  - 스트레스 회복은 ×1.4~1.6(광역 확률형은 더 큼). 몬스터 스트레스 피해는 레벨이 올라도 거의 그대로(×1.0)다.
  - 고행자 구제·방혈은 최대 체력 비율 회복이라 체력 성장이 자동 반영된다.

## 원칙 이탈 목록 (G-04 등 검토 후보)

특수 메커니즘은 모델에 반영되지 않았으므로 **검토 후보**일 뿐 확정 판정이 아니다.

- **장비 성장 예외**: 고행자(피해 성장률·속도), 방패 파괴자(속도·회피 기본값), 결투가(최소 피해).
- **성장 가치**(같은 상대 기준 1→5레벨 강해지는 정도)
  - 이득: 신비학자 +14%, 도망자 +12%, 방패 파괴자 +10%
  - 손해: 나병환자 −8%, 중보병 −8%, 석궁사수·총사·고행자 −7%
- **기술 가격표 대비 과대(피해 보정이 너무 높음)**: 노상강도 영거리 사격 +51, 고행자 처벌 +45, 노상강도 정맥 절개 +43, 석궁사수·총사 무차별 사격 +36, 노상강도 포도탄 +33, 도굴꾼 번뜩이는 비도 +31, 조련사 사냥개 습격 +29, 도굴꾼 단검 투척 +27.
- **기술 가격표 대비 과소**: 결투가 회수 −45, 야만인 돌파 −37, 결투가 최후의 일격 −37, 성녀 광휘 −35, 도망자 불길 역류 −30, 역병 의사 역병 수류탄 −29, 노상강도 추적탄 −28, 괴인 할퀴기 −26.
- **성장 없는 효과가 핵심인 기술**: 표식·보호·반격 지속 시간 고정 → 레벨업 가치가 명중/치명타뿐.
- **패치 이력**: `analysis/dlc_history.md`.
