# 원본 수치 규칙 (원칙서)

원래 게임 데이터에서 추론한 규칙. 변경 항목은 `따르는 원칙` / `어기는 원칙`에 이 ID를 적는다.
- **확정**: 해당 영웅·기술 전원에서 예외 없이 또는 적힌 예외만 빼고 일치
- **경향**: 상관관계 수준. 공식이 아니라 제작자가 손으로 정한 값의 흐름

모드는 이 규칙을 기본적으로 유지한다(intent.md P-03).

## 표기 규칙 [사용자 지정 2026-09-27]

- **명중·치명타 보정은 항상 1레벨 값으로 적는다.** 과거 문서·현재 작업·앞으로의 모든 제안에 동일하게 적용한다.
  - 5레벨 값이 필요하면 **1레벨 + 20**(명중), **1레벨 + 4**(기술 치명타 보정)으로 환산한다. 둘 다 레벨당 +5 / +1로 고정이다(R-SKILL-01·02).
  - 실제 치명타는 **무기 치명타 + 기술 보정**이므로, 기술 보정만 적을 때는 "보정"임을 명시한다.
  - **피해 보정·효과 수치는 레벨마다 다르므로 5레벨 값을 쓰되 레벨을 명시한다.**
- 2026-09-27 이전 문서에는 5레벨 명중으로 적힌 표가 남아 있다. 확인할 때는 **−20**을 적용한다.
## 전투 기본

- **R-CMB-01 명중 판정 (확정)**: 명중률 = 기술 명중 − 대상 회피, 0~95% 범위로 자름.
- **R-CMB-02 치명타 (확정)**: 치명타 피해 ×1.5.
- **R-CMB-08 치명타가 일으키는 효과 전부 (핵심 원칙, 확정 — 제작자 플레이 경험으로 전항목 확인 2026-09-27)**
  치명타는 피해 배율이 아니라 **복합 능력치**다. 아래를 전부 동시에 올린다. 표면상 기대 피해만 계산하면 치명타 가치는 크게 과소평가된다.

| 항목 | 치명타 시 | 검증 |
|---|---|---|
| 직접 피해 | **최대 피해 × 1.5** (굴린 값 ×1.5가 아니다). 무기 8-16이면 평균 12 → 치명타 24 | 배율 1.5는 `shared/rules.json` `player_crit_multiplier_table`. "최대값 기준"은 제작자 확인 |
| 기절 적용 확률 | **+20%p** (140 − 저항 90 = 50% → 70%) | `effect_crit_roll_mod -0.2` |
| 밀치기·당기기 확률 | **+20%p** | 같음 |
| 약화 적용 확률 | **+20%p** | 같음 |
| 출혈·중독 적용 확률 | **+20%p** | 같음 |
| **출혈·중독 지속** | **×1.5 올림** (1→2, 2→3, **3→5**, 4→6). 턴당 피해는 그대로 | 제작자 게임 내 확인. 데이터에 없어 엔진 하드코딩 |
| 기절 지속 / 이동 칸수 / 약화 수치·지속 | **변화 없음** | |
| 치명타로 처치 | **시체가 남지 않는다** | `death_class .is_valid_on_crit False` |
| 영웅이 치명타를 냈을 때 스트레스 | 본인 **−3 확정**, 다른 아군 각각 **25%로 −3** | `player_crit` |
| 영웅이 치명타를 맞았을 때 | 본인 **+10**, 다른 파티원 각각 **50%로 +5** | `monster_crit` |
| 광역기에서 여러 명에게 치명타 | 스트레스 회복·직업 버프는 **1회만** 발동 | 제작자 확인 |

  - **직업별 치명타 버프** (`on_crit_*`, 지속 2턴 / 스트레스 계열 3턴). 영웅 파일 참조를 전수 확인했다.

| 버프 | 영웅 |
|---|---|
| 표식 대상 피해 +33% | 석궁사수, **현상금 사냥꾼**, 총사 |
| 출혈 대상 피해 +33% | 야만인 |
| 피해 +20% | 괴인 |
| 출혈 확률 +20 | 고행자, 조련사 |
| 중독 확률 +20 | 역병 의사 |
| 회복량 +25% | 신비학자, 성녀 |
| 스트레스 회복 +40% | 광대 |
| 방어도 +15% | 성전사, 방패 파괴자 |
| 회피 +10 | 유물수집상, 도굴꾼 |
| 속도 +2 | 노상강도, 도망자 |
| 명중 +10 | 나병환자 |
| 받는 스트레스 −33% | 중보병 |
| (결투가 전용 회피 버프) | 결투가 |

  - **회복 치명타는 별도 계통**이다. 회복량 ×2 + 대상 스트레스 −4. 공격 치명타율을 올려도 오르지 않고, 회복 기술에 고정 확률이 있다(단일 12%, 광역 각 5%). **미검증**.
  - **미해결**: `excessCritMult 0.0` / `excessCritMax 0.20`의 의미. 치명타율 초과분 처리로 보이나 우리 수치대(11~26%)에서는 무관할 가능성이 높다.

  - **가격 환산 (개정)**: 치명타 보정 1점의 값은 **약 `(1 + 피해보정) + 0.1(효과 확률) + 0.3(스트레스·직업 버프)` %p**다.
    - 피해 보정 0%인 기술: 약 **1.4%p** / −40%: 약 **1.0%p** / −67%: 약 **0.75%p**
    - 지속 피해를 거는 기술은 지속 ×1.5가 더해져 **+0.2%p 내외**가 추가된다.
    - **이전에 쓰던 0.5%p는 약 2배 과소평가였다.** 원인은 ① 치명타 피해가 최대값 기준이라 실제 배율이 ×2에 가깝고 ② 스트레스 회복·직업 버프·시체 제거를 빼먹었기 때문이다.
  - **모드 적용**
    1. 치명타는 **피해 보정이 얕은 기술에 줘야 값어치가 난다.** 피해를 −67%까지 깎아놓은 기술에 치명타를 올리는 건 낭비다(BH-007 검토 근거).
    2. 지속 피해 기술의 치명타를 올리는 것은 **피해·지속 피해 동시 상향**이다(HEL-003).
    3. 직업 버프와 기술이 맞물리는 영웅(표식 3인방, 야만인, 역병 의사, 고행자·조련사)은 치명타의 실효가 더 크다.
- **R-CMB-03 효과 적용 (확정)**: 적용 확률 = 효과 확률 − 대상 저항.
- **R-CMB-04 명중·회피 대칭 성장 (확정, 상세: `analysis/accuracy.md`)**: 몬스터 회피는 던전 레벨별 고정 가산이다. 견습→베테랑 +8.75, 베테랑→영웅 +11.25~13.75, 견습→영웅 합계 +20~22.5. 실제 전투 몬스터 91종 전원에 적용되고, 시체·석상 같은 오브젝트 12종만 0이다. 영웅 기술 명중은 1→5레벨 +20. 반대로 몬스터 명중 +20, 영웅 회피 1→5레벨 +20. 레벨이 맞으면 양쪽 평균 명중률이 거의 그대로 유지되도록 설계됨(영웅→몬스터 약 83%→82%, 몬스터→영웅 77.5%→77.5%).
- **R-CMB-05 저항·효과 확률 대칭 성장 (확정)**: 같은 몬스터의 견습→영웅 저항 중앙 +40(기절·중독·출혈·약화·이동), 영웅 효과 확률 1→5레벨 +40%p. 레벨이 맞으면 적용 확률이 그대로(기절 예: 약 50%).
- **R-CMB-06 명중 공급원 (확정)**: 영웅 명중은 기술 레벨(+5/레벨) 외에 기본 성장으로 오르지 않는다(무기 명중 0, 레벨 보너스 없음). 추가 명중은 장신구·기벽·버프뿐. 어둠(횃불 50 미만)은 몬스터 명중만 +5~+12.5 올린다(`shared/rules.json` darkness).
- **R-CMB-07 몬스터 명중 성장 (확정, 상세: `analysis/accuracy_laws.md`)**: 같은 기술이 견습→베테랑 +6.25(202개), 베테랑→영웅 +13.75(183개), 합계 +20. 몬스터 명중 값은 대부분 끝자리 .5(82.5·92.5·102.5). 레벨이 맞는 영웅 기준 명중 여유는 베테랑 +1.25 / 영웅 −1.25, 회피 여유는 베테랑 +3.75 / 영웅 0 → 확률로는 베테랑 던전이 영웅에게 가장 유리하다.

## 장비 성장 (레벨 n = 1~5, 반올림)

- **R-GROW-01 무기 피해 성장 (확정, 예외 있음)**
  - 공식: 최소/최대 피해(n) = 반올림(1레벨 값 × (1 + r × (n−1)))
  - 최대 피해 r = 15% ⟺ 매혹 시 열 = 1. 기본 영웅 15명 전원 일치.
  - 최소 피해 r = 15% ⟺ 헤비 태그 이면서 매혹 시 열 = 1. 기본 영웅 15명 전원 일치.
  - 그 외 r = 20%.
  - 현재 값: 15/15 나병환자·성전사·야만인·중보병·현상금 사냥꾼, 최소 20/최대 15 노상강도, 최소 15/최대 20 결투가, 나머지 20/20.
  - 예외: **고행자**(매혹 시 1열인데 최소·최대 모두 20%), **결투가**(매혹 시 3열·라이트인데 최소 15%. 반격 보유로 설명 가능: 반격 영웅 4명 전원 한쪽 이상 15%).
  - 참고: 매혹 시 열(`controlled: .target_rank`)은 세이렌의 "욕망의 노래"에 매혹됐을 때 서는 열이며 UI에 표시되지 않는다.
- **R-GROW-02 최대 체력 성장 (확정)**: 최대 체력(n) = 1레벨 값 + (n−1) × 반올림(1레벨 값 × 0.2).
- **R-GROW-03 회피·치명타·속도 성장 (확정, 예외 있음)**
  - 회피 +5/레벨, 치명타 +1/레벨.
  - 속도 = 1레벨 값 + 내림((n−1)/2) → +0/+0/+1/+1/+2.
  - 예외: 고행자 속도 6/6/8/8/9, 방패 파괴자 속도 5/6/8/8/9. 방패 파괴자 회피 1레벨 8(5 단위가 아님).
- **R-GROW-04 고정값 (확정)**: 무기 명중 보정, 방어, 갑옷 속도는 전 영웅 0.
- R-GROW-01~04를 전부 따르는 영웅: 20명 중 17명. 벗어나는 3명은 모두 DLC(고행자·방패 파괴자·결투가).

## 기본 능력치

- **R-PRESET-01 기본 피해 조합 (확정)**

- **R-BASE-01 체력·속도·피해 (경향)**: 공식은 없다. 체력↔속도 −0.78(순위 상관 −0.73, 체력 약 3.4당 속도 −1, DLC 5명도 −0.85로 같은 경향), 체력↔평균 피해 +0.76. 체력을 고정하면 비피해 기술 수↔피해 −0.60(1개당 평균 피해 약 −0.58).
- **R-BASE-02 치명타 (경향)**: 공격 기술 비중과 +0.56, 종교 태그와 −0.55.
- **R-HERO-01 영웅 주 열 (산출 규칙, 상세: `analysis/hero_ranks.md`)**: 영웅 기술 7개의 사용 열 개수를 세어, 최다 −1 이상인 열을 주 열로 본다. 기술 분석에서 "주 열에서 쓸 수 있는 열" = 사용 열 ∩ 주 열.
- **R-BASE-03 영웅 회피 (확정/경향)**: 1레벨 0/5/10이 기본(예외: 괴인 7.5, 방패 파괴자 8, 광대 15), 장비 레벨당 +5(80/80). 체력과 −0.50, 속도와 +0.42.

## 저항

- **R-RES-01 저항 배분 (확정/경향)**
  - 기본 30, ±10 단위.
  - 기절 = 이동: 20명 중 19명(도망자만 20/30).
  - 죽음의 일격 67(고행자만 73).
  - 튀는 저항은 다른 저항에서 41%만 되돌려 받는다(부분 상쇄).

## 열 배치

- **R-RANK-01 이동기와 열 붙박이 (핵심 원칙 [사용자 지정 2026-09-27])**
  - **이동기 자체는 패널티가 아니다.** 적의 열 섞임 공격에 **턴을 허비하지 않고** 대처하게 해주므로 오히려 이득이다. 모든 영웅이 이동기를 하나씩 갖추면 파티 전체가 열 섞임에 유동적으로 대처하는 플러스가 된다.
  - **거의 모든 영웅은 선호 열이 있고, 그 열에서 쓰는 붙박이 기술이 좋다.** 이게 기본 설계다.
  - **최적 구성**: 붙박이 기술 3 + 이동 기술 1. 붙박이가 3·4열이면 후방 이동기, 1·2열이면 전방 이동기.
  - **이동 강제 설계 [사용자]**: 어떤 영웅은 **붙박이 기술 자체가 약하게 설계되고 좋은 기술이 전부 이동기**다. 기술 다양성·유동성을 쓰려면 필연적으로 자기 열을 흔들게 된다.
    - **이게 팀 단위 패널티다.** 이동이 강제되는 영웅은 **붙박이 영웅과 같이 쓰면 팀에 손해**다. 열이 계속 흔들려 붙박이 영웅이 제 열을 못 지키기 때문이다.
    - **방패 파괴자가 이 설계다.** 7기술 중 **6개가 자기 이동**(휘감기만 없음)이고, 붙박이 기술의 효율은 의도적으로 낮다.
  - **우회법 [사용자]**: 이 강제를 씹는 방법이 있고, 실제로 그게 가장 센 운용이다.
    1. **1열에서 전방 이동기만 쓴다.** 1열에서는 앞으로 갈 곳이 없어 이동이 무효화된다. 방패 파괴자 찌르기(`.move 0 1`, 대상 1~4열, 방어 관통)와 뱀의 형상(`.move 0 1`, 자기 강화)을 1열에서 반복하는 것이 그 예다.
    2. **후방 이동기 1개만 섞어 1·2열만 왕복한다.** 1·2열 호환 영웅이 많아 파티가 감당할 수 있다.
  - **가격표와의 충돌**: R-TRADE-01 회귀에서 자기 이동 계수는 +17~+24%p(= 부담)로 나온다. **그건 바닐라가 매긴 값일 뿐 실제 가치가 아니다.** 열 섞임 대처 가치를 계산에 넣지 않은 결과다.
  - **모드 적용**
    1. 자기 이동이 붙은 기술을 "대가를 치렀다"고 보고 상향하지 않는다.
    2. **판정은 기술 단위가 아니라 영웅의 붙박이/이동 구성 단위로 한다.** 붙박이 기술만으로 성립하는 영웅인지, 이동이 강제되는 영웅인지 먼저 본다.
    3. 이동 강제 영웅을 조정할 때는 **1열(또는 4열) 고정 우회법이 열리는지** 함께 본다. 그 우회법이 실제 최적해가 되면 의도한 패널티가 무력화된다.

  - 표본: 단일 대상이며 적에게는 피해만 주는 딜링기. 자기 이동·자기 강화·조건부 추가 피해는 허용했다. 근접 21개, 원거리 9개.
  - **기본 명중은 근접·원거리 모두 1레벨 85(중앙값)다.** 사거리를 명중으로 사고팔지 않는다.
  - **명중 +5 = 피해 보정 10%p** [사용자 확정 2026-09-26]. 아래 세 값을 놓고 제작자가 택했다.

| 값 | 정체 | 산출 |
|---|---|---|
| 2.2%p | **바닐라가 실제로 매긴 가격** | 5레벨 공격 기술 131개 회귀. 다른 특징을 전부 통제하면 명중 1당 −0.43%p. 통제를 빼도 −0.42로 같다 |
| 7.0%p | **기댓값 계산** | 명중 +5 = 적중률 85→90 = 기술 전체 ×1.0588. 피해 보정으로 같은 폭을 내려면 Δm = 0.0588 × (피해분 + 효과분). 기절 기술 12개 평균 7.0 |
| **10%p** | **채택값** | 위 기댓값의 상황 상한. 적중률이 낮을수록 값이 커져 65%→70%에서 8.6, 55%→60%에서 10.2%p가 된다 |

    - 10을 택한 이유 [사용자]: 빗나가면 기댓값이 비례해서 주는 게 아니라 **턴 하나가 통째로 날아간다**. 한 전투가 4영웅 × 4라운드 ≈ 16행동이라 미스 하나의 템포 손실이 기댓값보다 크다. 바닐라 가격(2.2)은 저평가로 본다.
    - 제 계산 오류 정정(2026-09-26): 처음에 2.9%p로 계산했던 것은 **피해분만 환산하고 효과분을 빼먹은 것**이다. 명중은 기절·출혈·약화 적용 확률까지 같이 올린다.
    - 옛 서술 "명중 +5 ↔ −10~−20%p"는 **명중과 사거리를 한 덩어리로 본 값**이었다. 회귀가 둘을 분리하면 명중 −2.2 + 원거리 −17.7 = −19.9로, 그 −10~−20의 거의 전부가 사거리 값이다.
  - **원거리(사거리) = 피해 보정 −18%p** (회귀 −17.71). 명중이 아니라 도달 범위의 값이다.
  - **원거리는 사거리의 대가를 피해로 낸다.** 딜링기 피해 보정 중앙값은 근접 0, 원거리 −10이다. 효과가 붙은 기술까지 포함한 원거리 단일 전체는 −50이다.
  - **영웅 능력치에서도 대가를 낸다.**
    - 원거리 위주 영웅(공격 기술 50% 이상이 원거리) 12명은 근접 위주 8명보다 5레벨 무기 −2.3(10.6 vs 12.9), 체력 −7.5(40.0 vs 47.5)다.
    - 무기가 강한 영웅(5레벨 평균 13.5 이상)의 기술은 가격표 차이 평균 −6.7로, 피해 보정이 낮게 매겨졌다.
  - **효과는 명중을 사고 피해를 크게 낸다.** 원거리 단일 효과 기술은 명중 평균 92, 피해 보정 평균 −71이다.
  - **예외 (모두 가격표 과대)**
    - 석궁사수 무차별 사격 / 총사 권총사격: 무작위 대상이라 명중 75, 피해 −10에 속도 +5까지. +35.7
    - 도굴꾼 단검 투척: 명중 90 + 자기 명중 +10, 피해 −10. +27.3
    - 석궁사수 저격 / 총사 조준사격: 명중 95, 피해 0. 표식 준비 턴이 대가. +12.7
    - 조련사 사냥개 돌진: 원거리, 1~4열, 피해 0, 출혈. +23.8. 무기가 약해(5레벨 10) 일부 상쇄되어, 실제 기대 피해 8.2는 노상강도 권총 사격 8.8·방패 파괴자 휘감기 8.4 수준이다.
  - **모드 적용:** 명중·피해·사거리를 바꾸는 변경은 이 교환을 따른다(P-10). 어길 때는 변경 항목에 대가를 적는다. 원거리를 일괄 조정하지 않고 예외 기술을 조정한다.
