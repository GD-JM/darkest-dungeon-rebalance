[h1]Rebalance (Verified)[/h1]
Hero rebalance where every change fixes a problem found in the game data and cites the principles below. Trinkets and shared vanilla files are untouched. Values are level 1 unless noted.

[h2]Principles[/h2]
[b]Goals[/b] G-00 many parties can be right · G-01/02 every hero and skill has a use · G-03 useful off-rank options that don't replace the main rank · G-04 outliers back to base-game rules · G-05 spread healing and stress relief
[b]Design[/b] P-01/03/09 change only confirmed problems, with reasons · P-05 off-rank never beats main rank · P-06/07 respect official nerfs; overshot buffs may return to launch values · P-10 accuracy/damage/reach changes follow R-TRADE-02 · P-11 buffs and nerfs are paired; total power stays · P-12 keep the feel · P-14 no copying another hero's signature · P-19 art and name match function · P-20 trinkets fixed, so effects they boost stay · P-21 crit is a tuning tool unless part of a combo · P-22 stay in official lore · P-23 Abomination: human form less accuracy, more output · P-24 Houndmaster: less damage, more utility · P-25 Antiquarian weak by design (paid in gold) · P-26 more heroes for mark parties
[b]Number rules[/b] R-STRAT-01 win on action economy: kill fast, then stun · R-TRADE-02 +5 accuracy ≈ −10% damage; reach costs damage · R-SKILL-09 base accuracy 85 plain melee, 90–95 effect skills · R-SKILL-05 effects grow each level · R-EFF-02 DoTs last 3 turns · R-STUN-01/03 damaging stun = acc 90, normal stun · R-STUN-02 stuns reaching rank 3 deal low damage · R-CMB-01 hit = accuracy − dodge (max 95) · R-VALUE-03 AoE DoT is worth less than it looks · R-RANK-01 movement isn't a cost; rank-locking is · R-RES-01 resists at baseline unless lore says otherwise · R-GROW-01/03, R-PRESET-01 standard weapon presets and growth

[h2]Compatibility[/h2]
Overrides only the listed heroes' hero files and adds one effect file and one buff file. Conflicts with mods that replace the same hero files. Safe on existing saves.
