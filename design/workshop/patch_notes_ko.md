# 리밸런스 — 패치 노트

항목마다: 무엇이 바뀌었나(게임 데이터에서 자동 생성) — 왜(설명문의 원칙 번호).

## 괴인

- **변신**: 아군 전체: 스트레스 +8; 아군 전체: 스트레스 회복 2 → 1렙 아군 전체: 스트레스 +6; 자신: 스트레스 회복 4; 아군 전체: 스트레스 회복 3 … 5렙 아군 전체: 스트레스 +6; 자신: 스트레스 회복 8; 아군 전체: 스트레스 회복 3 — 변신의 스트레스 대가가 이득에 비해 커서 거의 아무도 변신하지 않았다. 이제 풀어놓으면 괴인 자신의 스트레스가 풀리고 동료는 조금 줄어든 공포를 부담하며, 다시 묶으면 동료가 조금 더 안도한다 — 변신이 '스트레스를 누가 질지' 고르는 선택이 된다. *(P-23, G-02, P-22 / ABO-004)*
- **사슬질**: 명중 95% → 90% — 인간 형태 명중을 변신 기술(85~90) 쪽으로 낮춰 변신을 막던 명중 격차를 줄인다. 90은 피해 있는 기절의 기준 명중이기도 하다. 괴인 무기가 커서 피해는 그대로도 기절 기술 중 높은 편이라 손대지 않았다. *(P-23, R-STUN-03 / ABO-005, ABO-006)*
- **아수의 담즙**: 명중 95% → 90%; 피해 -90% → -75% — 같은 2·3열 광역 지속 피해인 광대 수확과 지속 피해량은 이미 비슷했고 직접 피해만 크게 뒤처져 피해를 올렸다. 명중 −5는 그 상향의 대가이자 인간 형태 방향(명중↓ 기본 성능↑)과 같다. *(P-23, G-02, P-11 / ABO-002, ABO-007)*
- **박치기**: 명중 80% → 90%; 피해 -25% → 0%; 사용 열 3·2·1 → 4·3·2; 제거: 1렙 회피 -10%, 속도 -2 3턴 … 5렙 회피 -20%, 속도 -6 (140%) 3턴 — 야수는 4열에서 쓸 기술이 없어 열이 섞이면 한 턴을 통째로 날렸다. 이제 뒤에서 박고 앞으로 나온다. 약화를 빼고 명중·피해를 올려, 분노(3열 도달·높은 치명타)와 구분되는 '1·2열을 확실히 맞히는 밀치기'로 역할을 나눴다. *(G-03, P-19, G-02 / ABO-001, ABO-003)*
- **짐승 형태**: 짐승 형태 턴당 스트레스 6 → 4 — 야수 형태를 유지하면 여전히 매 턴 스트레스가 쌓이지만 덜 쌓여, 변신 후 몇 턴은 야수로 버틸 수 있다. *(P-23, P-12 / ABO-004)*

## 유물수집상

- **섬광 가루**: 추가: 1렙 화상 1 … 5렙 화상 3 — 기술 연출이 불꽃 분출이라 화상을 준다. 화상을 거는 영웅이 도망자뿐이었는데, 이제 다른 영웅도 도망자의 화상 연계 기술을 열 수 있다. 유물수집상은 전투 성능이 다른 영웅보다 낮은 컨셉(대신 돈을 번다)이라 화상량은 작게 뒀다. *(P-19, P-25 / ANT-001)*

## 석궁사수

- **저격**: 치명 보정 5% → 6%; 1렙 표식 대상: 피해 +50%, 치명타 +9% 3턴 … 5렙 변화 없음 → 1렙 표식 대상: 피해 +60%, 치명타 +9% 3턴 … 5렙 변화 없음 — 표식 피해를 여러 영웅에 재배분하면서(조련사 하향, 다른 표식 딜러 상향) 저격의 저레벨 표식 보너스를 올리고 5렙 상한은 그대로 뒀다. 치명타 상향은 1렙 저격이 성녀 심판과 같은 피해라 약하게 느껴졌기 때문이며, 정밀 사격이라 치명타가 어울린다. *(P-26, P-21, P-11 / ARB-005, ARB-012)*
- **제압 사격**: 피해 -80% → -60% — 핵심 기술에 밀려 거의 고르지 않던 기술이다. 후열(3·4열) 두 적에게 명중·치명타 감소와 함께 피해를 더 줘서, 후열 스트레스 딜러를 묶는 실제 선택지로 만든다. *(G-02, R-STRAT-01 / ARB-008)*
- **사냥돌 발사**: 피해 -50% → -40%; 1렙 변화 없음 … 5렙 밀치기 1 (105%) → 1렙 변화 없음 … 5렙 밀치기 1 (115%) — 핵심 기술 4개에 밀려 쓸 일이 없어 피해를 올렸다. 5렙 밀치기는 바닐라에 정의돼 있지만 연결되지 않던 효과로 바로잡았다 — 전에는 5렙에서 확률 성장이 멈춰, 적 저항이 오를수록 오히려 밀치기가 덜 성공했다. *(G-02, P-01 / ARB-007, ARB-004)*
- **야전 붕대질**: 회복 2-3 … 4-5 → 3-3 … 7-7; 1렙 받는 회복 +20% … 5렙 받는 회복 +38% → 출혈 치료 — 붕대는 출혈을 치료해야 하므로 출혈 치료를 넣어, 출혈이 많은 던전에서 석궁사수를 회복 담당으로 쓸 수 있게 했다. 대신 빠진 받는 회복 증가는 성전사 전투 치유로 옮겼다. *(P-19, G-05, P-11 / ARB-001, ARB-002)*
- **결집 신호탄**: 1렙 아군 전체: 표식 해제, 기절 해제; 아군 전체: 스트레스 회복 1 (60%) … 5렙 아군 전체: 표식 해제, 기절 해제; 아군 전체: 스트레스 회복 3 (67%) → 1렙 아군 전체: 스트레스 회복 2 … 5렙 아군 전체: 스트레스 회복 4 — 길드 설명이 그녀를 '결집소'라 부르므로, 신호탄이 나머지 아군 전원의 스트레스를 확정으로 회복한다 — 광대에만 기대지 않는 선택지. 만능 기술이 되지 않게 회복량은 적당히 두고 아군 기절·표식 해제는 다른 영웅에게 넘겼다. *(G-05, P-22, P-11 / ARB-003, ARB-006, ARB-010, ARB-009)*

## 현상금 사냥꾼

- **현상금 수거**: 표식 대상: 피해 +90% → 표식 대상: 피해 +100% — 표식 보너스가 +90% 고정이라 5렙에서는 다른 표식 딜러(+100%)보다 낮았다. +100% 고정으로 표식 대상 마무리는 현상금 사냥꾼이 가장 확실하게 한다. *(G-01, P-24 / BH-003)*
- **죽음의 표식**: 1렙 방어 -10% 3턴; 자신: 속도 +3 2턴 … 5렙 방어 -20% (140%) 3턴; 자신: 속도 +5 2턴 → 1렙 방어 -20% (130%) … 5렙 방어 -30% (170%) — 표식 기술들이 '표식 + 작은 약화 하나'로 거의 같았다. 죽음의 표식은 방어 감소를 키워 방어 있는 적 전용 표식으로 특화하고, 그 대가로 자기 속도 강화를 뺐다. *(G-02, P-11 / BH-013)*
- **이리 오너라**: 명중 90% → 95%; 피해 -80% → -60%; 1렙 당기기 2; 표식 2턴 … 5렙 당기기 2 (140%); 표식 2턴 → 1렙 당기기 3 … 5렙 당기기 3 (140%) — 당기기 3칸이면 3·4열 어느 적을 끌어와도 1열에 서서, 현상금 사냥꾼의 모든 처형 기술이 닿는다. 소표식은 빼서 죽음의 표식이 할 일(표식 → 당기기 → 처형)을 남기고, 당기기가 본업이 된 만큼 명중과 피해를 올렸다. *(G-02, P-22, R-TRADE-02 / BH-009, BH-010)*
- **어퍼컷**: 명중 90% → 95%; 치명 보정 0% → 9%; 대상 1·2 → 1; 1렙 기절 … 5렙 기절 (140%) → 1렙 기절 (110%) … 5렙 기절 (150%) — 섬광탄이 더 좋아서 어퍼컷을 쓸 일이 없었다. 이제 1열 전용 처형 기절기다 — 1열을 치면 밀려난 적이 3열로 가서 끝장내기 사거리 안에 남는다. 좁아진 대상은 명중·치명타(맨손 턱 타격, 치명타 시 표식 대상 피해 강화도 발동)와 섬광탄에서 가져온 강한 기절로 돌려줬다. *(G-02, P-21, P-19 / BH-007, BH-014, BH-015)*
- **섬광탄**: 사용 열 4·3·2 → 4·3; 1렙 기절 (110%) … 5렙 기절 (150%) → 1렙 기절 … 5렙 기절 (140%) — 2열에서 어퍼컷과 겹쳐 현상금 사냥꾼이 2열 붙박이가 됐다. 이제 1·2열은 어퍼컷, 3·4열은 섬광탄으로 갈린다. 강한 기절은 어퍼컷으로 옮겼고, 명중 95에 2~4열을 치는 섬광탄은 일반 기절로도 충분하다. *(G-03, G-02 / BH-008)*
- **끝장내기**: 사용 열 3·2·1 → 2·1; 추가: 1렙 출혈 대상: 피해 +20% … 5렙 출혈 대상: 피해 +33% — 도굴꾼의 중독 대상 추가 피해처럼, 끝장내기가 출혈 대상에게 추가 피해를 줘 자기 마름쇠와 파티 출혈 영웅과 연계한다. 처형기는 1·2열 전용으로 — 3열에서는 현상금 수거와 후열 기술을 쓰면 된다. *(G-01, G-02 / BH-001, BH-017)*
- **마름쇠**: 피해 -95% → -85% — 바닐라보다 피해를 조금 올렸다. 예전의 더 큰 상향은 다른 상향이 들어간 뒤 절반가량 되돌렸다 — 출혈·속도 감소·받는 피해 증가가 함께 붙어 이미 3·4열 출혈 기술 중 최고였기 때문이다. *(P-11, G-02 / BH-005, BH-016)*

## 성전사

- **광신적 고발**: 명중 85% → 90% — 피해 −40% 2인 공격에 명중까지 낮아 강타 대신 고를 이유가 없었다. 명중 90이면 강타보다 나은 상황이 생긴다. *(G-02 / CRU-002)*
- **기절의 일격**: 1렙 기절 … 5렙 기절 (140%) → 1렙 기절 (110%) … 5렙 기절 (150%) — 성전사의 대표 기절은 3열에 닿지 않고 속도도 느려, 이름대로 확실히 기절시키도록 강한 기절로 바꿨다. 칼 손잡이로 치는 기술이라 피해는 바닐라 그대로 — 한쪽 축만 올렸다. *(R-STUN-01, P-19 / CRU-003, CRU-009)*
- **신앙의 방패**: 사용 열 2·1 → 4·3·2·1 — 나병환자 견디기는 같은 구조(방어 강화·자기 표식·전투당 1회)인데 더 많은 열에서 쓰고, 순수 자기 방어 기술은 대부분 전 열이다. 방패를 드는 동작에 열 제약 이유가 없다. 이제 성스러운 돌격 시작 열(4열)에서도 쓸 수 있다. *(G-03, P-19, R-RANK-01 / CRU-007)*
- **전투 치유**: 회복 2-3 … 5-6 → 2-3 … 4-5; 추가: 받는 회복 +20% — 성전사를 회복량으로 성녀·신비학자와 겨루는 대신, 이후 받는 회복을 키워 주는 보조 힐러로 만든다. 이 증폭 효과는 석궁사수 붕대에서 옮겨 왔다. *(G-05, P-11 / CRU-001)*
- **격려의 함성**: 1렙 변화 없음 … 5렙 스트레스 회복 8 → 1렙 변화 없음 … 5렙 스트레스 회복 9 — 스트레스 회복 수요는 큰데 공급이 거의 광대에게만 몰려 있었다. 성전사의 단일 스트레스 회복이 매 레벨 오르게 해 혼자서도 맡을 수 있게 하고 조합 폭을 넓힌다. *(G-05, G-00 / CRU-006)*

## 결투가

- **찌르기**: 1렙 자신: 회피 +40% 4턴 … 5렙 자신: 회피 +50% 4턴 → 1렙 자신: 회피 +15% 2턴 … 5렙 자신: 회피 +25% 2턴 — 피해 없는 찌르기가 어느 열에서나 회피 +40~50을 4턴 주었고, 두 번 겹치면 적 명중률이 0%까지 떨어져 기절·약화까지 전부 막았습니다. 강화를 작게, 2턴으로 줄여 두 번 겹쳐도 예전 1회 수준에 머물게 했습니다. *(R-CMB-01, P-12 / DUE-005)*
- **눈속임**: 1렙 명중 -10% (표식 상태일 때), 방어 -20% (110%) 3턴 … 5렙 명중 -10% (표식 상태일 때), 방어 -30% (150%) 3턴 → 1렙 명중 -10% (표식 상태일 때), 방어 -10% (110%) 3턴 … 5렙 명중 -10% (표식 상태일 때), 방어 -20% (150%) 3턴 — 방어 감소가 현상금 사냥꾼의 죽음의 표식과 숫자까지 같았습니다. 표식의 원래(더 작은) 수치를 받아 두 기술을 구분하고, 이미 강한 결투가를 조금 낮췄습니다. *(P-14, G-01 / DUE-007)*
- **최후의 일격**: 피해 -60% → -70% — 결투가는 원작에서 손꼽히게 강한 영웅입니다. 최후의 일격은 어느 열에서나 1~4열을 치고 방어를 무시하며 처치하면 추가 행동까지 주므로, 그만큼 피해로 대가를 더 치르게 했습니다. *(R-TRADE-02, R-STRAT-01 / DUE-010)*
- **부츠**: 피해 -40% → -60% — 기절과 밀치기를 한 번에 거는 근접기인데 다른 기절 기술보다 피해 손실이 작아 실제 플레이에서 지나치게 강했습니다. −60%는 기절 기술의 일반적인 피해 범위 안입니다. *(R-STUN-01, R-STRAT-01 / DUE-006)*

## 고행자

- **저항**: 저항 stun 50% → 40%; 저항 bleed 65% → 60%; 저항 move 50% → 40% — 기절·이동 저항이 근거 없이 기준보다 높았습니다. 스스로 상처 내며 단단해진다는 설정과 거의 맨몸인 외형이 상쇄되므로 기준값 40으로 맞췄습니다. 출혈 65는 대표 저항의 일반 상한(기준 +30)을 넘는 유일한 사례라 상한에 맞췄습니다. *(R-RES-01, P-22, G-04 / FLA-001)*
- **무기**: 무기 spd 6 / 6 / 8 / 8 / 9 → 6 / 6 / 7 / 7 / 8 — 거의 모든 영웅은 무기 레벨에 따라 속도가 +0/+0/+1/+1/+2로 오르는데 고행자만 더 크게 올랐습니다. 같은 성장 규칙에 맞췄습니다. *(R-GROW-03, G-04 / FLA-007)*
- **인내**: 1렙 자신: 스트레스 +10; 자신: 속도 +1 … 5렙 자신: 스트레스 +6; 자신: 속도 +3 → 1렙 자신: 스트레스 +4 … 5렙 자신: 스트레스 +8 — 1레벨 인내는 스트레스 10을 회복하고 자신이 10을 받아 순회복이 0이었습니다. 자기 스트레스를 레벨마다 올려 순회복을 매 레벨 6으로 맞췄습니다. 저레벨부터 쓸 만하되, 2018년 공식 하향을 존중해 5레벨은 바닐라보다 낮습니다. *(G-05, P-06 / FLA-008)*

## 도굴꾼

- **사악한 난도질**: 명중 85% → 90% — 야만인은 4개 기술로 된 고정 정답 조합만 쓰였습니다. 탈진이 사라진 기본 공격을 더 잘 맞게 해 대안으로 고를 수 있게 했습니다. *(G-02 / HEL-005)*

- **돌파**: 피해 -50% → -55%; 제거: 자신: 피해 -10%, 속도 -1 — 다른 기술처럼 탈진을 없애고 그 대가로 피해를 조금 낮췄습니다. 부가 효과가 없어 2·3열 광역 공격 중 가장 약했기 때문에 피해 감소 폭은 작게 두었습니다. *(P-19, G-02 / HEL-002, HEL-008)*
- **아드레날린 분출**: 1렙 자신: 출혈·중독 치료, 명중 +5%, 피해 +20%; 자신: 회복 1 … 5렙 자신: 출혈·중독 치료, 명중 +10%, 피해 +30%; 자신: 회복 4 → 1렙 자신: 출혈·중독 치료; 자신: 회복 3 … 5렙 자신: 출혈·중독 치료; 자신: 회복 7 — 공격 강화가 야만스러운 함성!으로 옮겨 가 치료와 작은 회복만 남았고, 한 턴을 써서 4를 회복하는 기술은 아무도 고르지 않습니다. 자기 회복을 키워 야만인의 회복 전용 기술로 만들었습니다. *(G-05, G-02 / HEL-004)*
- **출혈**: 피해 20% → 0%; 치명 보정 6% → 10%; 제거: 자신: 피해 -20%, 속도 -3 — 탈진을 없앴습니다. 1열만 치는 대가를 피해 대신 치명타로 보상합니다. 치명타는 방어를 무시하는 출혈을 길게 만들어 후반 고방어 적에 대한 해법이 됩니다. *(P-19, P-21 / HEL-003)*

## 노상강도

- **사악한 칼질**: 피해 15% → 0%; 사용 열 3·2·1 → 2·1; 대상 1·2 → 1·2·3 — 사용 열을 근접 위치(1·2열)로 정리했습니다. 근접으로 3열을 치는 희소한 능력은 강화·이동이 있는 결투가의 진격이 아니라 단순한 칼질에 주어 역할을 나눴고, 그 대가로 피해를 근접 단일 기술 표준값으로 맞췄습니다. *(R-SKILL-09, G-02 / HWY-008, HWY-019)*
- **권총 사격**: 명중 85% → 90%; 1렙 표식 대상: 피해 +25% … 5렙 표식 대상: 피해 +50% → 1렙 표식 대상: 피해 +40% … 5렙 표식 대상: 피해 +60% — 원거리 공격은 거의 다 명중 90에서 시작하는데 권총 사격만 85라 원거리 빌드가 근접 빌드보다 약했습니다. 표식 대상 피해를 올려 표식 파티의 보조 딜러로도 쓸 수 있게 했습니다. *(G-02, P-26, P-03 / HWY-009, HWY-015, MARK-01)*
- **영거리 사격**: 이동 1 0 → 2 0; 1렙 밀치기 1 … 5렙 밀치기 1 (140%) → 1렙 밀치기 2 … 5렙 밀치기 2 (140%) — 명중 95에 대가 없는 피해 +50%로 명백히 과했지만, 수치를 그냥 깎으면 체감이 불쾌합니다. 대신 2칸 뒤로 물러나게 해(도굴꾼 돌진과 대칭) 연달아 쓰기 어렵게 하고, 밀치기를 2칸으로 늘려 쓰는 맛을 더했습니다. 성녀·광대·노상강도·방패 파괴자 고정 조합을 푸는 목적도 있습니다. *(P-12, G-00 / HWY-001, HWY-017)*

- **추적탄**: 피해 -80% → -60%; 대상 2·3·4 → 1·2·3·4; 전투당 사용 1 → 없음; 1렙 자신: 명중 +6%, 치명타 +4%, 피해 +12% 전투 끝까지 … 5렙 자신: 명중 +10%, 치명타 +8%, 피해 +20% 전투 끝까지 → 1렙 자신: 피해 -40%, 치명타 +0% 3턴 … 5렙 자신: 피해 -15%, 치명타 +5% 3턴 — 반격은 앞으로 이동하는 결투가의 진격에만 있어서 원거리 빌드는 자리를 깨지 않고는 반격을 쓸 수 없었습니다. 조준하며 상대를 간파하는 쪽이 반격에 더 어울리므로, 추적탄이 이동 없이 반격을 켜고 매 턴 쓸 수 있으며 마무리 공격을 할 만큼 피해도 조금 올렸습니다. *(G-03, P-19, G-02 / HWY-004, HWY-019)*

## 조련사

- **저항**: 저항 poison 40% → 30%; 저항 bleed 40% → 30% — 영웅 저항은 설정 문장이 있을 때만 기준치를 벗어난다. 조련사 설명(낡은 제복, 받아내기보다 회피)에는 중독·출혈 저항이 높을 근거가 없고 같은 문장 구조의 노상강도는 30이며, 함정 저항은 '사냥개를 밤에 경비로 세운다'는 설정이 있어 유지한다. *(P-22, R-RES-01 / HM-017)*
- **사냥개 돌진**: 명중 85% → 90%; 피해 0% → -25%; 사용 열 4·3·2 → 4·3·2·1; 1렙 출혈 1×3턴 … 5렙 표식 대상: 피해 +100%; 출혈 2×3턴 (140%) → 1렙 출혈 1×2턴 … 5렙 표식 대상: 피해 +60%; 출혈 3×2턴 (140%) — 사냥개 돌진을 모든 열에서 쓸 수 있게 해 어디서나 쓰는 범용 공격으로 만들었고, 조련사는 딜이 아니라 지원이 강해야 하므로 대신 기본 피해와 표식 추가 피해를 낮췄다(개 간식으로 순간 화력은 여전히 낼 수 있다). 명중을 올리고 출혈은 짧지만 고레벨에서 더 세게 해, 가벼워진 한 방도 안정적으로 들어가게 했다. *(P-24, G-00, P-11 / HM-019, HM-016, HM-018, HM-010, HM-023, HM-011)*
- **사냥개 습격**: 명중 85% → 90%; 피해 -75% → -70%; 사용 열 4·3·2·1 → 4·3·2 — 사냥개 습격은 거의 쓰이지 않았다. 광역 출혈은 얕게 퍼져 전투가 끝나기 전에 다 들어가지 못하고, 해골·익사자처럼 출혈에 사실상 면역인 적도 많다. 피해를 조금 올리고 명중을 출혈 기술 표준인 90으로 맞췄으며, 1열 사용을 빼서 습격과 둔기 강타를 함께 쓸 수 있는 2열이 조련사의 주 자리가 되게 했다. *(G-02, G-03, R-VALUE-03 / HM-012, HM-027)*
- **목표물 지정**: 1렙 방어 -20% (130%) … 5렙 방어 -30% (170%) → 1렙 명중 -25% (130%) 3턴 … 5렙 명중 -30% (170%) 3턴 — 방어 감소는 방어가 0인 많은 적에게 효과가 없었고 현상금 사냥꾼의 죽음의 표식과 겹쳤다. 이제 목표물 지정은 표식한 적의 명중을 떨어뜨리는 방어형 표식으로, 보호형 영웅인 조련사에 맞고 석궁사수(회피)·현상금 사냥꾼(방어) 표식과도 역할이 갈린다. *(P-24, P-14, P-19 / HM-020, HM-021)*
- **위험 경보**: 1렙 스트레스 회복 2 (66%) … 5렙 변화 없음 → 1렙 스트레스 회복 4 (70%) … 5렙 변화 없음 — 위험 경보는 유일한 아군 전체 스트레스 회복인데 유일하게 확률형이라, 저레벨에서는 턴을 쓸 가치가 없을 만큼 불안정했다. 1~4레벨 회복량을 올리고 확률이 매 레벨 오르게 했으며, 5레벨은 그대로 두어 기존 사용자의 체감은 바뀌지 않는다. *(G-05, P-12 / HM-014, HM-026)*
- **경비견**: 1렙 자신: 회피 +10% 3턴 … 5렙 자신: 회피 +20% 3턴 → 1렙 자신: 회피 +20% 3턴 … 5렙 자신: 회피 +30% 3턴 — 아군을 보호하는 영웅은 공격을 약 1.6배 더 받는데, 기존 회피 보너스로는 그 위험을 감당하기 어려웠다. 길드 설명 '약자를 보호'와, 딜은 낮추고 유틸은 올리는 조련사 방향에 맞춰 회피를 높였다. *(P-24, G-02 / HM-025)*
- **상처 핥기**: 사용 열 4·3·2 → 4·3·2·1 — 가장 많이 맞는 1열에서 자가 회복을 못 쓰는 구조가 이상했다. 이제 모든 열에서 쓸 수 있어 '고통받는 자들을 부축한다'는 설정에 맞고, 1열에서 쓸 수 있는 기술 수도 평균 수준이 된다. *(G-03, P-22 / HM-015)*

- **광휘**: 사용 열 3·2·1 → 4·3·2·1; 1렙 회피 -20% … 5렙 회피 -30% (140%) → 1렙 회피 -15%; 화상 1 … 5렙 회피 -25% (140%); 화상 3 — 최대한 바닐라에 가깝게 두었습니다. 성스러운 빛이 화상(1~3)을 주고, 후열 성녀도 쓰도록 4열에서도 사용합니다. 화상의 대가로 회피 감소를 5 낮췄고, 덕분에 석궁사수 저격 표식과도 구분됩니다. *(P-19, G-03, P-11 / VES-W01, VES-006, VES-013)*
- **빛의 손길**: 명중 85% → 90% — 신의 손길은 맞혀야 강화가 걸리는 효과 위주 원거리 기술이라 원거리 표준 명중을 준다. 전열 성녀 강화도 겸한다. *(R-TRADE-02, G-03 / VES-007)*
