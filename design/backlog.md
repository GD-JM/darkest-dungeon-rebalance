# 보류 아이디어 (나중에 꺼내 쓸 것)

제작자가 "좋은데 일단 킵"한 설계 아이디어. 꺼낼 때는 `test` 브랜치에서 실험 → 확인 → main·창작마당.

## BL-01 현상금 사냥꾼 죽음의 표식: 방어 감소 → 이동 저항 감소 (2026-10-21, 제작자 "엄청 좋은 생각, 일단 킵")
- 문제: 지금 방어 −20~−30%(130~170%, 바닐라 조련사 휘파람 효과를 옮김). 방어 0인 적이 56%라 일반전 가치는 낮고(모델 5렙 −49%p, 표식 기술 중 최하) 보스·정예에게만 커서 "센 놈 찍고 패면 끝" → 강약약강 정체성 흐림.
- 안: 표식 + 이동 저항 −20~−40%(3턴). 바닐라 강화 MOVERESIST-10/-20/-40 재사용 가능.
- 근거: 이리 오너라(당기기 3)·어퍼컷(밀치기 2)·섬광탄(섞기)이 잘 들어감. 영웅 등급 몬스터 이동 저항 중앙값 65. 적 이동 저항 감소는 아무도 안 하는 빈 역할.
- 변형: B 기절 저항 감소(신비학자와 겹침), C 이동+기절 저항 동시(바닐라 해골 방어병 Axeblade 선례, 가장 강함), D 받는 치명 증가(3명과 겹침).
- 상태: 보류. 지금은 창작마당판(방어 −20~−30%) 유지.
