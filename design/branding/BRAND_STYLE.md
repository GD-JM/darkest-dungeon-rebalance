# Darkest Refined — 브랜드 아트 스타일 원칙 (고정)

> 사용자 결정(2026-10-29): "레이아웃의 폰트라든지 배치라든지 아트스타일이라든지 이런거를 고정해서 원칙으로 md로 박아두고 나중에 프롬프트에 넣으면 똑같은 아트 스타일로 이미지 뽑고 수정이나 이런거 할 수 있게"
> 이 문서가 기준이다. 새 이미지를 만들거나 고칠 때 이 문서와 `brand_render.py`를 벗어나지 않는다. 바꿔야 하면 먼저 이 문서를 고치고(사용자 승인), 그다음 코드를 맞춘다.

## 0. 빠른 사용법

```
python design/branding/brand_render.py            # brand_content.json 전부 렌더
python design/branding/brand_render.py intro_2    # out 이름에 intro_2가 들어간 것만
python design/branding/build_descriptions.py --local  # 꾸민 설명(목업용)
python design/branding/make_mock_page.py          # 창작마당 모양 목업(HTML)
```

- 문구·배치 대상을 바꾸려면 **`brand_content.json`만** 고친다(레이아웃 이름 + 문구 + 아트 키).
- 새 그림을 쓰려면 **`brand_art.json`**에 키를 추가한다(코믹스 칸 좌표 또는 원본 이미지 영역 + 초점).
- 결과물: `darkest_refined_draft/` (창작마당용 세트), `darkest_refined_draft/templates/` (템플릿 견본).
- 다른 AI/세션에 맡길 때는 §9의 프롬프트 블록을 그대로 붙인다.

## 4. 공통 처리

- **만화 칸(cell)**: 그림을 칸 비율에 맞춰 초점 기준으로 자른다(cover) → 3px 검은 홈(8,6,5) + 안쪽 2px 들어간 1px 상아 선. 둥근 모서리·그림자 없음.
- **확대 한도**: 원본 1.25배 이하가 원칙, 불가피하면 1.5배까지. 넘으면 칸을 줄이거나 다른 그림을 고른다(흐릿한 확대 금지).
- **얼굴 보호**: 제목·글자가 영웅 얼굴을 가리면 안 된다. 키아트는 제목을 아래에 둔다(§5 square_keyart).
- **어둡게 누르기**: 글 영역은 INK로 덮고(패널 왼쪽 560px 고정) 200px에 걸쳐 1.5제곱 곡선으로 풀어 경계선이 보이지 않게.
- **필름 그레인**: 정사각 6, 그 외 7 (effect_noise 기반 overlay).
- **테두리**: 정사각 = 14px 안쪽 금테 3px + 그 안 10px 가는 테 1px / 그 외 = 10px 안쪽 금테 3px.
- **규칙선**: GOLD 2px. 가운데 정렬 제목 아래는 마름모(7px) 장식, 왼쪽 정렬은 장식 없음.
- **글머리**: GOLD 마름모 16×16.

## 6. 아트 원칙

1. **출처**: Red Hook Studios 공식 아트만 쓴다 — 영웅 오리진 코믹스 18편(결투가·도망자 없음), 홍보 포스터(야만인·노상강도), 키아트, 초기 배경화면, 게임 내 원화. `source_art/`에 보관(공식 위키 darkestdungeon.wiki.gg에서 사용자가 직접 저장).
2. **저작권 표기 필수**: 모든 이미지 구석에 `Art © Red Hook Studios`, 설명문 끝에 "공식 코믹스 © Red Hook Studios, 비공식 팬 모드" 한 줄.
3. **공식 로고 제거**: 원화에 찍힌 Darkest Dungeon 로고·URL은 `box`로 잘라낸다(공식 제품처럼 보이지 않게).
4. **팬아트**: 작가 허락 없이는 쓰지 않는다. 허락받으면 작가 이름을 크레딧에 함께 적는다.
5. **B컷 고르는 기준**: 영웅이 주인공인 칸, 전투 화면과 다른 표정·상황(과거·결심·고통), 칸 안 글자 없음, 원본 해상도 충분(§4 확대 한도). 같은 이미지 세트 안에서 같은 칸을 두 번 쓰지 않는다.
6. **정답 파티처럼 보이지 않게**: 대표 이미지에 성녀·광대·결투가·방패 파괴자 같은 고정 조합을 나란히 세우지 않는다.
7. **게임 안 전신 원화**(spine21.py로 조립 가능)는 보조용. 대표 브랜드 이미지는 만화풍 B컷이 기준(사용자 선호 10-29).

## 7. 문구 원칙

- 이미지 글은 **영어**, 플레이어가 처음 읽어도 이해되는 자연어. 내부 ID(P-25, SYS-105 등) 금지.
- 수치는 **현재 main(창작마당 배포본) 카드 기준**, 범위는 기술 1~5레벨, 명중·치명은 1레벨 기준. 확인 못 한 수치는 쓰지 않는다.
- 항목 수: 패널 4개(각 본문 2줄 이내), 업데이트 4개, 스포트라이트 4단(각 3줄 이내).
- 공식 기술·영웅 이름은 게임 영어 이름 그대로(모드가 바꾼 이름은 모드 이름: Sunder 등).
- 과장 금지: "perfect balance" 같은 단정 대신 원칙("The same tension")과 근거로 말한다.

## 8. 파일·창작마당 규칙

- 출력 PNG. 창작마당 갤러리는 **장당 1MB 미만**(업로드 시 자동 축소, `upload_private_draft.py`의 fit_png), 대표 썸네일은 JPEG 92.
- 정사각 대표 이미지는 작은 썸네일(약 200px)에서도 DARKEST REFINED가 읽혀야 한다.
- 시안은 **비공개 시안 아이템 3828956017**에서 먼저 확인한다. 공개 아이템(3821353035) 반영은 별도 승인 후 push.py 배포 파이프라인으로만.
- `source_art/`와 `darkest_refined_draft/`는 저장소에 커밋하지 않는다(외부 저작물·생성물). 코드·JSON·이 문서는 승인 후 커밋.

## 9. 다른 세션/AI에 붙일 프롬프트 블록

```
Darkest Refined 브랜드 이미지를 만들거나 고친다. 규칙은 mods/Rebalance/design/branding/BRAND_STYLE.md가 전부다.
- 새 이미지는 brand_content.json에 항목을 추가하고 python design/branding/brand_render.py <이름>으로 렌더한다.
- 레이아웃은 §5의 9개 템플릿 중에서만 고른다. 좌표·글꼴·색·테두리·그레인을 임의로 바꾸지 않는다.
- 그림은 brand_art.json 키만 쓴다. 새 그림은 Red Hook 공식 아트만, 키를 추가하고 초점(focus)을 맞춘다. 확대 1.25배 이하.
- 모든 이미지에 'Art © Red Hook Studios'. 공식 로고는 잘라낸다. 팬아트는 허락 없이 금지.
- 이미지 글은 영어 자연어, 내부 ID 금지, 수치는 main 카드 기준(기술 1~5레벨 범위).
- 결과를 눈으로 확인하고(제목이 얼굴을 가리는지, 글이 넘치는지, 칸 경계가 보이는지) 고친 뒤 보고한다.
- 공개 창작마당 반영은 하지 않는다. 확인용은 비공개 시안 아이템 3828956017.
```
