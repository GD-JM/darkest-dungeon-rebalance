### MUS-000 모드에서 제외: 총사는 전부 바닐라 (결정)

- 결정 (제작자, 2026-09-28): 총사는 이 모드에서 **아무것도 바꾸지 않는다.** 제작자는 총사 전용 외부 모드를 함께 쓴다. 같은 영웅 파일을 두 모드가 덮으면 충돌한다.
- 경위: MARK-01(`30e207f`)에서 석궁사수와 공유하는 `Sniper Damage` 효과를 같이 조정하려고 총사를 편입했었다. 석궁사수 쪽 변경은 `RB ARB Sniper Damage` 사본으로 분리되어 있어 **총사를 빼도 석궁사수 변경은 그대로 유지된다.**
- 조치: `heroes/musketeer/`, `effects/rebalance_musketeer.effects.darkest` 삭제, `modfiles.txt` 재생성. 강함 모델(`tools/strength.py`)은 RB 파일이 없는 영웅을 바닐라로 읽는다.
- 앞으로: 석궁사수와 공유하는 바닐라 효과(저격 피해, 무차별 사격, 표식, 사냥돌, 결집 신호탄 스트레스 회복 등)를 석궁사수에서 바꿀 때는 **반드시 `RB ARB` 사본**으로 바꾼다. 도구가 자동으로 그렇게 처리한다(P-17).


## 2026-10-05 ~ 10-21 외부 총사 모드 편입 기간 (요약, 원문 제거)

- MUS-001~002: 다른 제작자의 총사 모드(YAMR)를 커스텀판에 편입해 썼다. 창작마당판에는 넣지 않았다.
- 2026-10-21: 자체 리워크(MUS-101~)로 교체하고, 그 모드의 파일·분석 사본은 저작권 문제로 저장소 기록 전체에서 제거했다 [제작자 "YAMR 관련 전부 지우자, 내가 다시 만든 게 훨씬 총사다워"].

## 창작마당판 독자 총사 (2026-10-21, 사용자 확정)

설계 과정·근거 전체: [musketeer_identity.md](../analysis/musketeer_identity.md), 모델 결과 [model_draft3.txt](../musketeer/model_draft3.txt). 데이터 원본: `design/workshop/musketeer/` (커스텀판의 YAMR 총사와 별개, 창작마당 빌드가 이 파일을 쓴다).
정체성: 대회 2등의 한을 괴물 사냥으로 풀려는 명사수. 방어를 꿰뚫어 큰 사냥감을 직접 잡고, 연기로 판을 흔들고 동료를 숨긴다. 석궁사수(붙박이 포탑)보다 전체 강함은 아래(이동 가능 원칙).
모델(5렙): 행동 가치 +85%p (석궁 +102), 총점 18위 32 (석궁 15위 42). 총점 차이는 의도한 약점(속도·체력).

### MUS-101 속도 2/2/3/3/4
- 화승총은 느린 무기 + 열 이동이 가능한 영웅은 붙박이보다 약해야 한다 [사용자 10-21].
### MUS-102 체력 24/28/33/37/42
- "참가자의 조끼" 대 석궁 판금 "생존자". 실전 경험 부족.
### MUS-103 관통탄 (조준사격 칸)
- 명중 90~110, 피해 0%, 사용 3·4 → 대상 1~4, 방어 관통 10/15/20/25/30% (엔진 버프 `ignore_protection`, V-19), 표식 대상 피해 +25/29/33/37/40%·치명 +9~13%.
- 완전 방어 무시는 과함 → 레벨별 관통 [사용자]. 총인데 피해 −25%는 약해 보임 → 0% [사용자].
### MUS-104 연막탄
- 광역 1·2열 기절(Stun 1~5) + 명중 −10/10/12/12/15%(1턴) + 자신 은신 2턴(stealth_self), 전투당 3회(바닐라 함성 3회 기준 [사용자]).
- 명중·치명 −15% 2턴은 석궁 제압 사격과 겹치고 과함 [사용자] → 1턴 명중만. 장신구 약화 확률 요구 때문에 약화는 남김.
### MUS-105 사냥감 지정 (신호탄 칸)
- 표식 3턴 + 자신 속도 +3/3/4/4/5(3턴) + 대형 상대 치명 +4~8%(3턴, 버프 규칙 monsterSize 2).
- B안 [사용자]: "이놈은 내 거야!"가 설정에 더 맞다. 속도는 다급하게 증명하려는 설정 [사용자], 무차별 사격 수치.
### MUS-106 몰이 사격 (산탄 칸)
- 4열 단일, 피해 −50%, 밀치기 1 (Push 1A~1E). 4열 밀치기 = 4열이 1열로(V-18 확인).
### MUS-107 권총사격
- 사용 1·2·3 → 대상 1·2 [사용자], 피해 −40%, 쏜 뒤 뒤로 1칸(.move 1 0). 뒤로 2칸은 열 섞임 대처가 공짜라 과함.
### MUS-108 응급처치
- 회복 바닐라 + 스트레스 회복 2/2/3/3/4, 받는 회복량 누적 삭제(성전사 전투 치유 몫) [사용자].
### MUS-109 엄호 연막 (스키트 사격 칸)
- 어디서든, 자신 제외 아군 1명 은신 2턴(바닐라 Stealth2). 버프 없음. 모델은 위기 구조 가치를 못 세어 −44%p로 나옴 → 플레이로 확인.
### MUS-110 표시: 이름·이펙트
- 이름: 관통탄 / 연막탄 / 사냥감 지정 / 몰이 사격 / 권총사격 / 응급처치 / 엄호 연막 (12개 언어 loc2). 엄호 연막 = 스키트 사격 발사 이펙트 + 연막탄 대상 이펙트(아군 위 연기).
### MUS-111 직업 치명타 버프: 방어 관통 +20% (2026-10-21, test 브랜치)
- 표식 대상 피해 +33%(석궁·현상금과 같음)는 "표식 딜 축소" 정체성과 충돌 [제작자 지적]. 치명타 후 2턴 동안 모든 공격 방어 관통 +20%(바닐라 방패 파괴자 야영 관통 20%와 같은 값).
### MUS-112 몰이 사격: 4열 단일 → 광역 2·3열 밀치기 (2026-10-21, test)
- 문제: 4열 밀치기 1이 맨 앞으로 돈다(V-18)는 전제가 틀렸다 [제작자: "4열이 1열로 바뀌는 건 섬광탄(위치 섞기)이었다, 내 실수"]. 4열은 더 뒤로 갈 칸이 없어 밀치기가 아무 일도 안 한다 → 창작마당 1.1의 몰이 사격은 피해만 주는 기술이었다.
- 변경: 대상 4 → 광역 2·3열(~23), 피해 −50%, 밀치기 1(Push 1A~1E) 그대로. 2·3열이 뒤로 밀리면 그 뒤의 4열 적이 앞으로 당겨진다. "몰이"(사냥감을 몰아내기) 의미는 유지.

### MUS-113 권총사격: 대상 1·2 → 1·2·3열 (2026-10-22, test)
- 사용 1·2·3 → 대상 1·2·3, 피해 −40%·명중 90·치명 3%(1렙) 그대로.
- 근거: 뒤로 빠지는 공격 기술 전수 비교(영거리 사격은 위험 없는 +50%라 비교 제외 [제작자]). 같은 사용 열·피해·이동인 방패 파괴자 폭로(대상 1·2·3 + 약화 3종, 모델(5렙) +76%p)의 완전 하위 호환(−27%p)이었다.
- 피해 0% 안은 기각 [제작자].

### MUS-114 권총사격 약화 + 사냥감 지정 개편 (2026-10-22, test)
- 권총사격: 피해 −40% → −20%, 적 치명 −10/11/12/13/15% 2턴(확률 100~140%) 추가. 제압 사격(명중·치명 −15, 2턴)에서 명중 반쪽은 연막탄이 가졌으므로 치명 반쪽을 가져온다 [제작자].
- 사냥감 지정: 대형 상대 치명 +4~8%(자신) 삭제 → 대상 받는 치명 +5/6/7/8/10% 3턴(약화, 확률 100~140%). 자신 명중 +5/6/7/8/10 추가(속도 +3/3/4/4/5와 같은 3턴) [제작자].
- 받는 치명은 방패 파괴자 폭로(+8~10)보다 낮게: 관통탄 표식 치명 +9~13, 은 탄환 +8, 치명 시 방관 +20%와 겹친다.
- 근거: 약화 확률 장신구 2개(분노의 모자 +30%, 은 탄환 +35%)가 쓸 약화가 연막탄 명중 −10(1턴) 하나뿐이었다 → 3개로. 공식 설정 "백발백중"(무기 5단계)·"빈틈없는 눈"을 명중으로 반영.
- 대형 조건 버프 RB_MUS_PREY_CRIT_1~5 삭제.

### MUS-115 연막탄: 자신 은신 → 기절한 적 은신 (2026-10-22, test)
- 문제 [제작자 게임 확인]: 연막탄을 쓰면 총사 자신이 은신했다. 결정은 "적 연막 = 1·2열 기절 + 은신"(musketeer_identity.md 10-21 오후)이었는데 `stealth_self`로 잘못 구현했다.
- 변경: `stealth_self` 삭제 → `RB MUS Smoke Hide`(대상, 500%, 1턴) + 강화 `RB_MUS_SMOKE_HIDE`(은신, 규칙 is_actor_status stunned, 조건이 꺼지면 제거). 기절한 적만 연기 속에 숨고, 기절이 풀리면 은신도 사라진다.
- 출처: YAMR 연막탄의 메커니즘(기절 동안만 은신)을 조사해 같은 규칙으로 직접 작성(YAMR 파일·문구는 쓰지 않음).
- 의도: 기절한 앞열이 숨으니 아군 화력이 후열로 모인다 — 메인 전략(R-STRAT-01: 앞열 기절, 후열 처치)과 일치.
