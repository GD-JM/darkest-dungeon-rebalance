### MUS-000 모드에서 제외: 총사는 전부 바닐라 (결정)

- 결정 (제작자, 2026-09-28): 총사는 이 모드에서 **아무것도 바꾸지 않는다.** 제작자는 총사 전용 외부 모드를 함께 쓴다. 같은 영웅 파일을 두 모드가 덮으면 충돌한다.
- 경위: MARK-01(`30e207f`)에서 석궁사수와 공유하는 `Sniper Damage` 효과를 같이 조정하려고 총사를 편입했었다. 석궁사수 쪽 변경은 `RB ARB Sniper Damage` 사본으로 분리되어 있어 **총사를 빼도 석궁사수 변경은 그대로 유지된다.**
- 조치: `heroes/musketeer/`, `effects/rebalance_musketeer.effects.darkest` 삭제, `modfiles.txt` 재생성. 강함 모델(`tools/strength.py`)은 RB 파일이 없는 영웅을 바닐라로 읽는다.
- 앞으로: 석궁사수와 공유하는 바닐라 효과(저격 피해, 무차별 사격, 표식, 사냥돌, 결집 신호탄 스트레스 회복 등)를 석궁사수에서 바꿀 때는 **반드시 `RB ARB` 사본**으로 바꾼다. 도구가 자동으로 그렇게 처리한다(P-17).


## 2026-10-05 적용 외부 모드 전수 검토 — 분석만

사용자 원문: “나병은 고칠 거없다 치고 총사 모드 적용된거로 몇개 수정하고 싶거든 적용된거로 능력치랑 전수조사 해서 다 보여주고 조정 해야할 부분 얘기해줘봐”

최근 저장 profile_0의 실제 applied_ugcs 목록에 Yet Another Musketeer Rework(1624470590)가 있으며, DD Tweaks(3796583336)와 Trinkets Plus는 이 목록에 없다. persistent 목록은 분리했다. 위 MUS-000의 바닐라 문구는 Rebalance에서 총사를 제외한다는 과거 결정이며, 현재 함께 쓰는 외부 총사의 실제 값이 바닐라라는 뜻이 아니다. 최신 요청은 외부 모드 기준 분석을 승인하며 특정 수치 편집은 승인하지 않았다.

설치 YAMR 기술35행·능력치·연결 효과72개·전용 장신구9개+CC세트·야영7개·치명 고유 강화·철갑탄 actor_dot·보급·훈련장 효과를 검토했다. 장신구는 제작자 권장 YAMR > Separator 우선순위 기준; 저장 직렬화만으로 UI 우선순위를 확정하지 않는다. 반대 우선순위의 장신구 원문도 보고서에 보존했다.

능력치·조준사격·스키트·후퇴 사격은 유지 우선. 산탄 명중80→85와 피해 교환, 고양 사용열234와 스트레스회복−1 교환을 후보로 비교했다. 열별 피해 합산·관통·기절 대상 은신·기절해제 순서·무료 행동/처치 재충전 상한은 엔진 확인 대상. 강기절/일괄 상향을 점수로 결정하지 않는다. 후보는 전부 미승인·미적용; 외부 모드 및 게임 수치/참조 수정 없음. 승인 후 적용할 때 별도 호환 패치·// ID+의도·변경 이력을 설계한다.

[전수 검토](../analysis/musketeer-full-review.txt), [모든 레벨 원문·계산·출처 해시](../analysis/musketeer-full-review.json). 표준 기본 공격 환산%p를 사용; 현재 strength.py의 총사 RB→바닐라 fallback으로 적용 모드를 잘못 평가하지 않았다. 게임 실행 검증 및 총사 종합 서열은 수행하지 않았다.


### MUS-001 적용된 YAMR 총사 전체 편입 및 편집 절차 연결

- 상태: 적용 (사용자 승인 및 편입 2026-10-05).
- 분류: 외부 모드 현행 이전. 신규 밸런스 조정 없음.
- 목표: G-01 조합 다양성; 적용된 총사를 동일한 파일/의도/효과 편집 절차로 관리.
- 사용자 원문: “해당 능력치를 Rebalance에 그대로 적용해서 다른 영웅 파일과 동일하게 만들어줘 가능하겠어?”
- 범위 확인 원문: “외부 모드 없이 총사 전체 편입”
- 의도: 설치된 YAMR의 모든 영웅/효과/강화/장신구/야영/그래픽/번역/오디오/재충전 값을 보존하며 Rebalance에서 직접 편집. 앞서 산탄/고양 후보는 적용하지 않는다.
- 출처: o'nite, Yet Another Musketeer Rework, https://steamcommunity.com/sharedfiles/filedetails/?id=1624470590 ; 현재 설치본 해시는 design/imports/musketeer/manifest.json. 소스 숫자·문구·그래픽 원본 보존.
- 변경: heroes/musketeer에 info/vanilla/effects_edit 작성. 바닐라와 별개인 고정 YAMR 원본을 design/imports에 보존; 원본 이름을 그대로 사용하고 수정 때만 RB MUS 사본으로 분리. 중복 효과 생성 없음.
- 연결 효과: 반격의 하위 효과, actor DOT 재충전, 장신구 추가 효과까지 편집 참조 갱신/원상복귀 지원. 모드 전용 강화 JSON은 RB 모델 로더에 포함; 숫자/평가 공식은 변경하지 않는다. 현재 모델의 열 피해/무료 행동/은신·기절해제 누락 한계는 여전히 남음.
- 장신구: 별도 Separator 없이 DLC 원래 묶음 경로의 총사 항목만 교체. 다른 영웅의 장신구/세트 값은 설치본 그대로 보존. 야영도 총사 투영만 이전하며 타 영웅 기술은 보존.
- // 주석: darkest 및 효과 편집 사본의 각 변경에 ID+의도. 엄격 JSON·바이너리는 문법을 깨는 주석을 넣지 않고 design/imports/musketeer/intents.txt에 // MUS-001 경로/항목별 근거 기록.
- 운용: 기존 YAMR/다른 총사 개조 모드/Trinket Separator/Trinkets Plus를 끄고 Rebalance를 우선 적용. 게임 총사 DLC는 계속 필요. 모드 활성 목록/세이브/Workshop 원본은 자동 수정하지 않는다.
- 검증: 설치 수치 동등성, 참조 해소, 타 영웅·소스 해시, 효과 편집/복귀 멱등성, 주석/manifest 검사를 완료한 뒤 적용 결과를 기록한다. 게임 실행 검증은 별도.
- 이력: MUS-000의 제외 결정은 이 최신 승인으로 대체. 앞선 전수 검토 문서는 해당 날짜의 역사 기록으로 유지.

검증 결과: 442개 데이터/참조/편집복귀/주석/manifest 검사 통과. 기술35행과 효과71행은 설치 YAMR과 주석을 제외하고 동일하며, 편집 사본72개 효과를 지원한다. 실제 숫자를 바꾼 실험은 별도 검증 복사본에서만 수행하고 본 적용에는 포함하지 않았다. 전체20영웅 주석 검사 통과. 게임 실행 테스트는 미실시.

공유 장신구 JSON의 다른 영웅 값과 총사 장신구의 다른 직접 편집 필드는 효과 적용/복귀 때 덮어쓰지 않는 회귀 검증도 통과했다.
