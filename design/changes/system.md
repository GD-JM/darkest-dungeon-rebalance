# 적용·기록 안전성

### SYS-101 잘못된 효과 재적용의 부분 쓰기 방지 (2026-10-06)
- 상태: 사용자 "나머지 버그날 가능성 있는거 고쳐봐"에 따른 도구 수정.
- 목표: G-00. 원칙: P-02, P-11, P-13, P-15, P-17.
- 문제: 기존 apply_effect_edits.py는 효과 파일/영웅 참조를 쓴 뒤 이름·신규 참조 오류를 출력했고, 오류가 있어도 성공 종료했다. 잘못된 입력이 게임 상태를 부분 변경할 수 있었다.
- 수정: 파일 변경을 메모리에 모은다. 모든 요청 영웅 검증 후 오류가 있으면 쓰기/파일 목록 갱신 없이 종료1, 정상일 때만 적용. --dry-run도 오류는 종료1. 동일 효과/사용하지 않는 효과 경고는 비치명으로 구분.
- 검증: 정상 반복 적용, 잘못된 원본 이름, 누락 신규 참조, 여러 영웅 중 후순위 오류, --dry-run 무변경을 격리 복사본에서 확인한다. OS 쓰기 오류 롤백까지 보장하는 변경은 아니다.
- 원칙 보강: P-11은 사용자가 지정한 핵심 원칙이다. 응징−20/추적탄−75, 사냥개 돌진−25/성녀 심판0은 재배분 의도의 예시이며 실제 전투력 보존을 계산 없이 단정하지 않는다.
- 중보병 결정 원문: "4 1.2열만 때려서 3열까지 때리는 분쇄보다 좋을 가능성 적어". 응징 피해−20/대상12를 그대로 유지하고−30 후보는 이번 결정에서 채택하지 않는다.
