# 피드백 기록

창작마당 댓글·토론·플레이 테스트 피드백을 전부 남긴다(P-08).
반영하면 `changes/`에 새 항목을 만들고 ID를 연결한다. 반영하지 않으면 이유를 적는다.

## 항목 틀

```
### FB-001 (날짜) 요약
- 출처: 창작마당 댓글 / 토론 / 플레이 테스트 (작성자 표기는 닉네임까지만)
- 버전: 피드백 당시 모드 버전
- 내용 요약:
- 관련 항목·목표: SB-002, G-01 …
- 판단: 반영 / 부분 반영 / 보류 / 미반영
- 이유: (근거 데이터·원칙과 대조)
- 후속: 새 변경 항목 ID 또는 없음
```
