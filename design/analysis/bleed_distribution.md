# 출혈 기술 분포 (2026-10-23, test 기준, 1렙 수치 / 출혈은 1→5렙)

조련사 출혈 특화(HM-029) 검토용. 영웅 기술 중 적에게 출혈을 거는 것 전부(13개 + 조련사 안).

|---|---|---|---|---|---|
| 전열 → 전열 | 고행자 응징 | 1·2 → 1·2 | 단일 | 0% | 4→6 |
| | 고행자 방혈 | 1·2 → 1·2 | 단일 | 0% | 5→9 |

## 출혈 대상 보너스 (출혈을 "받아 먹는" 쪽)
- 현상금 사냥꾼 끝장내기: 출혈 대상 피해 +20~33%
- 야만인 직업 치명: 출혈 대상 피해 +33% (2턴)
- 결투가 면도날 힐트(장신구): 출혈 대상 방어 무시
- 조련사 핏빛 궁정 세트: 출혈 대상 피해 +25%·치명 +5
- 출혈 확률 강화: 고행자·조련사 직업 치명(+20)

## 판단
- 후열에서 **전열·전체 어디든** 출혈을 거는 영웅은 조련사뿐 → 열 분포상 겹침 없음.
- 광대는 2·3열 → 2·3열(중열) 출혈이 부업(본업은 스트레스 회복·강화), 고행자·야만인은 전열 고수치 출혈 딜러.
- 조련사 = "원거리 출혈 부여자": 후열에서 사냥개로 어디든 물어 출혈을 깔고, 끝장내기·야만인 치명·면도날 힐트가 받아먹는 구조. 고수치보다 **넓게·확실히(확률 110~150%)** 거는 쪽이 고유.
