# 회복 기술 분석 (체력·스트레스)

원본 데이터 기준. `*` = DLC 영웅.
- 방법은 `stun.md`, `dot.md`와 같다. 성장 구조와 몬스터 비교는 `heal.md`에 있다.
- 영웅 주 열은 `hero_ranks.md` 기준이다.
- 5레벨 기대 회복
  - 고정량은 평균값이다.
  - 비율 회복은 영웅 5레벨 평균 최대 체력 43 기준이고, 자기 회복은 해당 영웅의 5레벨 최대 체력 기준이다.
  - 지속 회복은 턴당 × 지속 턴이다.
  - 확률형 스트레스 회복은 크기 × 확률 × 대상 수다.
- 치명타 O = 치명타가 가능한 기술(`.is_crit_valid`).

## 5. 경향

### 5-1. 체력 회복의 두 계열
- **고정량 회복(성녀·성전사·석궁사수·총사·유물수집상·역병 의사·신비학자)**: 치명타 불가, 제한 없음, 영웅 체력 성장과 같은 속도로 오른다(`heal.md`).
- **비율·지속 회복(고행자)**: 치명타 가능, 1회 회복량이 최대(43~50%)지만 사용 조건으로 묶었다.

### 5-2. 광역 회복은 1인당 절반
- 성녀 신성한 위무의 1인당 4.5는 신성한 은총(8.5)의 약 절반이다.
- 4명 전원을 채우면 총량은 2배(18.0)가 된다. 광역 스트레스 회복(위험 경보)도 1인당 4.4로 단일(격려의 선율 12)보다 작지만 총량은 더 크다.

### 5-3. 성녀·신비학자·고행자에 회복량이 몰려 있다
- 아군 체력 회복 5레벨 기대 상위 5개 중 4개가 성녀·고행자이고, 신비학자는 4위다.
- 나머지 영웅(성전사·석궁사수·총사·유물수집상·역병 의사)의 아군 회복은 평균 체력의 5~13%다(G-05 문제의 수치적 근거).

### 5-4. 광대의 스트레스 회복은 수치 1위가 아니다
- 5레벨 기대 순위는 위험 경보(17.8) > 인내(14.0) > 격려의 선율(12.0)이다.
- 격려의 선율의 강점은 비용 없음·치명타 가능·후열 사용이다. 인내는 자기 비용이 있고, 위험 경보는 확률형이다(`heal.md` 4절과 같은 결론).

### 5-5. 사용 열
- 아군 회복 11개 모두 영웅 주 열에서 쓸 수 있다. 성녀·석궁사수·총사·유물수집상·역병 의사는 3·4열, 성전사·고행자·신비학자는 전 열에서 쓴다.
- **1·2열 전용 아군 회복은 없다.** 전열 영웅이 전열에서 쓰는 회복은 모두 "전 열 사용" 기술이다.

## 6. 표준형과 가감 분해

### 6-1. 아군 체력 회복 표준형: 성녀 신성한 은총
아군 1명 / 사용 3·4열 / 고정 4-5 → 8-9 / 치명타 불가 / 제한·부가 효과 없음 (최빈값과 완전 일치)

| 기술 | + 더한 것 | − 뺀 것 / 대가 |
|---|---|---|
| 성녀 신성한 위무 | **아군 전체**, 사용 +2열 | 1인당 회복 약 절반(1-3 → 4-5) |
| 고행자* 구제 | 사용 전 열, **비율 회복 43%**, 자기 회복 50%, 치명타 | **전투당 2회, 체력 40% 이하**, 소진 약화 |
| 고행자* 재기 | 사용 전 열, 총량 +3.5(지속), 치명타 | 즉시 회복 아님, 자신 출혈 |
| 신비학자 기괴한 재구축 | 사용 전 열, 최대 22 | **최소 0**, 대상 출혈 부작용 |
| 성전사 전투 치유 | 사용 전 열 | 회복 −2~−3 (2-3 → 5-6) |
| 석궁사수 야전 붕대질 · 총사* 응급처치 | — | 회복 −2~−4 (2-3 → 4-5) |
| 역병 의사 야전 의술 | **상태 치료** | 회복 −3.5~−5.5 (1 → 3) |
| 유물수집상 강화의 연막 | 부가 강화 효과 | 회복 −3.5~−5.5 (1 → 3) |
| 성전사 격려의 함성 | 사용 전 열, **스트레스 회복 5→8**, 횃불 | 체력 회복 1 → 2 |

**교환 비율**: 체력 회복량을 깎는 대가로 받는 것은 **사용 열 확대(전투 치유 −3), 상태 치료·강화(−5), 스트레스 회복(−6.5)**이다. 고행자 계열만 제한·조건으로 치른다.

## 7. 설계 의도 추론

1. **고정량 아군 회복은 치명타를 막아 회복량 변동을 없앴다.** 대신 신비학자 기괴한 재구축에 편차(0~22)를 줘서 "도박형 회복"을 따로 만들었다.
2. **자기 회복은 치명타를 허용했다.** 자기 생존 기술의 기대값을 조금 높였다.
3. **고행자의 강한 회복은 조건(체력 40% 이하·횟수 제한)으로만 묶었다.** 2018-06 패치에서 추가된 제한이다(`dlc_history.md`).
4. **체력 회복량을 깎는 대가로 사용 열·상태 치료·스트레스 회복을 준다.** 회복 전문가(성녀)와 겸업 회복(성전사·역병 의사·유물수집상)을 수치로 나눴다.

## 8. 모드 적용 시사점 [제안] (G-05)

- **회복 대체재 만들기**: 겸업 회복의 교환 비율(사용 열 확대 −3, 상태 치료·강화 −5, 스트레스 −6.5)을 유지하면서 기본 회복량을 올리면, 성녀를 대체할 여지가 생긴다. 예: 전투 치유·야전 붕대질·야전 의술.
- **자기 회복 확대(G-05 "모든 영웅 자가 회복")**: 표준형(상처 핥기: 자기 기술, 4→8, 치명타 가능, 제한 없음)을 틀로 쓴다. 회복 기술이 없는 영웅 8명에게 공격 + 자기 회복형(성녀 심판 3→5)이 가장 싸게 붙일 수 있는 형태다.
- **스트레스 회복 분산**: 광대 격려의 선율(12)보다 약한 성전사 격려의 함성(8)·결집 신호탄(6)이 대체재 후보다. 광대의 강점이 비용·치명타·후열이라, 대체재에도 이 조건을 맞춰야 한다(`heal.md` 4절).
- **1·2열 전용 아군 회복이 없다**: 전열 영웅이 전열에서만 쓰는 회복을 설계하면 G-03(서브 열)과 G-05를 함께 건드릴 수 있다.
