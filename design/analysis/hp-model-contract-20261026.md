# R-HP-027 — Claude 공식 계승과 HP 환산 검증 (2026-10-26)

사용자 요청: 기존 Claude 피해량 % 모델의 모든 항목을 가져와 HP 산정 공식으로 이어 쓰고, 항목별로 검증하며 점진적으로 수정한다. 단위만 바꾸는 작업이 아니다. 괴인 유지 비용은 6 유지이며, 동료 부담을 본인에게 이전하는 기획을 비용 총합과 분배로 따로 평가한다.

## 단위와 비교 계약

1. **실제 기대 HP 감소:** 무기, 명중, 치명, 방어, 정수 처리, 대상 현재 HP로 계산한 체력 감소. 직접 피해가 어디에서 실제 수치로 끝나는지 명시한다.
2. **HP 환산 가치:** 피해 + 실현되는 회복 + 예방 손실 + 후속 공격 증가 − 비용. 스트레스 가격·열 가중·생존율 등 모델 가정을 포함할 수 있으므로 실제 체력 감소라고 부르지 않는다.
3. **EHP:** `HP/(1-PROT)` 또는 명중 노출을 고려한 생존 지표. 유한 기간 막은 HP와 중복 합산하지 않는다. 공격력 차이를 반영한다는 이유로 공격 값을 EHP라고 부르지 않는다.
4. 기존 %p 복원: 기술 총량 `HP=B*(1+총량%p/100)`; 구성 기여 `HP=B*구성%p/100`. 둘을 혼동해 구성마다 +100을 더하지 않는다. B가 자기 무기인지 공통 기준인지, 해당 버전의 정확한 B가 무엇인지 기록한다. 이미 반올림된 옛 표만으로 정확 복원했다고 주장하지 않는다.
5. `strength.py` 기본 출력은 HP환산으로 바꾼다. `--unit standard-pp`는 해당 실행의 바닐라 공통 기준, `--unit self-pp`는 명시적인 자기 무기 기준이다. 영웅간 비교에 self-pp를 사용하지 않는다. 다른 버전끼리 %p를 비교할 때는 같은 기준 B를 고정해야 한다.
6. 기존 총점은 행동/생존/속도/유연성의 가중 지수다. HP나 OLS 회귀 잔차가 아니다. 총점·순위를 HP 정답으로 승격하지 않는다. 사거리/사용열의 상호배타적 기술을 상위3 평균으로 묶는 한계도 남는다.

## 이번 수정과 검증 경계

첫 수리는 반격의 연속 평균을 일반 공격과 같은 정수 피해 계산으로 맞추는 것이다. 예를 들어 무기11–20, 피해−60%, 명중 확정, 치명0, 방어0이면 기존6.2HP가 아니라 정수5–9의 평균7HP다. 방어50%라면 결과2/3/3/4/4로3.2HP다. 별도 수작업 기대값 테스트로 확인한다. 반격 기술 자체의 게임 수치는 바꾸지 않는다.

기존 280개(20영웅×바닐라/RB×7기술) 계산을 수정 전후 보관하고 구성 합, 유한 값, 바닐라 공통 분모와 자기 분모 역산을 검증한다. 수리와 관련 없는 기술 값은 같아야 한다. 모델 변경은 배포/게임 시험이 아니다.

다음 검증은 **스트레스의 인물별 실제 회복 행동 비용과 임계값 → 저항 감소의 포화/후속 횟수 → 스턴·밀치기·약화의 공동 행동 방지 → 치명 proc·과회복 → 사거리/사용열의 실제 파티 기회비용** 순서다. 기존 가정을 몰래 새 계수로 바꾸지 않고 원본·수정안·근거·입력·결과를 나란히 남긴다. 실전 관찰이 없는 가정을 '실측 보정 완료'로 표시하지 않는다.
