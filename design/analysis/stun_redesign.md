# 3열 닿는 기절 가늠하기 (2026-10-14, 제안 단계)

- 수치는 1렙(명중 +5·치명 보정 +1·기절 확률 +10%p / 레벨). 가치는 모델(5렙), 표준 평타 7.7 HP 기준 %p.
- 전수 데이터: [stun_survey.md](stun_survey.md) (RB 12개·바닐라 12개 기절 기술, 기절 확률 장신구 16개, 몬스터 열별 위협). 데이터 커밋 `52b7a61`.
- 같은 날 처음 낸 안(이 파일의 이전 판)은 대상 1·2·3열 4개만 보고, 1·2열 기절 기준을 잘못 잡고, 치명 보정 가격을 빼서 폐기.

## 1. 기준: 1·2열 기절 (제작자 판정 — 서로 맞아떨어진다)

기본 = 명중 90, 피해 −50%, 일반 기절, 1·2열 → 1·2열. 나머지는 이 기본에서 특징을 맞바꾼 것.

| 기술 | 기본에서 바꾼 것 | 모델(5렙) |
|---|---|---|
| 성전사 기절의 일격 | 강한 기절 ↔ 피해 −60% (중간값) | +34 |
| 결투가 부츠 | 사용 1·2·3열·전진·밀치기 1·공세 자세 / 명중 95 → 90으로 맞출 것 | +50 → +41 |
| 중보병 성채의 일격 | 사용 1·2·3열 + 밀치기 1 ↔ 피해 −60% | +47 |
| 현상금 사냥꾼 어퍼컷 | 밀치기 2 + 강한 기절 ↔ 대상 1열만, 피해 −67%, 치명 보정 +9로 변주 | +52 |

→ 1·2열 기절의 띠 = 모델(5렙) **+34 ~ +52**.

## 2. 3열 도달의 가격

- 왜 비싼가: 영웅 등급 편성에서 몬스터 1행동 위협(HP + 스트레스)이 1·2열 9.6·10.1, **3·4열 14.2·14.1** — 3열을 고를 수 있으면 1.41배 위협적인 적을 기절시킨다. 피해도 우선 처치 대상(후열)에 들어간다(R-STRAT-01).
- 모델 측정(기준 기절에서 대상만 1·2 → 1·2·3): **+46~53** (큰 무기일수록 큼). 1·2·3 = 1·2·3·4 = 2·3·4 (3열이 핵심).
- 같은 가치로 환산하면

| 3열 도달 하나 = | |
|---|---|
| 기절 등급 | 약 5단계 (한 단계 = ±9) |
| 피해 보정 | 35~50%p (무기 클수록 적게) |
| 치명 보정 | 약 +30 (+1 = 약 1.5) |
| 명중 | 약 +25~30 |

- 그래서 3열 닿는 기절은 **1·2열 기절과 같은 띠(+34~+52)에 들어오도록 다른 축을 그만큼 내준다.** 사용 열(어디서 쓰나)은 모델이 세지 않으므로 규칙으로 판단: 후열(3·4열)에서 쓰는 기절은 띠 아래쪽이어도 된다.
- 치명 보정은 조정 수단으로 쓰지 않는다(P-21) → 피해·등급·명중으로 맞춘다.
