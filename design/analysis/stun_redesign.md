# 기절 재설계안 — 특색은 다르게, 가치는 한 띠로 (2026-10-14, 제안 단계)

- 수치는 1렙(명중 +5·치명 보정 +1·기절 확률 +10%p / 레벨). 가치는 모델(5렙), 표준 평타(7.7 HP) 기준 %p.
- 데이터 커밋 `4c1d669`(HM-022 반영 후). 검증 스크립트: scratchpad `stun_plan.py`(PLAN 딕셔너리만 바꿔 재실행).

## 1. 바닐라에 일관성이 없는 이유 (데이터로 확인된 것)

- 공식이 없다. 같은 "1·2열 근접 단일 기절"인데 성전사 기절의 일격(명중 90·강한 기절)과 중보병 성채의 일격(명중 90·일반 기절)의 등급이 다르고, 3열에 닿는 둔기 강타·손아귀가 오히려 강한 기절이었다(바닐라 둔기 강타: 명중 95·강한 기절·피해 −65%·3열 도달 = +75%p).
- 지킨 관례는 하나뿐: **피해 없는 상태 기술은 명중 95, 피해 있는 기절은 90**(2015-12 패치 방향). 예외 2개 — 족쇄 95, 부츠 95.
- 가장 큰 원인은 **3열 도달의 가격**을 매기지 않은 것. 모델로 재면 3열 도달 하나가 기절 등급 5단계와 맞먹는다(아래).

## 2. 특징별 가격 (모델(5렙) %p, 기준 = 근접 1·2열 → 1·2열, 명중 90, 피해 −50%, 일반 기절)

| 바꾼 것 | 큰 무기(성전사 10-19) | 작은 무기(신비학자 7-13) |
|---|---|---|
| 기준 | +46 | +29 |
| **대상 1·2·3열 (3열 도달)** | **+99 (+53)** | **+75 (+46)** |
| 대상 1·2·3·4 / 2·3·4 | +99 | +75 |
| 대상 1열만 | +40 (−6) | +24 (−5) |
| 광역 ~1·2 | +112 (+66) | +90 (+61) |
| 강한 기절 (+10%p) | +55 (+9) | +38 (+9) |
| 약한 기절 (−10%p) | +37 (−9) | +20 (−9) |
| 피해 +10%p | +59 (+13) | +38 (+9) |
| 명중 +5 | +55 (+9) | +37 (+8) |
| 원거리 | 차이 없음 | 차이 없음 |

- 모델은 **사용 열**(어디서 쓰나)을 기술 가치에 넣지 않는다 → 사용 열 유연성은 규칙으로 판단(후열 사용·넓은 사용 열 = 밀치기·전진 등 다른 대가).

## 3. 기절 설계 규칙 (제안: R-STUN-01~05)

1. **명중**: 피해 있는 기절 90, 피해 없는 기절 95. 예외 없음.
2. **등급**: 강 110 / 일반 100 / 약 90 (1렙). 한 등급 = 약 9%p.
3. **3열 도달은 비싸다**(+45~53%p). 3열에 닿는 피해형 기절은 피해 −65% 이하(손아귀 −70, 둔기 강타 −65, 눈부신 빛 −75). 3열 대신 피해를 택한 기절도 둔다(족쇄).
4. **가치 띠**: 피해형 단일 기절은 모델(5렙) +50 안팎. 직업 대표 기절(손아귀, 가장 확실한 3열 기절 + 횃불 −5 대가)은 +70 이하까지.
5. **다른 범주는 별도**: 피해 없는 기절(섬광탄·혼란 기체 폭발)과 광역 기절(실명 기체·연막탄)은 이 띠 밖에서 따로 본다.
