# R-AUDIT-25: 같은 적의 후속 피해로 평가한 방어 약화 (2026-10-25)

상태: 모델 개선 및 test 적용. 실제 전투 로그로 회귀 적합한 결과는 아니다. 비교 baseline은 cd4bee0이며 main/push는 변경하지 않는다.

- SB-024 노출: 피해 -45%, 대상1~4열. 명중90(기술1), 치명2.5%, 받는 치명8~10%p, 속도-4~-8, 은신 해제, 후퇴1·사용321 유지.
- ANT-005 섬광 가루: 방어도 -10/-11/-12/-14/-15%p(2턴). 명중 약화·은신 해제·적용100~140% 유지. 중간 수열은 기존 정수 성장 패턴을 사용한 구현 선택이다.

## 이전 식의 문제

이전 PROT 가격은 평균(min(PROT 감소, 적 PROT)) × 고정 공격값7.17 × 후속횟수 × 따로 평균낸 약화 성공률이었다. 실제 무기 피해·최소 방어 피해 감소·피해 반올림과 같은 적의 저항 상관이 빠진다. 회피 감소와 PROT 감소를 따로 더하면 동시에 걸렸을 때의 상호작용도 빠진다. 공통 지속 상한2 때문에2턴/3턴 약화가 동일했다. 표식 조건부 포효 치명 약화를 항상 적용으로 계산하던 것도 고쳤다.

## 새 식과 단위

ΔD = E[변경 후 같은 적에 대한 후속 직접 피해 − 변경 전 같은 적에 대한 후속 직접 피해]

V = 직접 피해 + ΔD + 통제/예방 HP 환산 + 회복/스트레스 HP 환산 + 치명 부수효과

잔차(%p) = (V후 − V전) / 8.14872802734375 × 100

분모는 R-AUDIT-24 고정 표준평타다. 후보마다 재추정하지 않는다. 여기서 잔차는 동일 기술의 기존 효과 예산을 차감한 차이이며, 통계 회귀잔차나 바닐라 중간 기술의 추정값이 아니다. 기술 총값은 V/표준×100−100, 성분/차이는 HP/표준×100이다.

EHP=HP/(1−PROT)는 연속 근사 진단값으로만 제공한다. EHP 감소를 실제 피해 증가에 다시 더하지 않는다. 실제 타격은 기존 REA 확인 커널(float32, 일반 피해 ceil 구간, 최대 피해×1.5 치명, PROT 최소 감소·roundf)을 사용한다. 새 전체 상태 처리 엔진까지 역분석한 것은 아니다.

## 입력과 가정

- 명중→일반/치명→해당 적의 약화 저항→개시 공격 후 생존을 같은 분기에서 계산한다. 개시 공격으로 죽은 적의 후속 약화 가치는0이다.
- 한 effect 안의 PROT+회피는 한 번의 성공으로 함께 적용한다. 별도 effect는 명중/치명에 조건부 독립인 성공 판정으로 모델링한다. 독립성·세부 판정순서는 엔진 검증 대상이다.
- 장신구 없는 바닐라20영웅의 같은 레벨 무기·무기 치명·기본 명중85+5×레벨을 동등 가중한다. 실제 선택 기술 회전이나 관측 파티 분포가 아니다.
- 동일 적의 PROT·회피·약화 저항을 묶는다. 기존 일반 몬스터 균등 표본 유지(챔피언64종, 보스/오브젝트 제외). 출현 빈도 추정이 아니다.
- 기본 후속 공격1.5회/라운드, 첫창0.5, 이후 생존가중(1−0.393)^k. 실제 지속만큼 최대3창. 2턴은1.107창,3턴은1.475449창. 기존 행동경제 가정이며 새 관측으로 적합한 값이 아니다.
- 표식 유지율0.3은 가정. 조건을 끄면 포효 치명 약화 추가값0. 피해받음 배율의 modifier 순서는 아직 근사다.
- 유한1~3회 타격 분포를 별도 계산한다. 현재HP10/30/60, PROT0/20/40/60%, 성전사/나병 후속 공격으로 과잉 피해를 제한한다. 이 결과를 생존가중 피해에 또 합산하지 않는다.

## 사거리·보호·속도

기존 모델과 같은 본편 .5.mash 통로/방 가중치를 사용한다. 초기 은신 적이 있는119행 중1~3열 대응 가능90행, 가중 도달률104/139=74.82%;1~4열은119행·100%. 캠페인 전체 출현율이 아니다. 원래 은신 해제 HP가격1.14는 유지한 가정이며 새 도달률만 데이터로 확인했다. 절대 가격·적 이동/증원/다른 해제기는 미포함이다.

당기기는 기존 편성 전체 재배열/위협 모형으로4열 제외 손실을 계산한다. 속도 약화는 기존 선행 확률/예방 행동 HP 모형을 유지한다. 개시 턴 즉시 재정렬·특정 적 AI 대응을 새로 확인한 것은 아니다.

보호 무시·해체·차단은 유지하지만 절대 가치를 완전히 가격화하지 못한다. 4열 보호 대상에게 이를 쓰지 못하는 손실도 잔차에 완전히 반영되지 않는다. 따라서 -0.19%p는 모든 보호 상황까지 동등하다는 증거가 아니다. 자기 전진/후퇴의 실제 조합 가치도 미해결이다.
