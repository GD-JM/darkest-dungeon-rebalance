## 수정 결과

- 찌르기: 원본 효과가 참조하는 원본 ID의 수정 버프를 빌더가 누락했다. 승인된 30/32/35/37/40을 포함하도록 두 빌더를 수정했다. native ID와 소비 조건은 유지한다.
- 날쌘 돌진: main 및 공개판 +20 확인. 로컬의 과거 +10 잔여값을 +20으로 교정한 기록은 별도 로컬 변경으로 보존한다.
- 노출: 속도 약화 삭제라는 오기를 회피·받는 치명타 약화 삭제로 정정. 뱀의 형상은 1열 도착을 보장하지 않으므로 전진1칸으로 표기.
- 몰이 사격: 밀치기 확률 100은 기술1레벨 값이었다. 100~140으로 범위를 명시.
- 야만인: 자기 약화가 전투 전체 지속이라는 단정 삭제. 역병 의사: 모두를 치료한다는 표현을 대상과 자신 출혈·중독 해제로 구체화.
- 본편 21장과 통합판 21장 실제 CDN 파일을 내려받아 로컬 이미지 해시와 대조. 갤러리는 한국어 소개5+비교27, 수정 후 게시 검증은 배포 영수증에 별도 기록한다.

카드는 바닐라 대비 변경 요약이며, 유지된 모든 효과를 빠짐없이 적는 기술 사전이 아니다. 단일 수치는 기술1레벨, 범위는1~5레벨. 700행 참조 해석 성공을 엔진 실전 시험으로 주장하지 않는다. 회피 소비, 반격 결합, 화상 처리의 과거 엔진 근거를 유지하되 이번 작업은 파일·게시 이미지 정합성 검증이다. 새 밸런스 수치는 도입하지 않는다.
