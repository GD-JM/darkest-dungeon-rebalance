# 밀치기·당기기 기술 분석

원본 데이터 기준. `*` = DLC 영웅.
- 방법은 `stun.md`, `dot.md`와 같다.
- 영웅 주 열은 `hero_ranks.md` 기준이다.
- 이동 성공률 = 명중률 × (이동 확률 − 이동 저항). 영웅 던전·5레벨·몬스터 중앙값 기준(회피 22.5, 이동 저항 75).
- 기대 피해 = 5레벨 무기 평균 × (1+피해 보정) × 명중률.
- 자기 이동은 원본 `.move 뒤 앞` 값이다. 광대 대단원 `.move 3 0`(뒤로 3칸), 독주 `.move 0 3`(앞으로 3칸)으로 방향을 검증했다.

## 3. 확정 법칙

| # | 법칙 | 일치 |
|---|---|---|
| M1 | 이동 확률 1레벨 **100**, 레벨당 **+10%p**. 예외: 석궁사수 사냥돌 발사·총사 산탄(수치 동일)은 75 시작, 4→5레벨 증가 0(105 고정). 결투가 부츠는 110 | 1레벨 10/12, 증가 46/48 |
| M2 | **이동 거리는 레벨로 오르지 않는다** | 12/12 |
| M3 | 몬스터 이동 저항: 같은 몬스터가 견습→베테랑 **+20**, 베테랑→영웅 **+20**. 중앙값 30 → 52.5 → 75 | 102/103, 98/102 |
| M4 | **밀치기 대상은 전부 1·2열 안**, **당기기 대상은 전부 3·4열을 포함** | 8/8, 4/4 |
| M5 | 레벨이 맞으면 이동 성공률이 약 50~69%로 유지된다. **유일한 예외는 사냥돌 발사·산탄으로, 43% → 40% → 28%로 레벨이 오를수록 떨어진다** | 10/12 |

## 4. 경향

### 4-1. 밀치기는 단독 기술이 아니라 부가 효과다
- 8개 중 다른 효과가 없는 것은 수치가 같은 사냥돌 발사·산탄 2개뿐이다. 기절과 결합한 것이 3개, 자기 이동과 결합한 것이 4개다.
- 그래서 표준형도 기절이 붙은 성채의 일격이 뽑혔다(최빈값 불일치 3). "순수 밀치기 표준"은 원본에 없다.

### 4-2. 당기기는 "후열을 끌어내는" 전용 도구다
- 4개 전부 3·4열까지 닿고, 사용 가능 열이 3~4개로 넓다. 절반은 시체 제거도 한다.
- 역할: 뒤쪽 적을 앞으로 끌어내 근접 기술 사거리에 넣는다.

### 4-3. 당기기가 더 비싸게 매겨졌다
- 가격표 차이 평균: 밀치기 +5.1(영거리 사격 +51 제외 시 −1.5), 당기기 −10.2.
- 3·4열 도달의 가치로 해석할 수 있다. 기절 분석의 "가격표는 대상 열 범위를 반영하지 않는다"(stun.md 7-4)와 같은 결론이다.

### 4-4. 노상강도 영거리 사격: 서브 열 전용 + 복귀 이동의 원본 선례
- 노상강도 주 열(2·3) 밖인 1열에서만 쓴다. 쓰고 나면 자신이 **뒤로 1칸** 빠져 주 열로 돌아간다.
- 대신 피해 보정 +50으로 가격표보다 51 싸다. 게임 전체에서 가장 크게 이탈한 기술이다.
- G-03(서브 열 활용) 설계 틀로 쓸 수 있는 선례이면서, 가격이 과한 사례다.

## 5. 표준형과 가감 분해

### 5-1. 밀치기 표준형: 중보병 성채의 일격
근접 / 사용 1·2·3열 → 대상 1·2열 단일 / 피해 보정 −60 / 명중 90 / 밀치기 1칸 확률 100 / 기절 + 자신 앞으로 1칸

| 기술 | + 더한 것 | − 뺀 것 / 대가 | 피해 보정 변화 | 판정 |
|---|---|---|---|---|
| 결투가* 부츠 | 명중 +5, 이동 확률 +10 | — | **+20** | 표준보다 모든 면에서 같거나 좋다 → **싸게 삼** |
| 현상금 사냥꾼 어퍼컷 | 거리 +1(2칸) | 사용 1·2열, 자기 이동 없음 | −7 | 정가 |
| 괴인 박치기 | 거리 +1(2칸), 회피 약화 | 명중 −10, 기절 없음 | +35 | 기절을 빼고 피해를 삼 → 약간 쌈 |
| 노상강도 영거리 사격 | 원거리, 명중 +5, 자신 뒤로 1칸 | 사용·대상 1열만, 기절 없음 | **+110** | **크게 쌈** (가격표 +51) |
| 나병환자 축출 | 거리 +2(3칸), 시체 제거, 자기 효과 | 사용·대상 1열만, 명중 −5, 기절 없음 | +20 | 약간 비쌈 (−14) |
| 석궁사수 사냥돌 발사 · 총사* 산탄 | 원거리, **광역 1·2열**, 후열(3·4) 사용, 명중 +5 | 이동 확률 −25(75, 5레벨 105에서 정지), 기절 없음 | +10 | 정가지만 확률 성장 결함 |

### 5-2. 당기기 표준형: 방패 파괴자* 구멍내기
원거리 / 사용 1~4열 → 대상 1~4열 단일 / 피해 보정 −50 / 명중 90 / 당기기 2칸 확률 100 / 보호 해제·보호 막기·속도 약화 + 자신 앞으로 1칸

표준형이 DLC 영웅 기술이다. 당기기 기술이 4개뿐이라 대표성이 약하다.

| 기술 | + 더한 것 | − 뺀 것 / 대가 | 피해 보정 변화 | 판정 |
|---|---|---|---|---|
| 현상금 사냥꾼 이리 오너라 | 표식 | 대상 3·4열만, 보호 해제·속도 약화·자기 이동 없음 | −30 | 정가 |
| 도망자* 판 뒤엎기 | 근접, 시체 제거, 자기 효과 | 거리 −1(1칸), 명중 −5 | +40 | 약간 비쌈 (−6.8) |
| 신비학자 악마의 아귀팔 | 시체 제거 | 사용 2·3·4열, 대상 3·4열만, 약화·자기 이동 없음 | 0 | **비쌈** (−20.6) |

## 6. 스펙 순위

이동 효과의 가치는 상황에 크게 좌우된다. 여기서는 **도구로서 믿을 만하고 두루 쓰이는지**를 기준으로 삼는다.
1. 이동 성공률
2. 함께 오는 제어·유틸(기절, 표식, 시체 제거, 보호 해제)
3. 도달 범위
4. 주 열에서 쓸 수 있는 열 수
5. 거리
6. 피해

### 6-1. 밀치기

| 순위 | 기술 | 근거 |
|---|---|---|
| 1 | 결투가* 부츠 | 이동 69%(최고) + 기절 46%, 주 열 3개 |
| 2 | 중보병 성채의 일격 | 이동 57% + 기절 44%, 주 열 3개 |
| 3 | 노상강도 영거리 사격 | 이동 60%, 기대 피해 17.3(최고), 1열에서 쏘고 주 열로 복귀 |
| 4 | 현상금 사냥꾼 어퍼컷 | 이동 57% + 기절, 2칸, 주 열 1개(2열) |
| 5 | 나병환자 축출 | 3칸(최장) + 시체 제거, 1열 전용 |
| 6 | 괴인 박치기 | 2칸 + 회피 약화, 이동 50%(명중 80) |
| 7 | 석궁사수 사냥돌 발사 / 총사* 산탄 (공동) | 광역이지만 이동 28%, 레벨이 오를수록 떨어짐 |

### 6-2. 당기기

| 순위 | 기술 | 근거 |
|---|---|---|
| 1 | 방패 파괴자* 구멍내기 | 전 열 도달 + 보호 해제·막기, 주 열 3개 |
| 2 | 신비학자 악마의 아귀팔 | 3·4열 도달 + 시체 제거, 주 열 3개 (가격표보다 비쌈) |
| 3 | 현상금 사냥꾼 이리 오너라 | 3·4열 도달 + 표식(현상금 사냥꾼 표식 연계), 주 열 2개 |
| 4 | 도망자* 판 뒤엎기 | 전 열 도달 + 시체 제거, 피해 7.4(최고)지만 거리 1칸 |

## 7. 설계 의도 추론

1. **이동도 확률·저항 +40으로 성공률을 유지했다.** 석궁사수·총사의 광역 밀치기만 예외라, 의도인지 누락인지 확인이 필요하다.
2. **밀치기는 다른 효과의 부가 가치로 붙이고, 당기기는 후열 공략 도구로 따로 만들었다.**
3. **서브 열 전용 기술에 복귀 이동을 붙인 선례가 있다**(영거리 사격).

## 8. 모드 적용 시사점 [제안]

- **틀**: 이동 확률 100 + 레벨당 +10, 거리 고정, 밀치기는 1·2열 대상 / 당기기는 3·4열 포함.
- **G-02**: 석궁사수 사냥돌 발사·총사 산탄의 확률 성장을 복원한다(예: 75→115 또는 100 시작). 레벨이 오를수록 약해지는 유일한 이동 기술이다.
- **G-03**: 영거리 사격 패턴(서브 열에서 사용 → 자기 이동으로 주 열 복귀)을 서브 열 기술 설계 틀로 쓴다. 단, 영거리 사격 자체는 가격표 +51 과대라 G-00 관점에서 검토 대상이다.
- **가격 규칙**: 당기기가 밀치기보다 약 10%p 비싸다. 3·4열 도달 가격을 별도 항목으로 두자는 기절 분석 제안(stun.md 7-4)과 합쳐 설계한다.
