# 전용 장신구로 읽는 영웅 방향 감사 A (2026-10-23, test 브랜치)

대상 7명(전수): 괴인, 유물수집상, 석궁사수, 현상금 사냥꾼, 성전사, 결투가, 총사

## 읽는 법

- **방법**: 영웅 전용 장신구가 원 개발사가 의도한 영웅상이라고 본다. 조련사에 먼저 적용해 검증한 방법이다.
  - 장점(+)은 **방향**이다.
  - 대가(−)는 **가드레일**이다. "이 장신구를 끼면 이것은 포기하라"는 뜻이다.
- **장신구 출처**: 전부 열어 `hero_class_requirements`로 거르고, 강화 효과 ID는 수치·조건까지 풀었다. 아레나는 제외했다.
  - 파일: `trinkets/base.entries`, 진홍빛 궁정(`crimson_court.entries/sets`), 광기의 색채(`com.entries`, `special_com.entries`), 총사 DLC(`musketeer.entries`), 결투가 DLC(`duelist.entries/sets`)
  - 킥스타터 등급 중 이 7명 전용은 0개다.
  - 한국어 이름은 `str_inventory_title_trinket<id>`(koreana)를 따른다.
  - `in_rank`는 0부터 센다. `in_rank 3` = 4열이다.
  - `actorStatus X`는 "X 상태인 대상에게", `is_actor_status X`는 "자신이 X 상태일 때"다.
- **현재 기술**: `mods/Rebalance` test 브랜치 작업 트리(영웅 `.info.darkest` + 모드/바닐라 효과 + 모드/바닐라 강화)를 직접 풀었다.
  - 바닐라 비교 기준은 설치 원본 `*.info원본.darkest`다.
  - 수치는 **1레벨**(`.level 0`)이다. 성장 폭이 필요하면 "1→5"를 함께 적었다.
- **판정**
  - **잘 맞음**: 축을 받치는 기술이 둘 이상이거나, 정체성 기술 하나가 확실히 받친다.
  - **약함**: 기술은 있으나 수치가 작거나 한 개에만 걸린다.
  - **없음**: 받치는 기술이 0개다.
  - **가드레일 위반**: 장신구가 포기하라는 것을 리밸런스가 핵심으로 만들었다.
- **앞선 감사**: `lore_audit_A.md`(main 기준, 총사 제외)와 판정이 같은 곳은 확인만 하고 옮겼다. test 브랜치 변경(BH-020~023, DUE-011·012, MUS-112~119)은 새로 반영했다.
- 강함 모델은 이번에 다시 돌리지 않았다. 인용한 %p는 변경 기록의 "모델(5렙)" 값이다.

### 데이터 메모

- **연기 나는 해골**(유물수집상): 강화 ID `TRINKET_com_ant_smoking_skull_blight_res_D15`가 `com.buffs.json`에 **두 번** 정의돼 있다.
  - 첫 정의는 명중 −0.15, 둘째 정의는 중독 저항 −0.15다.
  - 엔진은 뒤 정의로 덮는 것으로 보고 "명중 −15, 중독 저항 −15%"로 읽었다(lore_audit_A와 같다). 게임 툴팁 확인 전이다.
- **영원의 가면**(현상금 사냥꾼): 강화 ID는 `def_vs_husks`인데 규칙은 `always`다. 실제로는 조건 없는 회피 +15다.
- **총사 진홍 장신구 2개**: 석궁사수 진홍 장신구와 **같은 강화 ID**를 쓴다. 세트 효과도 `SET_arb_PROT_B1`(방어도 +25%)로 같다. 개발사는 총사를 석궁사수의 쌍둥이로 설계했다.

- 체력 26, 회피 7.5, 방어도 0, 속도 7, 무기 6–11

- 부러진 열쇠(받는 스트레스 +10%): "괴인의 힘은 스트레스로 치른다"(야영 기술과 같은 주제)를 기절 빌드에도 적용한다.

### 1-4. 제안 (최소 변경)

1. **변신 대가 하한을 지킨다.** 동료 6·턴당 4 아래로 더 내리지 않는다. 억제의 자물쇠는 대가를 비율로 깎는 매우 희귀 장신구라, 기본 대가가 더 줄면 장신구가 비게 된다(P-20).
2. (선택, 낮은 우선) **박치기 사용 열 4·3·2 → 4·3·2·1.**
   - 이유: 바닐라에 있던 1열 사용을 되살리면 진홍 세트의 "1열 피해 +20%"가 쓸 기술이 2개 → 3개로 는다. ABO-001의 4열 복귀 경로는 그대로 남는다.
   - 대가: ABO-001 기록의 "1열에서 2칸 밀치기는 손해"라는 판단과 부딪친다. 제작자 판단 사항이다.
3. 기절·중독 축은 잘 맞으므로 손대지 않는다.

| 기절 | 기절의 일격: 대상 1·2, 명중 90, 피해 −50%, **강한 기절 110%**(→150, 바닐라 일반 100%, CRU-003) | **잘 맞음** (틀 쪽 변경) |
| 근접 피해 | 강타(0%), 기절의 일격(−50%), 성스러운 돌격(0%, 4·3열 사용 → 전진 1). 광신적 고발은 원거리라 제외 | **보통** (바닐라부터) |

**멀어진 변경**

- CRU-001: 전장 치료 4·5렙 회복이 4–5 → 4–4, 5–6 → 4–5로 줄었다. 회복 장신구의 절대 이득이 소폭 감소한다.
- 대신 받는 회복 +20%를 붙였고, 1렙은 변화가 없다. 작은 이탈로 본다.

### 5-4. 제안

1. **현 상태 유지.** 가드레일 구조(회복 빌드 ↔ 딜 빌드)가 장신구 그대로 살아 있다.
2. 앞으로 회복량을 더 내리지 않는다. 회복 장신구 2개가 받쳐야 할 기본값이다.

## 6. 결투가 (duelist)

- 저항: 약화 40, 나머지 30

### 6-1. 전용 장신구 전부

| 장신구 | 등급 | 효과 전부 |
|---|---|---|
| 철테 두른 장화 | 일반 | 기절 확률 +10%, 공격 태세에서 치명 +4% |

| 금박 망토 | 고급 | 받는 치명 −6%, 자신이 표식일 때 받는 치명 추가 −6%·회피 +10 |

| 챔피언의 망토 | 매우 희귀 | **2열·4열에서** 피해 +20%, **1열·3열에서 회피 −10** |

### 6-2. 방향 축과 가드레일

| 방향 축 | 미는 장신구 수 | 장신구 |
|---|---|---|

**가드레일**

- 챔피언의 망토(1·3열 회피 −10): **"1·3열에 머물지 말고 2·4열을 오가라"**.
- 면도날 힐트(출혈 저항 −20): 대가가 작다.
- 망령의 재치(체력 −33%): 맞지 않는 운용을 강제한다.

### 6-3. 현재 기술과 대조 (1레벨)

| 축 | 받치는 기술 | 판정 |
|---|---|---|
| 반격 | 예측(턴 소모 없음, 반격 2턴), 전투 시작 반격, 눈속임 반격 피해 +25%(→+35%, 4턴) | **잘 맞음** |
| 공격 태세 | 날쌘 돌진(피해 +25%, 치명 9%), 최후의 일격(−70%, DUE-010), 장화 차기(−60%, DUE-006) | **잘 맞음** |
| 기절 | 장화 차기: 기절 100%(→140) + 밀치기 1, 110% | **잘 맞음** (1개지만 장신구 설명이 이 기술을 가리킨다) |
| 자기 표식 | 눈속임·날쌘 돌진: 자기 표식 2턴 | **잘 맞음** |
| 2↔4열 교대 | 이탈: 사용 2·1 → 뒤로 3칸, 4열에서 회피 +30, 2턴간 어느 열에서나 공격. 날쌘 돌진: 사용 4·3·2 → 앞으로 2칸 (4열 → 2열). 최후의 일격은 전 열 | **잘 맞음** (2 → 4 → 2 순환이 기술 이동량으로 정확히 구현됨) |
| 약화 | 눈속임(방어도 −10(→−20) + 표식 대상 명중 −10, 110%), 이탈(적 피해 −10%(→−15), 2턴, DUE-012 신규) | **보통** (DUE-007이 줄이고 DUE-012가 보완) |
| 출혈 대상 관통 | 결투가의 출혈 기술 0개 | **없음** (바닐라부터). 단, 조련사 원거리 출혈 리워크·현상금 마름쇠 광역 출혈로 파티 시너지가 전보다 쉽게 성립한다 |
| 1열 대상 (세트) | 공격 6개 모두 1열을 칠 수 있음 | 잘 맞음 |
| 무피격 | 찌르기 자기 회피 +15(→+25) 3턴(바닐라 +40~50 4턴, DUE-005·011), 치명 버프 회피 +10 | 보통 |

**멀어진 변경**

- DUE-007: 눈속임 방어도 감소가 −20 → −10으로 줄어, 아카데미 반지(약화 확률)가 키우는 약화의 크기가 절반이 됐다. DUE-012가 두 번째 약화를 추가해 보완했다.
- DUE-005·011: 찌르기 회피 하향. 회피를 직접 미는 장신구는 없어 위반은 아니다. 망령의 재치 운용은 조금 어려워졌다.

### 6-4. 제안

1. **현 상태 유지.** 장신구 틀(2↔4 교대·반격·자기 표식)이 기술 이동량까지 정확히 맞는 영웅이다.
2. 면도날 힐트는 결투가에게 출혈을 주지 말고 파티 시너지로 둔다. 조련사 출혈 리워크와 짝이다. 결투가에 출혈을 더하면 P-12(체감 최소화)에 어긋나고 조련사와도 겹친다.

**틀 밖 축 (장신구 0개)**

- 기절: 연막탄 1·2열 광역 기절 100%, 전투당 3회 (MUS-104·115)
- 방어 관통: 관통탄 10%(→30%), 치명 버프 (MUS-103·111)

### 7-4. 제안

1. **표식 보너스 하한 유지.** 관통탄 표식 대상 피해 1렙 +25%보다 더 깎지 않는다.
   - 이유: 진홍 장신구 은 화승총 탄환이 표식 축 하나를 통째로 맡는다. "표식 딜 축소"(MUS-111)는 이미 틀에서 한 걸음 멀어졌다.
2. 기절·관통·은신(장신구 밖 축)의 증설은 자제하고, 강화가 필요하면 4열 피해·약화·이동 축으로 한다. 장신구가 함께 커지는 쪽이 끼울 이유를 만든다.
