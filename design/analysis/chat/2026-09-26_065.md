## 비용 구조를 보니 관행에 근거가 있습니다

기술 강화 비용과 요구 조건입니다.

| 단계 | 비용 | 요구 결의 레벨 |
|---|---|---|
| 기술 해금 | 1000 골드 | 0 |
| 1 → 2레벨 | 250 | 1 |
| 2 → 3레벨 | 750 | 2 |
| 3 → 4레벨 | 1250 | 3 |
| **4 → 5레벨** | **2500 (직전의 2배)** | **5 (두 단계 점프)** |

장비도 같습니다. 750 / 1750 / 3000 / **6000**, 요구 결의 1 / 2 / 3 / **5**.

**마지막 강화만 비용이 2배이고 요구 조건도 두 단계 뜁니다.** 그래서 "마지막 증가폭 2배"는 골드당 가치를 평평하게 유지하려는 설계로 읽힙니다.

| 성장 형태 | 예 | 골드당 성능 (1→2 / 2→3 / 3→4 / 4→5) |
|---|---|---|
| **도약형** | 저격 표식 피해 +10 / +10 / +10 / **+20** | 25 / 75 / 125 / **125** — 유지 |
| **등차형** | 회복 +1 / +1 / +1 / +1 | 25 / 75 / 125 / **250** — 절반으로 악화 |

## 그래서 제 판단은 이렇습니다

**1. 관행 자체는 합리적입니다.** 비용이 2배 뛰는데 성능이 그대로 오르면 마지막 강화가 최악의 투자가 됩니다. 도약은 그걸 막습니다.

**2. 다만 적용이 자의적이라 기술마다 마지막 강화의 가치가 2배 차이 납니다.** 같은 2500골드를 쓰는데 저격은 +20을 받고 은총은 +1을 받습니다. "모든 기술이 쓸모 있게"(G-02)라는 관점에서는 결함입니다.

**3. 확률 계열이 전부 등차인 것은 오해하면 안 됩니다.** 효과 확률 수열 67개 중 66개가 등차(100 → 140, +10씩)인데, 이건 성장이 아니라 **유지비**입니다. 몬스터 저항이 견습 → 영웅에서 +40 오르므로(R-CMB-05), 확률 +40은 성공률을 제자리에 묶어 둘 뿐입니다. 여기서 도약을 주면 오히려 후반 제어가 과해집니다. **확률이 등차인 건 옳습니다.**

**4. 진짜 문제는 회복 쪽입니다.** 도약을 받은 회복 기술은 성녀 신성한 위무, 신비학자 재구축, 고행자 구제 — **이미 회복이 몰려 있는 세 영웅**입니다. 반면 겸업 회복(역병 의사 야전 의술, 유물수집상 강화의 연막, 석궁사수 붕대)은 전부 등차라 마지막 강화 가치가 절반입니다. **관행이 편중을 키우는 방향으로 작동하고 있습니다.** G-05 문제의 숨은 축입니다.

**5. 지속 피해가 계단인 건 어쩔 수 없습니다.** 값이 2~9라 정수 단위로는 매끄럽게 만들 수 없습니다.

## 모드에 적용할 방침 (제 권고)

| 계열 | 방침 | 이유 |
|---|---|---|
| 효과 확률 | **원본 그대로 등차 유지** | 저항 상승 상쇄용 유지비. 건드리면 후반 제어 과잉 |
| **회복** | **등차로 통일하되 5레벨 값을 넉넉히** | 우리 목표가 "중반부터 회복 선택지 확보"라, 중반을 깎는 도약형은 목적과 반대 |
| 버프·피해 배율 | 원본이 도약이면 도약 유지 | 사용감 보존(P-12) |
| 새로 만드는 수치 | **끝값을 4등분 가능한 수로 고른다** | 자동으로 등차가 되고 계단·도약이 안 생김 |

이 기준이면 앞서 제안드린 값이 맞습니다. 역병 의사·석궁사수를 **3 / 4 / 5 / 6 / 7**로 두면 끝값이 상한(7.0)에 딱 맞고 등차가 됩니다. 성전사 전투 치유도 2 / 2.5 / 3 / 3.5 / 4로 등차입니다.

한 가지 남는 선택은 **성녀·신비학자·고행자의 도약을 그대로 둘지**입니다. 그대로 두면 5레벨에서는 여전히 이들이 앞서고, 우리가 올린 겸업 회복은 4레벨까지만 경쟁력이 있습니다. 편중을 수치로 확실히 줄이려면 이 셋의 마지막 도약분(위무 +1, 재구축 +1.5, 구제 +3%p)을 등차로 되돌리는 방법이 있는데, 이건 성녀를 건드리지 말라고 하신 결정과 충돌합니다. 어떻게 할지 정해 주시면 그대로 맞추겠습니다.
