**답: 전체의 5.4%, 설계자가 값을 자유롭게 고르는 수치(버프·디버프·회복·지속 피해)만 보면 13.5%입니다.**

명중(+5/레벨 104개 전부 등차)과 치명타(+1/레벨)와 효과 확률(+10%p/레벨)은 규칙으로 고정돼 있어 도약이 원천적으로 0개라, 전체 비율은 희석된 값입니다. 실제 "관행이 적용될 수 있는 자리"에서는 7~8개 중 1개꼴입니다.

## 2. 마지막 도약 23개 전부

거의 전부가 **자기 강화·팀 강화·표식 피해 배율**이고, 공통점은 **끝값이 10·15·20·25·30·33·50·100 같은 예쁜 수**라는 것입니다. 즉 "L1을 정하고 L5를 예쁜 수로 올림 → 중간은 +1씩"의 결과물입니다.

| 유형 | 수열 | 해당 기술 |
|---|---|---|
| 5→10 (×2) | 5/6/7/8/**10** | 도굴꾼 단검 투척(명중), 야만인 아드레날린 분출(속도), 광대 전투의 발라드, 중보병 지휘, 중보병 고양, 도망자 화톳불 |
| 10→15 | 10/11/12/13/**15** | 도굴꾼 그림자 은신(회피), 나병환자 복수(피해), 유물수집상 엎드려!(중독 저항) |
| 20→25 / 20→30 | 20/21/22/23/**25**, 20/22/24/26/**30** | 역병 의사 강화 작용제, 야만인 아드레날린 분출(회피) |
| 15→20 (약화) | −15/−16/−17/−18/**−20** | 석궁사수 제압 사격, 총사 연막탄, 신비학자 취약화 주술 |
| 기타 약화 | −5/−6/−7/−8/**−10**, −20/−23/−26/−29/**−33** | 중보병 포효, 나병환자 위협 |
| 조건부 피해 배율 | 20/23/26/29/**33** | 도굴꾼 돌진·단검 투척(Poison Killer) |
| 조건부 피해 배율 | 25/30/35/40/**50** | 노상강도 권총 사격(표식) |
| 조건부 피해 배율 | 50/60/70/80/**100** | 석궁사수 저격, 총사 조준사격 |
| 회복 | 13/15/17/19/**22**, 1/1/1/1/**2** | 신비학자 기괴한 재구축, 성전사 격려의 함성(최소 회복) |

회복군에서 도약은 2개뿐입니다. 회복은 도약보다 **계단**이 주류입니다.

## 3. 등차가 아닌 나머지 유형

**(a) 반올림 등차 = 계단형 — 92개, 가장 흔한 "비등차"**
L1→L5를 4등분했을 때 나눠떨어지지 않아 정수로 반올림된 것들입니다. 설계 의도는 등차인데 표현이 계단이 된 경우라, 사실상 등차로 봐야 합니다.
- 지속 피해 **22/23개**가 전부 여기 (예: 출혈 2/3/4/4/5, 중독 3/3/4/4/5)
- 회복 **18/26개** (예: 성녀 신성한 은총 4/4/5/6/7, 역병 의사 3/3/4/5/6)
- 디버프 46개 (−20/−23/−26/−30/−33, −20/−22/−25/−27/−30 처럼 평균 2.5·3.25 단위)
- 고행자 구제(33/35/37.5/40/43)와 방혈(35/39/42/46/50)도 여기에 들어갑니다 — 이전에 제가 구제를 "마지막 도약"으로 분류했는데, 4등분(+2.5%p)의 반올림 범위 안이라 **도약이 아니라 계단**이 맞습니다. 따라서 "회복 도약을 되돌릴지" 검토 대상은 성녀 위무와 신비학자 재구축 2개로 줄어듭니다.

**(b) 불규칙 — 11개 (어떤 규칙으로도 설명 안 됨)**

| 영웅 | 기술 | 수열 | 증가폭 |
|---|---|---|---|
| 현상금 사냥꾼 | 끝장내기 (기절 킬러) | 25/33/40/50/60 | +8 +7 +10 +10 |
| 중보병 | 수호자 | 15/18/22/26/30 | +3 +4 +4 +4 |
| 중보병 | 고양 (스트레스 방어) | −10/−10/−15/−15/−20 | 0 +5 0 +5 |
| 도굴꾼 | 단검 투척 (표식 피해) | 25/28/32/36/40 | +3 +4 +4 +4 |
| 조련사 | 경비견 | 10/12/14/17/20 | +2 +2 +3 +3 |
| 노상강도 | 결투가의 진격 (반격 피해) | 0/2/3/4/5 · −40/−33/−25/−20/−15 | +2 +1 +1 +1 · +7 +8 +5 +5 |
| 성녀 | 신성한 위무 (최대) | 3/3/3/4/5 | 0 0 +1 +1 |

앞쪽이 느리고 뒤쪽이 빠른 **후반 가속형**(끝장내기, 수호자, 경비견, 위무, 전투 치유)이 대부분입니다. 마지막 한 칸이 아니라 4·5레벨 두 칸에 걸쳐 가속한다는 점만 다르지, 동기는 도약형과 같습니다.

**(c) 마지막 감속 — 1개**
유물수집상 고양의 연막 회피 3/5/7/9/**10** (+2 +2 +2 **+1**). 전체에서 유일하게 마지막이 더 적게 오릅니다. 끝값 10을 맞추려다 생긴 것으로 보입니다.

**(d) 비단조 = 사실상 데이터 오류 — 3개**
- 고행자 재기 회복 지속 턴 2/**3**/**2**/3/3 — 2레벨이 3레벨보다 높습니다.
- 석궁사수 결집 신호탄 / 총사 스키트 사격 스트레스 회복 확률 60/60/**67**/**60**/67 — 3레벨이 4레벨보다 높습니다.

이 3개는 우리 모드에서 고쳐도 사용감에 영향이 없는(P-12 안전) 순수 버그 수정 후보입니다.

## 4. 정리

- 도약은 **소수(5.4%)이고 특정 자리에 몰려 있습니다**: 자버프·팀버프·조건부 피해 배율. 회복·지속 피해·확률은 거의 전부 등차/계단입니다.
- 도약의 정체는 "관행"이라기보다 **끝값 우선 설계**입니다. L5를 10·15·20·25·33·50·100 같은 수로 먼저 박고, L1에서 +1씩 올리다 남는 차이를 마지막에 몰아준 것입니다. 이 해석은 도약 23개 중 21개의 끝값이 5의 배수(또는 33)라는 사실과 일치합니다.
- 따라서 우리가 새 수치를 만들 때 지킬 규칙은 하나면 충분합니다: **끝값을 (끝값 − 시작값)이 4로 나눠떨어지는 수로 고르면 도약이 저절로 사라집니다.** 제안했던 회복 3/4/5/6/**7**이 정확히 이 형태입니다.
