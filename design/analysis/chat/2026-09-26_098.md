## 조정안 4개

### ① 정맥 절개: 속도 약화 제거 (HWY-002)

> `HW Open Vein SPD Debuff 1~5` 제거. 출혈과 출혈 저항 −33%는 유지.

- 효과가 **출혈 + 출혈 저항 −33% + 속도 −3**으로 셋입니다. 여기에 명중 115(전 기술 최고)까지 붙어 잔차 2위입니다.
- **출혈 저항 −33%는 출혈 딜러 정체성과 직결되지만 속도 −3은 무관합니다.** "정맥을 갈라 피를 흘리게 한다"에 속도 감소가 붙을 이유가 약합니다(P-19).
- 잔차 **+95.8 → +76.8** (−19)

### ② 영거리 사격: 피해 +40% → +30%

> HWY-001 원안 완주 (현재 +50%에서 +40%까지 내려온 상태)

- 잔차 1위(+99.6)의 원인은 **피해 보너스 +40%**입니다.
- 다만 이미 명중 −5와 **자기 후퇴 2칸**(빌드 전환 장치)으로 재설계하셨으니, 이건 **선택 사항**으로 봅니다. 후퇴 2칸은 "1열에서 쏘고 3열로 빠진다"는 실질 비용이자 원거리 빌드의 입구라, 그 자체가 이미 대가입니다.
- 잔차 **+99.6 → +89.6** (−10)

### ③ 포도탄 발사: D안 — 원거리 빌드의 광역

> 명중 95 → **100**, 치명타 보정 −5 → **+2**, 피해 −50% → **−55%**

- 1레벨 기준 명중 75 → 80, **실제 치명타 −4% → 3%**
- **자기가 거는 취약(받는 치명타 +8%)을 자기 치명타(4%)로 못 받는 모순**을 해소합니다. 메모에 쓰신 "포도샷으로 치명타 받을 약화 주고 반격으로 치명타 빵빵"이 수치로 성립하려면 포도탄 자신의 치명타도 음수를 벗어나야 합니다.
- 기대 피해는 13.6 → 13.9로 거의 그대로, **적중률 70% → 75%**로 분산만 줄어듭니다.
- 잔차 **+26.5 → +37** (+10)

### ④ 추적탄: 반격 추가 + 자버프 축소 — 원거리 빌드의 핵심

> `Hwy Riposte 1~5` 추가. 대신 `Tracking Buff`의 피해 **+20% → +10%**, 치명타 **+8 → +5**

**이게 메모에 쓰신 "테이크에임 원거리 기술로 반격이 발동하게 바꿨다"인데, 아직 적용 안 돼 있습니다.** 현재 `Tracking Buff`에는 반격이 없습니다.

**근거**

| | 결투가의 진격 | 추적탄 |
|---|---|---|
| 종류 | **근접** | **원거리** |
| 자기 이동 | **앞 1칸** | 없음 |
| 사용 열 | 4·3·2 | **4·3·2·1 전 열** |
| 제한 | 없음 | **전투당 1회** |

원거리 빌드(3열 상주)에서 반격을 켜려면 결투가의 진격을 써야 하는데, **자기 전진 1칸 때문에 2열로 밀려나 빌드가 깨집니다.** 추적탄은 자기 이동이 없고 전 열에서 쓸 수 있어, **자리를 지킨 채 반격을 켜는 유일한 수단**이 됩니다.

**두 기술이 반격을 나눠 갖는 게 중복이 아닌 이유**: 조건이 정반대입니다.
- **결투가의 진격** = 앞으로 나가며 반격 자세 → **근접 빌드**
- **추적탄** = 자리를 지키며 조준 → **원거리 빌드**, 대신 전투당 1회

차별화를 더 주려면 **추적탄의 반격 지속을 3턴 → 2턴**으로 두면 됩니다.

- 반격 +47, 자버프 축소 −16 → 잔차 **+0.6 → +31.6**
- 추적탄이 "턴 버리는 기술"에서 "빌드를 여는 기술"이 됩니다
