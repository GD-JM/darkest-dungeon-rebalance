# 잔차가 뭐야? 기절 50 65 이건 무슨 의미? 피해 65 이런거 무슨의미?

- 날짜: 2026-09-26, 출처: 대화 기록 `cc3c95a9-aeea-4409-9feb-eb162a738694.jsonl`
- 대화 당시 답변 원문(그 뒤 데이터가 바뀌었을 수 있음). 질문 원문:

> 잔차가 뭐야? 기절 50 65 이건 무슨 의미? 피해 65 이런거 무슨의미?

---

## 1. 단위: "피해 보정 %p"

기술 줄을 그대로 보면 이렇습니다.

```
성전사 기절의 일격 (5레벨)
.atk 110%  .dmg -50%  .crit 4%  .launch 21  .target 12  .effect "Stun 5"

조련사 둔기 강타 (5레벨)
.atk 115%  .dmg -65%  .crit 9%  .launch 21  .target 123  .effect "Hero Strong Stun 5"
```

`.dmg -50%`는 **"이 기술은 영웅 무기 피해의 50%를 깎고 나간다"**는 뜻입니다. 성전사 무기가 10-19면, 기절의 일격은 5-9.5로 때립니다.

여기서 핵심은 — **원 개발사가 이 `.dmg` 값을 "가격표"로 쓰고 있다**는 것입니다. 기술에 뭔가 좋은 걸 붙이면 그만큼 `.dmg`를 깎습니다. 그래서 **"피해 보정 %p"가 이 게임의 화폐**입니다. 기술이 무언가를 얻으려면 피해로 값을 치릅니다.

## 2. "기절 +50"이 무슨 뜻인가

영웅 기술 140개 전부를 회귀분석해서, **각 효과가 평균적으로 피해를 몇 %p 깎는지** 구한 게 가격표(R-TRADE-01)입니다.

| 효과 | 피해를 깎는 양 |
|---|---|
| 기절 | **−50%p** |
| 반격 | −47 |
| 표식 | −45 |
| 추가 대상(광역) | −24 |
| 약화 / 자기 강화 | −19 |
| 원거리 | −12 |
| 밀치기·당기기 | −9 |
| 사용 열 1개당 | −5 |

즉 **"기절이 붙은 기술은 안 붙은 기술보다 피해가 평균 50%p 낮다"**가 데이터로 나온 사실입니다. 그래서 저는 이걸 뒤집어서 읽었습니다 — **기절이라는 효과의 값어치 = 50%p**.

그러니까 제 표의 **"기절 +50"은 "이 기술은 50%p짜리 물건을 받았다"**는 뜻입니다.

## 3. "기절 +65"는 왜 더 큰가

기절 확률이 다르기 때문입니다.

- 성전사 기절의 일격: `Stun 5` = 확률 **140** (기본 기절)
- 조련사 둔기 강타: `Hero Strong Stun 5` = 확률 **150** (강한 기절)

확률 10%p 차이의 값을 **15%p**로 잡았습니다. 근거는 바닐라 자체입니다 — 강한 기절을 가진 기술들이 그 대가로 피해를 약 15%p 더 내고 있습니다(stun.md §8-3).

그래서 **강한 기절 = 50 + 15 = 65**, 약한 기절(사슬질, 확률 130) = 50 − 15 = **35**입니다.

## 4. "피해 65"는 지불액

둔기 강타의 `.dmg -65%`입니다. **이 기술이 실제로 치른 값**입니다.

받은 것과 낸 것을 나란히 두면 이렇게 됩니다.

| 조련사 둔기 강타 | %p |
|---|---|
| 강한 기절 | **+65** |
| 명중 115 (기본 110보다 +5) | +15 |
| 치명타 보정 +9 | +4 |
| 사용 열 2개 (1·2열) | +10 |
| 대상이 3열까지 닿음 | +15 |
| **받은 것 합계** | **+110** |
| 피해 −65% | **−65** |
| **잔차 (받은 것 − 낸 것)** | **+44** |

| 성전사 기절의 일격 | %p |
|---|---|
| 기본 기절 | +50 |
| 명중 110 (기본값이라 0) | +0 |
| 치명타 보정 +4 | +2 |
| 사용 열 2개 | +10 |
| 대상 1·2열뿐 (보너스 없음) | +0 |
| **받은 것 합계** | **+62** |
| 피해 −50% | **−50** |
| **잔차** | **+12** |

## 5. 잔차 = "받은 것 − 낸 것"

- **잔차가 크다 = 싼값에 많이 받았다 = 강하다**
- **잔차가 작다/마이너스 = 비싸게 샀다 = 손해 보는 기술**

둔기 강타는 110어치를 65에 샀고, 기절의 일격은 62어치를 50에 샀습니다. 둔기 강타가 **44 남고**, 기절의 일격은 **12 남습니다.**

## 6. 중요한 주의 — 절대값은 의미 없습니다

12개 전부 잔차가 양수인데, 이건 모든 기절 기술이 강하다는 뜻이 **아닙니다.** 제가 "지불"에 피해만 넣고, "기술 하나가 존재한다는 것 자체의 기본값"을 빼지 않았기 때문입니다. 그래서 **비교만 의미가 있습니다.**

12개 평균 잔차가 **+18**입니다. 이게 실질적인 정가선입니다. 여기에 맞춰 다시 읽으면:

| 기술 | 잔차 | 정가(+18) 대비 | 판정 |
|---|---|---|---|
| 조련사 둔기 강타 | +44 | **+26** | 크게 싸게 삼 |
| 신비학자 심연에서의 손아귀 | +44 | **+26** | 크게 싸게 삼 |
| 결투가 부츠 | +34 | +16 | 싸게 삼 |
| 현상금 사냥꾼 섬광탄 | +29 | +11 | 약간 싸게 삼 |
| 역병 의사 혼란 기체 폭발 | +24 | +6 | 정가 |
| 괴인 사슬질 | +18 | **0** | **정확히 정가** |
| 현상금 사냥꾼 어퍼컷 | +13 | −5 | 정가 |
| 성녀 눈부신 광채 | +12 | −6 | 정가 |
| 성전사 기절의 일격 | +12 | −6 | 정가 |
| 역병 의사 실명 기체 | +9 | −9 | 약간 비싸게 삼 |
| 중보병 성채의 일격 | +2 | −16 | 비싸게 삼 |
| 야만인 야만스러운 함성! | −27 | **−45** | **크게 비싸게 삼** |

가운데 7개(혼란 기체 ~ 실명 기체)가 ±10 안에 몰려 있습니다. **바닐라 기절 기술 대부분은 정가에 잘 맞춰져 있고, 위로 튄 게 둔기 강타·손아귀, 아래로 튄 게 함성**이라는 게 결론입니다.
