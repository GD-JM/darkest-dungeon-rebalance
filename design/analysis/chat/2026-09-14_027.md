# 스턴 기술의 가장 표준적인 기술을 알려주고 그것에서 각자의 기술들이 어떤 것이 가감된 형태인지를 보여줘

- 날짜: 2026-09-14, 출처: 대화 기록 `cc3c95a9-aeea-4409-9feb-eb162a738694.jsonl`
- 대화 당시 답변 원문(그 뒤 데이터가 바뀌었을 수 있음). 질문 원문:

> 스턴 기술의 가장 표준적인 기술을 알려주고 그것에서 각자의 기술들이 어떤 것이 가감된 형태인지를 보여줘

---

기절 기술의 표준형은 **성전사 기절의 일격**입니다. 기절 기술 12개의 속성별로 가장 흔한 값과, 원 개발사의 가격 공식(기절 하나 = 피해 보정 −50%p)을 동시에 만족하는 기술은 이것 하나뿐입니다. 나머지 11개는 이 표준에서 무엇을 더하고 무엇을 뺐는지로 분해했습니다.

## 1. 표준형: 성전사 기절의 일격

| 속성 | 표준값 | 근거 |
|---|---|---|
| 종류 | 근접 | 12개 중 6개 |
| 사용 열 → 대상 | 1·2열 → 1·2열 단일 | 가장 흔한 조합 |
| 명중 (1레벨) | 90 | 피해를 주는 기절 8개 중 5개 |
| 피해 보정 | −50 | 가격 공식 예측 −52.7과 일치 |
| 기절 확률 (1레벨) | 100 (기본 등급) | 12개 중 7개 |
| 부가 효과·제한 | 없음 | |

모든 기절 기술 공통 규칙: 기절 지속 1턴, 명중 +5/레벨, 기절 확률 +10%p/레벨.

## 2. 피해를 유지한 기술 = 표준 + 가산 − 감산

"가격 공식 예상"은 원 개발사의 가격 공식이 이 변형에 매겼을 피해 보정 변화입니다. 실제 변화가 예상보다 크게 음수면 비싸게 산 것, 덜 음수면 싸게 산 것입니다.

| 기술 | + 더한 것 | − 대가 | 피해 보정 변화 (가격 공식 예상) | 판정 |
|---|---|---|---|---|
| **결투가 부츠** | 사용 1·2·3열, 밀치기 1, 자신 앞으로 1칸, 명중 +5 | 없음 | **+10** (+3) | **가장 싸게 삼** |
| **신비학자 심연에서의 손아귀** | 원거리, 대상 +3열, 강한 기절(110), 치명타 +9 | 횃불 −5 | **0** (−12) | **싸게 삼** |
| 괴인 사슬질 | 원거리, 사용 2·3열, 대상 +3열, 명중 +5 | 약한 기절(90) | −10 (−12) | 피해는 정가인데 기절 등급까지 내줘 약간 손해 |
| 중보병 성채의 일격 | 사용 1·2·3열, 밀치기 1, 자신 앞으로 1칸, 치명타 +5 | | −10 (+3) | 약간 비쌈 |
| 현상금 사냥꾼 어퍼컷 | 밀치기 2 | | −17 (−9) | 약간 비쌈 |
| 조련사 둔기 강타 | 대상 +3열, 강한 기절(110), 명중 +5, 치명타 +5 | | −15 (−0.3) | 가격 공식에 없는 강한 기절·3열 도달 값을 피해로 치름 |
| 성녀 눈부신 광채 | 원거리, 사용 2·3·4열, 대상 +3열, 횃불 +6 | | −25 (−18) | 정가~약간 비쌈 |

## 3. 피해를 버린 기술

피해를 버리면(피해 보정 −100, 치명타 불가) 4개 모두 **명중 +5**를 받고, 거기에 아래를 추가로 받습니다.

| 기술 | + 더한 것 | − 대가 |
|---|---|---|
| 현상금 사냥꾼 섬광탄 | 원거리, 사용 2·3·4열, 대상 2·3·**4**열, 강한 기절(110), 위치 섞기 | 1열 대상 불가 |
| 역병 의사 혼란 기체 폭발 | 원거리, 사용 2·3·4열, 대상 2·3·**4**열, 위치 섞기, **시체 제거** | 1열 대상 불가 |
| 역병 의사 실명 기체 | 원거리, **3·4열 동시 공격** | 1·2열 사용·대상 불가, **전투당 3회** |
| 야만인 야만스러운 함성! | **1·2열 동시 공격**, 강한 기절(110) | **전투당 3회**, 자신 피해 −20%·속도 −3 |

## 4. 원본에서 읽히는 교환 비율

1. **원거리·후열 사용:** 피해 보정 −10~−25를 내거나, 피해를 전부 버립니다.
2. **3열까지 닿기:** 가격 공식에는 항목이 없지만 실제로는 피해 −10~−25나 기절 등급 하락과 함께 옵니다. 손아귀만 대가가 없습니다.
3. **4열까지 닿기:** 피해를 버린 기절에만 있습니다.
4. **강한 기절(110):** 피해 −15, 피해 포기, 횃불 −5 중 하나와 짝입니다.
5. **밀치기:** 1칸은 피해 약 −10, 2칸은 −17입니다. 부츠만 예외입니다.
6. **여러 적 동시 기절:** 피해 포기 + 전투당 3회가 기본이고, 강한 기절까지 붙으면 자기 약화도 붙습니다.
7. **피해를 버리면 명중 +5**를 받습니다.

## 5. 이 규칙에서 가장 벗어난 두 기술

- **결투가 부츠:** 표준보다 사용 열·밀치기·자기 이동·명중을 더 받았는데, 피해 보정은 오히려 10 좋습니다.
- **신비학자 심연에서의 손아귀:** 원거리·3열 도달·강한 기절·높은 치명타를 받고 피해 대가가 0입니다. 치르는 건 횃불 −5뿐입니다.

반대로 성채의 일격·어퍼컷·눈부신 광채는 표준보다 약간 비싸게 샀습니다. 두 이탈 기술은 G-02·G-04 검토 후보로 적어 두었습니다. 결투가는 DLC라 G-04에도 해당합니다.

표와 교환 비율은 [stun.md](mods/Rebalance/design/analysis/stun.md) 8절에 정리했고, 원칙서 R-EFF-01에 표준형을 명시해 커밋했습니다. 작업 중이신 고행자·방패 파괴자 파일은 이번에도 커밋에 넣지 않았습니다.
