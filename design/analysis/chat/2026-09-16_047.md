## 버프안 1: 자버프를 깎고 자가 회복을 넣는다 (사용자 방식)

| 영웅 | 기술 | 깎는 것 | 넣는 것 (1→5레벨) |
|---|---|---|---|
| 도굴꾼 | 극약처방 | 회피 +13 → **+8**, 속도 +4 → **+2** | 출혈·중독 치료 유지 + **회복 3 → 6** |
| 야만인 | 아드레날린 분출 | 피해 +30 → **+15** | 치료·명중 유지 + **회복 1→4를 4 → 8** (표준형) |
| 방패 파괴자* | 뱀의 형상 | 속도 +4 → **+2** | **회복 3 → 6** (전투당 2회 유지) |
| 결투가* | 찌르기 | 자기 회피 +35 → **+25** | **회복 2 → 4** (공격 + 자힐, 선례: 성녀 심판) |
| 노상강도 | 추적탄 | 자기 피해 +20 **제거** | **회복 3 → 6** (전투당 1회) |
| 중보병 | 수호자 | 자기 방어 버프 유지 | **회복 2 → 4** (보호 동반이라 −5 교환) |
| 현상금 사냥꾼 | 죽음의 표식 | 자기 속도 +5 → **+3** | **회복 2 → 4** |
| 광대 | 독주 | 회피 +30 → **+20** | **자기 스트레스 회복 5** (광대는 스트레스 정체성 유지) |
| 도망자* | 도피 | - | 은신 중 지속 회복 5 → **7** (이미 있는 값 소폭) |

이 안이 끝나면 **체력 또는 스트레스 자가 회복이 없는 영웅은 0명**이 됩니다(G-05 1번 목표).

## 기존 제안과 충돌하는 부분

- **노상강도 HWY-003(추적탄 피해 −80 → −60)은 철회하고**, 이 패치의 자기 회복 추가로 대체해야 합니다. 둘 다 넣으면 추적탄이 과해집니다.
- 결투가·방패 파괴자·도망자는 DLC라 G-04(이상치 정상화) 방향과 같습니다. 자버프를 깎고 회복을 주는 건 방향이 맞습니다.

## 구현 메모

- **새 자기 회복은 전부 신규 효과로 만듭니다.** `RB <약어> Self Heal 1~5` 형태로 각 영웅 효과 파일에 넣고, 기술 줄에서 참조합니다. 바닐라 효과는 건드리지 않습니다.
- **역병 의사 야전 의술의 자기 치료 제거는 참조만 지우면 됩니다**(`Cureself` 삭제). `Cure`와 `Cureself`는 공유 효과라 수정하면 안 됩니다.
- 회복량이 기술 줄(`.heal a b`)에 있는 기술(성녀·성전사·석궁사수·총사·유물수집상·역병 의사)은 영웅 파일에서 바로 고칩니다.
