# 아니 모든 기술의 1렙 치명타에 어떤 공식이 있는지 궁금하다고 어떤 기술은 56789 어떤 기술으 01234

- 날짜: 2026-09-26, 출처: 대화 기록 `cc3c95a9-aeea-4409-9feb-eb162a738694.jsonl`
- 대화 당시 답변 원문(그 뒤 데이터가 바뀌었을 수 있음). 질문 원문:

> 아니 모든 기술의 1렙 치명타에 어떤 공식이 있는지 궁금하다고 어떤 기술은 56789 어떤 기술으 01234 이런식이잖아

---

먼저 정정할 게 있습니다. 직전 답변에서 "단일 18개 평균 +0.89, 광역 95개 평균 +2.15"라고 쓴 건 대상 파싱 오류(`.target "12"`를 2타겟으로 센 것)로 **앞뒤가 뒤집힌 숫자**였습니다. 실제로는 광역이 훨씬 적고, 치명타는 광역에서 **깎입니다**. 그리고 이게 1레벨 값을 결정하는 가장 큰 요인이었습니다.

## 결론부터: 1레벨 값은 3단계로 정해집니다

```
실제 치명타 = 무기 치명타(영웅별 1~6%, 전 영웅 +1%p/레벨)
            + 기술 .crit 보정
```

**1단계 — 기술이 치명타를 가질 자격이 있는가**

| | 개수 | 1레벨 값 |
|---|---|---|
| `is_crit_valid False` (표식·기절·연막 등) | 18 | 0, 성장 없음 |
| 피해가 없는 버프기 | 28 | 0, 성장 없음 |
| 공격기 | 85 | 아래 2·3단계 |

**2단계 — 광역이냐 단일이냐 (가장 강력한 규칙)**

| | 개수 | 보정 범위 | 평균 | 중앙값 |
|---|---|---|---|---|
| 광역 (연쇄 `~` / 전체 `@`) | 17 | **−10 ~ +2** | −2.9 | 0 |
| 단일 대상 | 68 | **−1 ~ +9** | +4.0 | **+5** |

**광역 공격은 +2가 상한이고 예외가 하나도 없습니다.** 음수 보정 11개 중 10개가 광역입니다(유일한 예외는 결투가 회수 −1). 회귀로 뽑으면 광역 계수는 **−6.2%p**입니다.

광역의 음수값은 무작위가 아니라 **"실제 치명타를 0% 부근으로 만드는 값"** 입니다. 무기가 6%인 석궁사수·총사는 −10, 5%인 노상강도는 −9, 1~2%인 나병환자·괴인은 −4, −3 — 전부 합계 −4%~+1%로 수렴합니다.

| 기술 | 보정 | 무기 | 실제 1레벨 |
|---|---|---|---|
| 제압 사격 / 연막탄 | −10 | 6 | −4% |
| 포도탄 발사 | −9 | 5 | −4% |
| 꿰뚫기 | −6 | 6 | 0% |
| 번뜩이는 비도 | −5 | 6 | +1% |
| 사냥개 습격 | −5 | 4 | −1% |
| 광신적 고발 | −4 | 3 | −1% |
| 가르기 | −4 | 1 | −3% |
| 할퀴기 | −3 | 2 | −1% |

즉 **"이 기술로는 치명타가 뜨지 마라"** 를 값으로 구현한 것입니다. 치명타는 피해 ×1.5 + 파티 스트레스 회복 + 자기 강화까지 주기 때문에, 광역 견제기에서 그게 터지는 걸 막은 것입니다.

**3단계 — 단일 대상 68개 안에서의 등급**

| 시작값 | 개수 | 정체 |
|---|---|---|
| **+5** (5/6/7/8/9) | **24개, 최빈** | 주력 딜링기 표준값 — 저격, 조준사격, 끝장내기, 분쇄, 절개, 심판, 약화 저주, 사냥개 돌진… |
| +6 ~ +9 | 15개 | 영웅 간판 기술 — 신비학자 제물 암습·심연에서의 손아귀 +9, 결투가 날쌘 돌진 +9, 도굴꾼 돌진·단검 투척 +8, 광대 저며내기 +8, 노상강도 권총 사격 +7.5, 괴인 분노 +7.5 |
| 0 ~ +4 (0/1/2/3/4) | 28개 | 보조 딜링·연계기 — 강타, 기절의 일격, 정맥 절개, 유혈사태, 어퍼컷, 이리 오너라, 얼굴 찍기, 빛의 손길… |
| −1 | 1개 | 결투가 회수 |

## 검증: 어디까지가 공식이고 어디부터가 손맛인가

| 모델 | R² |
|---|---|
| 피해 보정만 | 0.05 |
| 피해 + 광역 → **보정 = 4.41 + 0.018×피해% − 6.23×광역** | **0.466** |
| + 부가효과(지속·기절·표식·약화·자버프·이동) + 무기 | 0.517 |
| + 영웅 고정효과까지 | 0.511 |
| 단일 대상 68개 **안에서만** 속성으로 설명 | 0.201 |

**광역 여부가 설명력의 대부분을 차지하고, 단일 대상 안에서 +5냐 +8이냐 0이냐는 속성으로 거의 설명되지 않습니다(R² 0.20).** 85개 중 속성 모델로 정확히 맞는 건 9개뿐이고 중앙 오차는 2.3%p입니다. 즉 **단일 대상 구간은 수식이 아니라 "이 기술이 이 영웅의 간판인가"라는 손 배정**입니다.

그 손 배정에도 경향은 있습니다: 같은 영웅의 두 기술을 비교하면 **125쌍 중 90쌍(72%)에서 피해가 높은 쪽이 치명타도 높습니다.** 치명타는 약한 기술을 보상하는 통화가 아니라, 주력기에 더 얹어 정체성을 만드는 장치입니다.

## 그래서 "56789 vs 01234"의 답

| 시작 계열 | 조건 |
|---|---|
| 5/6/7/8/9 이상 | **단일 대상 + 주력 딜링기** (영웅당 1~3개) |
| 0/1/2/3/4 | 단일 대상이지만 보조기, 또는 광역 중 피해가 덜 깎인 것 |
| 0 고정(성장 없음) | 피해가 없는 버프·표식·기절 유틸 |
| 음수 | **광역 + 저피해 견제기**, 값은 −(무기 치명타)만큼 = 실제 0% |

한 줄로 쓰면: **기본 +5에서 출발해, 광역이면 −6 정도 깎고 실제 치명타가 0%가 되도록 무기값까지 상계, 간판 기술이면 +2~+4를 더 얹는다.**

이걸 `design/rules.md`에 **R-CRIT-01**로 기록해둘까요? 우리 모드에서 야만인 함성에 시체 제거를 넣거나 광역기를 손볼 때, "광역인데 치명타 +5" 같은 바닐라 위반을 자동으로 걸러낼 수 있는 기준이 됩니다. 아직 데이터 파일은 건드리지 않았습니다.
