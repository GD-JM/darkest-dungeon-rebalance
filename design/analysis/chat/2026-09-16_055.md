## 1. 1·2열 동시 기절: 현재 야만인 함성 하나뿐입니다

2명을 한 번에 기절시키는 기술은 원본에 2개인데, 1·2열은 함성, 3·4열은 역병 의사 실명 기체입니다. 원본 법칙(광역 분석 N3)은 **"적 2명 대상 피해 없는 광역은 둘 다 기절 + 전투당 3회"**입니다.

### 후보 비교

| 후보 | 현재 | 개조안 | 기술 가치 | 영웅 행동 가치 / 순위 | 판정 |
|---|---|---|---|---|---|
| **중보병 성채의 일격** | 1·2·3열 사용 → 1·2열 **단일**, 피해 −60, 기절 140%, 밀치기, 가격표 −10.4 | 대상 **~1·2 광역**, 피해 −60 → **−80** | 7.0 → **8.5** | 11.9 → 11.9 / **10위 유지** | **1순위** |
| 나병환자 가르기 | 1·2열 사용 → **~1·2 광역**, 피해 −50, 효과 없음, 가격표 −22.9 | **기절 추가**, 피해 −50 → −100 | 9.6 → **2.5** | 13.8 → 13.8 / 6위 유지 | 2순위 |
| 괴인 할퀴기 | ~1·2 광역, −50 | - | - | - | 괴인은 사슬질로 기절 보유 → 중복 |
| 성전사 광신적 고발 | ~1·2 광역, −40, 정가 | - | - | - | 성전사도 기절의 일격 보유 → 중복 |

### 중보병을 1순위로 보는 이유

1. **이미 기절을 가진 기술이라 이질감이 가장 작습니다(P-12).** 단일 → 2명으로 범위만 넓히는 변경입니다.
2. **가격이 맞습니다.** 추가 대상 1명은 −24%p입니다. 현재 −60에 −24면 −84가 정가인데, 지금 가격표가 −10.4(과소)라 **−80으로만 내려도 정가 부근**입니다. 총량도 유지됩니다(P-11).
3. **정체성과 맞습니다.** 중보병은 전열 방어·제어 담당인데 광역 제어가 없었습니다.
4. **순위가 안 변합니다.** 성채의 일격은 중보병 상위 3기술(지휘 14.2, 포효 11.3, 수호자 10.2)에 못 들어가기 때문입니다.

**설계 두 가지 중 선택**

| 안 | 내용 | 함성과의 차이 |
|---|---|---|
| A | 대상 ~1·2, 피해 −80, 기절 140%, **밀치기 유지**, 제한 없음 | 함성(150%, 전투당 3, 피해 없음)보다 약하지만 무제한 |
| B | 대상 ~1·2, **피해 없음(−100)**, 기절 140%, 밀치기 제거, **전투당 3회** | 원본 법칙 N3를 그대로 따름. 함성의 중보병 버전 |

밀치기까지 2명에게 들어가면 제어가 과해질 수 있어, 저는 A에서 **밀치기를 빼고 피해 −75**로 하는 절충을 권합니다(밀치기 시세 −9%p 반환).

### 나병환자안의 문제

제어가 없는 영웅에게 제어를 준다는 점은 좋지만, **가르기는 나병환자의 유일한 광역 공격**입니다. 기절을 붙이려면 피해를 −100까지 내려야 해서 기술 가치가 9.6 → 2.5로 떨어지고, "광역 딜러 → 광역 기절기"로 역할이 통째로 바뀝니다. 사용감 변화가 큽니다.

## 2. "싸다"는 표현: 축이 두 개입니다

제가 쓰는 숫자는 **서로 다른 두 가지**인데, 같이 쓰다 보니 헷갈리게 만들었습니다.

### 축 1: 가격표 차이 (단위 %p) — "규칙 대비 위치"

원본 기술 100여 개로 만든 회귀식입니다. 기술의 특징을 넣으면 "피해 보정이 얼마여야 하는가"가 나옵니다.

| 특징 | 피해 보정 값 |
|---|---|
| 기절 | −50 |
| 반격 | −47 |
| 적 표식 | −45 |
| 추가 대상 1명 | −24 |
| 약화 1개 / 자기 강화 | −19 |
| 원거리 | −12 |
| 밀치기·당기기 | −9 |
| 사용 열 1개 | −5 |
| 지속 피해 총량 1 | −1.9 |
| 조건부 추가 피해 | +3 |
| 자기 이동 | +17 |
| 자기 약화 비용 | +26 |

- **가격표 차이 = 실제 피해 보정 − 예측값**
- **+면 "싸게 샀다"**: 효과를 많이 달았는데 피해를 덜 깎였다 → 유저에게 이득, 규칙보다 후함
- **−면 "비싸게 샀다"**: 효과에 비해 피해를 많이 깎였다 → 규칙보다 박함
- 이 축은 **절대 성능이 아니라 설계 규칙 준수 여부**를 봅니다.

### 축 2: 모델 가치 (단위 HP) — "실제 성능"

1회 행동이 만들어내는 값을 전부 HP로 환산합니다. 직접 피해 + 지속 피해 + 기절(몬스터 1행동 4.26 HP) + 약화 + 회복 + 강화 − 자기 비용. 여기엔 **영웅 무기, 명중, 치명타, 대상 수**가 전부 들어갑니다.

### 두 축이 왜 어긋나는가

| 기술 | 무기 | 피해 보정 | 기대 직접 피해 | 가격표 차이 | 모델 가치 |
|---|---|---|---|---|---|
| 역병 의사 절개 | 10.0 | 0 | 8.2 | +19.5 | 13.3 |
| 노상강도 정맥 절개 | 12.5 | −15 | 9.8 | +43.0 | 15.6 |
| 고행자 처벌 | 8.0 | 0 | 7.4 | +44.6 | 16.6 |

가격표는 **무기·명중·치명타·대상 열 범위·방어 무시**를 모릅니다. 그래서 무기가 약한 고행자의 처벌이 "가격표 +44.6"으로 최상위인데 실제 직접 피해는 7.4로 셋 중 가장 낮습니다.

**앞으로 제가 쓰는 표기법을 이렇게 통일하겠습니다: `가격표 +19.5 / 실전 13.3`**

## 3. 영웅 능력치를 빼고 기술만 보는 게 옳은가 — 검토 결과

직접 계산했습니다. 가격표 잔차를 영웅 무기로 설명해 봤습니다.

```
잔차 ≈ 13.7 − 1.16 × (영웅 5레벨 무기 평균)
설명력 R² = 0.024, 잔차 표준편차 19.2 → 19.0
```

- **원 개발사는 기술 피해 보정을 정할 때 영웅 무기를 사실상 반영하지 않았습니다.** 무기로 설명되는 부분이 2.4%뿐이고, 무기를 보정해도 잔차가 거의 안 줄어듭니다(19.2 → 19.0).
- 약한 음의 경향(무기 1당 −1.16)은 있습니다. 무기 19.5인 나병환자의 기술은 평균적으로 −9 정도 박하게 매겨집니다.

**결론: 두 층을 나누되, 둘 다 봐야 합니다.**

| 층 | 무기 포함? | 쓰는 목적 | 적합한 판단 |
|---|---|---|---|
| **설계 층 (가격표)** | 제외 | 개발사의 설계 규칙 재현 | "이 기술이 규칙을 어겼나" |
| **실전 층 (모델 가치)** | 포함 | 실제 강함 | "실제로 세거나 약한가" |

- 설계 층에 무기를 넣으면 **개발사가 쓰지 않은 변수를 넣는 것**이라 규칙 추론 자체가 흐려집니다. 그래서 가격표에서 무기를 빼는 건 옳습니다.
- 다만 **조정 판단을 가격표만으로 하면 안 됩니다.** 예를 들어 조련사 사냥개 돌진은 가격표 +23.8(설계 위반)이지만 실전 기대 피해는 8.2로 평범합니다. 반대로 노상강도 영거리 사격은 가격표 +51, 실전 17.3으로 **두 축 모두 과대**입니다.

**제안하는 조정 우선순위 규칙**

| 순위 | 조건 | 예 |
|---|---|---|
| 1 | 두 축 모두 과대 | 영거리 사격, 정맥 절개 |
| 2 | 실전만 과대 (설계는 정가) | 방패 파괴자 꿰뚫기 |
| 3 | 설계만 과대 (실전 평범) | 사냥개 돌진, 역병 의사 절개 |
| 4 | 두 축 모두 과소 | 현상금 사냥꾼 마름쇠, 노상강도 추적탄 |

이 우선순위 규칙과 "무기는 가격표에 없다(R² 0.024)"는 발견을 원칙서(R-TRADE-01 보강)에 기록할까요? 기록해 두면 앞으로 제가 내는 모든 판단이 같은 기준으로 정렬됩니다.
