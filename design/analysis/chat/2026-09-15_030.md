# base.effects.darkest 여기에 스킬관련된 거 효과 다 있거든? 여기서 모드 가능한거라 이것도 

- 날짜: 2026-09-15, 출처: 대화 기록 `cc3c95a9-aeea-4409-9feb-eb162a738694.jsonl`
- 대화 당시 답변 원문(그 뒤 데이터가 바뀌었을 수 있음). 질문 원문:

> base.effects.darkest 여기에 스킬관련된 거 효과 다 있거든? 여기서 모드 가능한거라 이것도 내거 리밸런싱 폴더에 복사해서 옮겨야 하지 않을까?

---

base.effects.darkest를 통째로 리밸런싱 폴더에 복사하는 건 추천하지 않습니다. 효과는 모드에서 바꿀 수 있지만, 바꾼 효과만 새 이름으로 추가하는 방식이 더 안전합니다.

## 확인한 사실

| 항목 | 결과 |
|---|---|
| base.effects.darkest | 효과 1,187개 (220KB) |
| 영웅 기술이 쓰는 효과 | 731개. 이 중 base에 557개, 나머지 174개는 DLC 효과 파일 4개(고행자·도망자·방패 파괴자·결투가)에 있음 |
| base 효과 중 몬스터 기술이 쓰는 것 | 376개. 그중 29개는 영웅과 같이 씀 (출혈 Bleed 1~5, 보호 해제, 표식 해제 등) |
| 영웅 2명 이상이 같이 쓰는 효과 | 92개 |
| 원본 안에서 같은 이름이 중복 정의된 효과 | 26개. 같은 이름으로 다시 정의하면 어느 쪽이 적용될지 보장이 안 됨 |
| 구독 중인 모드의 효과 파일 6개 | 전부 **새 파일 + 새 이름**. base.effects.darkest를 덮어쓰는 모드는 하나도 없음 |

## 통째로 복사하면 생기는 문제

1. **다른 영웅과 몬스터까지 같이 바뀝니다.** 예를 들어 출혈 효과 "Bleed 3"을 고치면 그 효과를 쓰는 몬스터가 영웅에게 거는 출혈도 바뀝니다. 영웅끼리 공유하는 효과 92개도 한 영웅만 따로 조정할 수 없습니다.
2. **다른 모드와 충돌합니다.** 파일 전체를 덮어쓰니, 이 파일을 건드리는 다른 모드와 동시에 쓸 수 없습니다.
3. **게임 업데이트에 약합니다.** 원본 파일이 바뀌면 우리 사본이 옛날 내용으로 덮어써 버립니다.
4. **여전히 전부가 아닙니다.** DLC 영웅 효과는 다른 파일 4개에 있어서, base만 복사해서는 모든 영웅 효과를 다룰 수 없습니다.
5. **배포 원칙과 맞지 않습니다.** "원본과 다른 파일만 넣는다"는 원칙에 어긋나고, 안 바꾼 효과 수백 개까지 배포됩니다.

## 추천하는 방식

| 단계 | 사용자가 할 일 | 제가 할 일 |
|---|---|---|
| 1. 편집 | `heroes/<영웅>/<영웅>.effects_edit.txt`에서 수치를 고치고 밑에 `//` 메모를 씁니다. 그 영웅 기술이 쓰는 효과 줄만 모아 둔 편집용 사본이고, 게임은 읽지 않습니다. | (파일은 미리 만들어 둠) |
| 2. 정리 | "정리해줘" | 원본과 비교해 바뀐 효과만 찾습니다 |
| 3. 변환 | — | 바뀐 효과를 새 이름(예: `RB CRU Stun 3`)으로 `effects/rebalance_<영웅>.effects.darkest`에 추가하고, 그 영웅 기술 줄이 새 이름을 가리키게 바꿉니다 |
| 4. 기록 | — | 변경 항목 문서에 메모를 옮기고 커밋합니다 |

방패 파괴자 출시 수치 복원(SB-003~008) 때 이미 이 방식을 썼습니다.

**두 방식 비교:**

| | 통째 복사 (덮어쓰기) | 새 이름 추가 (추천) |
|---|---|---|
| 다른 영웅·몬스터 영향 | 공유 효과를 고치면 같이 바뀜 | 없음 (그 영웅 기술만 새 효과를 씀) |
| 다른 모드와 충돌 | 이 파일을 쓰는 모드와 충돌 | 없음 |
| 게임 업데이트 | 원본 변경이 가려짐 | 안 바꾼 효과는 원본이 그대로 적용 |
| DLC 영웅 효과 | 별도 파일이라 따로 복사 필요 | 같은 방식으로 처리 |
| 배포 파일 | 220KB 전체 | 바꾼 효과만 |
| 편집 편의 | 메모장으로 바로 수정 | 편집용 사본에서 바로 수정 (같음) |
