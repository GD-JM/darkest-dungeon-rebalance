## 야만인

### ① 함성의 대상 `~1234`가 아무 일도 하지 않습니다 — 최우선

```
.dmg -100%  .target ~1234  .effect "clear_corpses" "Adrenaline 5"
```

- `clear_corpses`는 `.target "target_group"`이라 **대상 열과 무관하게** 적 시체 전체를 지웁니다
- `Adrenaline 5`는 `.target "performer"`라 **자기에게만** 걸립니다
- 피해는 −100%

**즉 적 4명을 때리는 판정인데 적에게 일어나는 일이 하나도 없습니다.** 대상을 `~1234`로 하든 `12`로 하든 결과가 똑같습니다. 제 환산에서는 광역 4대상이 **+72%p**로 잡혀 잔차 +50이 나오지만, 실제 값어치는 0입니다.

플레이어 입장에서도 "전체를 향해 포효하는데 아무 표시도 안 뜬다"가 되어 P-19에 역행합니다.

**세 가지 선택지**

| 안 | 내용 | 잔차 | 평가 |
|---|---|---|---|
| **A** | 적 **약화** 추가(피해 −, 명중 −)하고 **자버프는 아드레날린 분출로 되돌림**. 대상 `~12` 또는 `~123` | 약 +9 | **권장** |
| B | 대상을 `~12`로만 축소, 현 구성 유지 | 약 +2 | 광역은 여전히 무의미 |
| C | 대상을 비워(`.target` 없음) 순수 자버프 기술로 | — | 아드레날린 분출과 완전 중복 |

**A안을 권합니다.** 그러면 역할이 이렇게 갈립니다.

- **함성** = 전열에 포효해 **적을 위축시키고(약화) 시체를 치운다** — 적에게 하는 기술
- **아드레날린 분출** = **자기를 끌어올린다**(자버프 + 자가 회복) — 자기에게 하는 기술

선례도 있습니다. 중보병 포효(`Disrupt`: 피해 −7, 명중 −10)가 정확히 "소리로 적을 위축시키는" 광역 약화입니다. 야만인 함성에 같은 계열을 붙이면 **광역 4대상이 실제로 작동**하고, 이름·모션과 기능이 일치합니다.

### ② 아드레날린 분출이 껍데기가 됐습니다

```
.atk 0%  .launch 4321  .effect "Cureself" "HellionHealSelf 5"   (자가 회복 4 + 치료)
```

자가 회복 **4**는 자가 회복 표준(조련사 상처 핥기 8.0)의 **절반**입니다. 한 턴을 써서 4 회복하고 디버프 하나 푸는 기술은 아무도 안 고릅니다(G-02 위반).

- A안을 택하면: `Adrenaline 5`가 돌아와 원래대로 강한 준비기가 됩니다
- A안을 안 택하면: **회복 4 → 7~8**로 올려야 합니다. G-05(자가 회복 확대) 목표와도 맞습니다

### ③ 돌파가 과지불입니다

탈진 제거의 대가로 피해 −50% → −60%를 하셨는데, **돌파에는 자기 전진 1칸(`.move 0 1`)이라는 부담이 이미 있습니다**(가격표 −17~−24).

| 기술 | 잔차 |
|---|---|
| 출혈 | +58 |
| 사악한 난도질 | +41 |
| 강철의 추모곡 | +23 |
| 유혈사태 | +17 |
| **돌파** | **−7** |

광역 3대상(~123) + 4·3·2열에서 사용 가능한 기술인데 야만인 기술 중 유일하게 마이너스입니다. **−50% 원복을 권합니다**(잔차 +3). 탈진 제거분은 출혈에서 이미 −26 반납했으니 총량은 맞습니다.

### ④ 전열 광역 기절이 게임에서 사라졌습니다

함성이 기절을 잃으면서 **1·2열을 동시에 기절시키는 기술이 0개**가 됐습니다. 광역 기절은 역병 의사 실명 기체(3·4열)만 남습니다. 의도하신 결과라면 그대로 두면 되지만, G-02 관점에서 빈 자리가 하나 생긴 건 기록해둘 값입니다.

### ⑤ 출혈은 재확인 결과 +10 높습니다

치명타 계수를 R-CMB-08 개정판(피해 0%일 때 1.6)으로 다시 계산하니:

| | 잔차 |
|---|---|
| 야만인 출혈 | **+60.9** |
| 방패 파괴자 살모사의 입맞춤 | +50.9 |

이전에 "+5 차이"라고 한 건 옛 치명타 계수(0.69) 기준이었습니다. **치명타 23%의 값이 제가 생각한 것보다 커서 격차가 +10으로 벌어집니다.** 야만인이 11위라 허용 범위지만, 판정이 바뀐 건 알려드립니다. 조이려면 치명타 14 → 12(실제 21%)면 +57.7로 좁혀집니다.

### ⑥ 이리 오너라가 최하위입니다

피해 −80%에 당기기 2 + 소표식뿐입니다. **당기기의 실측 가치도 밀치기처럼 낮을 가능성이 큽니다** — 몬스터는 앞으로 끌려나와도 화력이 평균 0.5 HP밖에 안 줄었습니다(후열형 54종 측정).

다만 당기기는 밀치기와 달리 **후열 적을 근접 사거리에 넣는** 전술 가치가 있어서, 실측만으로 판정하면 과소평가입니다. 그래도 −32는 낮습니다. **피해 −80% → −65%** 정도가 적정해 보입니다(잔차 −17).

### ⑦ 마름쇠는 BH-005 제안(−70%)까지 갈 여지가 있습니다

현재 −80%로 적용하셨는데, 원안은 −70%였습니다. −70%면 잔차 −7로 정가권에 들어옵니다.
