네, 15로 봤습니다. **그리고 그건 틀렸습니다.** 정확히는 15는 "명중 +5"의 값이 아니라 **"명중 +5 + 원거리 사거리"를 합친 값**이었습니다.

## 근거 ① 원본이 실제로 매긴 값 (회귀)

5레벨 공격 기술 131개를 다른 요소(기절·표식·반격·약화·광역·원거리·사용 열·지속 피해·자기 이동·자기 약화)를 전부 통제하고 회귀했습니다. R² = 0.646.

| 항목 | 피해 보정 계수 |
|---|---|
| **명중 1당** | **−0.43** |
| 사용 열 1개당 | −4.66 |
| 추가 대상 1당 | −9.96 |
| **원거리** | **−17.71** |
| 기절 | −49.10 |
| 반격 | −25.07 |
| 지속 피해 총량 1당 | −0.77 |

| 자기 약화 | +15.13 |

**명중 +5 = 2.2%p**입니다. 통제를 다 빼고 명중 하나만 넣어도 2.1%p로 거의 같습니다 — 즉 이 값은 모델 설정에 흔들리지 않습니다.

## 근거 ② 전투 수식으로 직접 계산

명중 +5는 적중률을 85% → 90%로 올립니다. 기대 출력이 **×1.0588**이 됩니다.

같은 효과를 피해 보정으로 내려면, 현재 피해 보정이 `m`일 때:

```
(1 + m') = (1 + m) × 1.0588
Δm = (1 + m) × 0.0588
```

| 기술의 피해 보정 | 명중 +5와 같은 값 |
|---|---|
| 0% (주력 딜링기) | **+5.9%p** |
| −50% (기절 표준형) | **+2.9%p** |
| −65% (둔기 강타) | **+2.1%p** |

**회귀값 2.2와 계산값 2~6이 겹칩니다.** 원 개발사의 가격과 실제 기댓값이 일치한다는 뜻이고, 그래서 이 숫자는 믿을 만합니다.

→ **명중 +5 ≈ 3%p** (피해 보정이 큰 기술은 2, 피해가 온전한 기술은 6까지)

## 그럼 R-TRADE-02의 "−10~−20"은 무엇이었나

원칙 자체가 틀린 게 아니라, **한 덩어리로 묶여 있던 것**입니다. 근접(명중 85)과 원거리(명중 90) 딜링기를 비교하면서 "원거리는 명중 +5를 받고 피해 −10~−20을 낸다"고 읽었는데, 회귀가 둘을 분리하니:

- 명중 +5 → **−2.2**
- 원거리(사거리) → **−17.7**
- 합 = **−19.9** ≈ 관찰했던 −10~−20의 상단

즉 **그 −10~−20은 거의 전부 "사거리" 값이었습니다.** 명중은 그중 10분의 1 남짓입니다.

`rules.md`의 R-TRADE-02를 이렇게 고치는 게 맞습니다:

> ~~명중 +5 ↔ 피해 −10~−20%p~~
> **명중 +5 ↔ 피해 −3%p** (피해 보정 0인 기술은 −6까지)
> **원거리(사거리) ↔ 피해 −18%p** — 원거리가 비싼 이유는 명중이 아니라 도달 범위다

### 바뀐 결론

1. **손아귀가 단독 최대 이상치(+33)가 됐습니다.** 둔기 강타(+22)를 앞섭니다. 둔기 강타의 우위가 상당 부분 명중 115였는데 그게 3밖에 안 되기 때문입니다.
2. **괴인 사슬질에 대한 제 직전 판정은 취소합니다.** "약한 기절(−15)을 명중 115(+15)로 정확히 상쇄받아 정가"라고 했는데, 명중이 +3뿐이라 실제로는 **−5로 정가 아래**입니다. 처음에 "약한 기절인데 받은 게 없다"고 한 판단이 맞았습니다.
3. **조정안은 대체로 유지됩니다.** 둔기 강타는 여전히 2위 과대(+22)이고 영웅이 2위이므로 강한 기절 → 기본 기절 제안은 그대로입니다. 다만 근거에서 "명중 115도 과하다"는 항목은 빼야 합니다. 함성(−50)과 성채의 일격(−9)도 방향 그대로입니다.
4. **손아귀는 여전히 건드리지 않습니다.** 신비학자가 17위(34점)라는 사실은 변하지 않았습니다. 다만 이제 "기절 기술 최대 이상치"라는 점은 기록해둘 가치가 있습니다.
