## 정맥 절개 ↔ 맹독 다트 대응 (분석)

두 기술을 나란히 놓으면 이렇습니다.

| | 도굴꾼 맹독 다트 (모드) | 노상강도 정맥 절개 |
|---|---|---|
| 종류 | **원거리** | 근접 |
| 명중 (1→5) | 95 → 115 | 95 → 115 |
| 피해 보정 | **−60%** | **−15%** |
| 실제 치명타 | **13.5% → 21.5%** | 5% → 13% |
| 사용 열 | 4·3·2 | 3·2·1 |
| **대상 열** | **1·2·3·4** | **1·2** |
| 지속 피해 | 중독 **12** | 출혈 **12** |
| 약화 | 중독 저항 − | 출혈 저항 −33%, **속도 −3** |
| 자버프 | **명중 +10** | — |

**지속 피해 총량이 12로 완전히 같습니다.** 명중도 같습니다. 짝으로 설계된 게 맞습니다.

**맹독 다트가 더 받는 것을 %p로 환산하면:**

| 항목 | %p |
|---|---|
| 원거리 | +18 |
| 대상 열 2개 더 (1·2·3·4 vs 1·2) | +10 |
| 자버프(명중 +10) | +10 |
| 치명타 +7.5 차이 | +4 |
| **소계** | **+42** |
| 정맥 절개가 더 받는 것: 약화 1개 더 | **−19** |
| **순** | **+23** |

**따라서 정맥 절개의 피해 보정은 맹독 다트보다 23%p 높아야 대등합니다.**

```
−60% + 23 = −37%
```

**현재 −15%는 22%p 더 유리합니다.** 즉 "정맥 절개가 더 좋아야 한다"는 판단은 맞지만, **이미 필요한 것보다 22%p 더 좋습니다.**

### 권장

> **명중 95 유지(1렙), 치명타 보정 +0 → +5, 피해 −15% → −40%**

- 대응값 −37%에 치명타 +5의 대가(약 3%p)를 더해 **−40%**
- 실제 치명타 **10% → 18%**. 맹독 다트(13.5% → 21.5%)보다 여전히 낮아 서열이 유지됩니다
- 치명타 +5는 절개·마름쇠·살모사의 입맞춤과 동급이라 새 값이 아니고, "정맥을 긋는 정밀한 칼질"이라는 모션에 맞습니다(P-21 예외)
- 약화 2개는 P-20에 따라 유지
- 기대 피해 10.35 → **7.20**

명중 95는 지속 피해 기술 23개 중 **최빈값**이라 그대로 두는 게 맞습니다. 앞서 "명중 90으로 정상화"라고 한 제 판정은 철회했습니다.
