# 사냥개 조련사 조정안 검토

## ① 사냥개 돌진 — "전 열 사용 + 전 열 타격"은 유일하지 않습니다

사용 4열 + 대상 4열을 둘 다 가진 **공격** 기술입니다.

| 영웅 | 기술 | 피해 보정 | 1렙 명중 |
|---|---|---|---|
| 도망자 | 판 뒤엎기 | **−10%** | 85 |
| 방패 파괴자 | 구멍내기 | −50% | 90 |
| 결투가 | 최후의 일격 | −60% | 95 |
| 유물수집상 | 부패의 연막 | −75% | 95 |
| 신비학자 | 약화 저주 | −75% | 95 |
| 신비학자 | 취약화 주술 | −90% | 95 |
| 유물수집상 | 섬광 가루 / 현상금 죽음의 표식 / 조련사 목표물 지정 | −100% | 95~100 |

**8개나 있고, 도망자 판 뒤엎기가 −10%로 가장 후합니다.** 다만 판 뒤엎기는 당기기 + 시체 제거 + 은신 해제가 붙은 유틸기이고 조련사 돌진은 순수 딜링기입니다.

### 제안하신 안 평가

> 출혈 제거, 사용 4·3·2 → **4·3·2·1**, 피해 0% → **−20%**

| 항목 | 잔차 변화 |
|---|---|
| 출혈 제거 (2×3턴) | **−11** |
| 사용 열 +1 | +5 |
| 피해 −20% | −20 |
| **합** | **−26** → 잔차 **+93** |

**여전히 조련사 최고입니다**(다른 공격기 52~58). 방향은 좋은데 폭이 부족합니다.

**다만 출혈 제거의 부수 효과가 큽니다.** 조련사 전용 장신구 중 **징 박힌 목걸이(출혈 +30%)와 허물송곳니 호루라기(개 간식 소지 시 출혈 +50%)**가 있어서, 출혈을 빼면 **장신구 두 개가 사냥개 습격 하나에만 의존**하게 됩니다. P-20 관점에서 손해입니다.

**대안: 출혈은 유지하고 피해만 −40%로**

|---|---|---|---|---|---|---|

**대안 A를 권합니다** — 출혈을 남겨 장신구 시너지를 지키고, 사용 열은 넓혀 1열 조련사를 열고, 피해로 값을 치릅니다.

## ② 사냥개 습격 사용 4·3·2·1 → 4·3·2는 방향이 반대입니다

습격의 사용 열을 줄이면 **1열 조련사가 습격을 못 씁니다.** "1열 조련사 활용" 목표와 어긋납니다.

현재 조련사가 1열에서 쓸 수 있는 기술: 습격(4321), 목표물 지정(4321), 경비견(4321), 둔기 강타(21) = **4개**. 돌진을 4321로 넓히면 5개가 됩니다.

여기서 습격을 432로 줄이면 다시 4개로 돌아갑니다. **돌진만 넓히고 습격은 그대로 두는 게 목표에 맞습니다.**

피해 −75% → −70%는 +5로 작습니다. 습격은 **광역 전 열 + 출혈 3×3(확률 150)**을 가진 기술이라 −75%가 과하지 않습니다.

## ③ 보호 기술 3개 비교 — 경비견이 중간입니다

| 영웅 | 기술 | 사용 | 보호 지속 | 자기 강화 | 부가 |
|---|---|---|---|---|---|
| **중보병 수호자** | | **1·2·3·4** | **3턴** | **방어도 +30** | — |
| **조련사 경비견** | | 4·3·2·1 | **2턴** | **회피 +20** | — |
| **유물수집상 동료 방패** | | 4·3·2·1 | **2턴** | 없음 | **대상에게 회피 +8·방어도 +20**, 표식 부여 |

- **중보병 수호자가 가장 강합니다** — 보호 3턴 + 자기 방어도 +30. 탱커 정체성에 맞습니다
- **경비견은 보호 2턴 + 자기 회피 +20**. 회피 +20은 조련사 기본 회피 30%에 더해져 50%가 되므로 **실효가 큽니다**(회피형 탱킹)
- **동료 방패는 자기 강화가 없는 대신 보호 대상에게 방어도 +20**을 줍니다. 그리고 **표식을 함께 거는 게 특이**합니다 — 유물수집상이 표식 조합에 들어가는 이유이기도 합니다

**세 개가 서로 다른 축으로 갈려 있어 조정 불필요**로 봅니다. 경비견이 수호자보다 약한 건 영웅 역할(조련사=딜러/서포터, 중보병=탱커)에 맞습니다.
