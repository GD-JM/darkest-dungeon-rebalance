스트레스 회복 기술이 서로 겹치지 않도록 각자의 "회복 방식"을 나누는 방향을 제안합니다. 지금 회복 기술은 대부분 "즉시 N 회복"이라는 같은 방식에 대상만 다릅니다.

## 지금 스트레스 회복원 (회복 방식 기준)
| 영웅 · 기술 | 대상 | 방식 |
|---|---|---|
| 광대 격려의 선율 | 단일 | 큰 즉시 회복(8~12) + 받는 스트레스 감소 |
| 고행자 인내 | 단일 | 큰 즉시 회복 |
| 총사 응급 처치 | 단일 | 즉시 회복 + 기절 해제 |
| 성전사 고무하는 함성 | 단일 | 즉시 회복 + 소량 체력 회복 + 횃불 |
| 조련사 위험 경보 | 아군 전체 | 확률(66~74%) 회복 |
| 석궁사수 결집 신호탄 | 자신 제외 3명 | 소량 회복 + 은신 해제·횃불 |
| **중보병 고양** | 자신 포함 4명 | 소량 회복(1~3) + 받는 스트레스 −10% + 회피 |

단일 대량은 광대·고행자·총사·성전사, 광역 소량은 조련사·석궁사수·중보병으로 몰려 있습니다. 같은 칸끼리는 사실상 대체재라 하나만 고르게 됩니다.

## 차별화 축 (새 메커니즘 없이 기존 효과·규칙만 사용)
1. **예방형:** 받는 스트레스 감소 위주. 고양이 이미 이쪽입니다.
2. **조건형:** 특정 상태의 아군에게 더 회복합니다. 게임에 이미 있는 조건 규칙(보호받는 중, 표식, 붕괴·기상 상태 등)을 씁니다.
3. **부가 효과형:** 회복에 다른 역할을 묶습니다. 신호탄의 은신 해제, 응급 처치의 기절 해제가 이 방식입니다.
4. **대가형:** 크게 회복하는 대신 시전자가 대가를 냅니다. 고행자 계열입니다.

## 중보병 고양 개선안: "지키는 자의 회복"
중보병 정체성은 수호자(아군 보호)입니다. 고양을 **보호와 묶인 회복**으로 특화하면 다른 회복기와 겹치지 않습니다.

- **A. 보호받는 아군 추가 회복:** "보호받는 중"(is_guarded) 조건으로 받는 스트레스 회복량 +50~100%. 중보병이 수호자로 지켜 주는 동료가 고양에서 더 많이 회복합니다. 지휘의 "보호받는 아군 피해 증가"와 같은 규칙이라 툴팁도 익숙합니다.
- **B. 예방 특화:** 즉시 회복은 1~2로 두고, 받는 스트레스 감소를 −10%(2턴)에서 −15%로 올리는 대신 회피를 뺍니다. "덜 받게 하는" 유일한 힐러가 됩니다.
- **C. 붕괴 아군 응급:** "붕괴 상태" 아군에게 회복량 2배. 위급할 때만 강해지는 보험형입니다.

**권장은 A입니다.** 중보병 키트(수호자 → 지휘 → 고양)가 하나의 플레이로 이어지고, 평소에는 보조 힐로 남아 광대·조련사와 자리를 다투지 않습니다. 조건이 붙어서 상시 가치는 크게 안 올라가고, 수호자와 함께 쓸 때만 좋아집니다.

**다른 회복기 정리 방향 (원하시면 이어서):**
- 조련사 위험 경보: 확률 회복을 그대로 두고 "운에 맡기는 광역"으로 유지
- 성전사 고무하는 함성: 신앙 계열에 맞게, 붕괴·기상 상태 아군에게 더 회복하는 조건형으로

어느 방향으로 갈지 정해 주시면, 고양부터 수치를 계산해서 가져오겠습니다.
