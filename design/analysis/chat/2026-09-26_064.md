> 왜 어떤 기술은 관행을 따르고 어떤 기술은 선형적으로 상승하고 그런거야?

데이터로 규칙이 나왔습니다. **하나의 규칙과, 나머지를 처리하는 두 가지 방식**입니다.

## 결정적 증거

(5레벨 값 − 1레벨 값)을 4로 나눌 수 있는지에 따라 형태가 갈립니다.

| | 등차 | 계단 | 마지막 도약 |
|---|---|---|---|
| **4등분 가능** (차이가 4의 배수, 0.5 단위 포함) | **104** | 48 | 3 |
| **4등분 불가** | **0** | 19 | 15 |

**4등분이 안 되는 수열에서 등차는 단 하나도 없습니다.** 즉 개발사는 먼저 1레벨 값과 5레벨 값을 정하고, 그 차이를 4로 나눠 채웁니다. 깔끔하게 나뉘면 등차, 아니면 나머지가 어딘가로 몰립니다.

## 나머지를 어디에 두는가 — 값의 크기가 갈랐습니다

### 값이 작을 때: 내림 보간 → 중간에 계단, 끝에 잔여

| 예 | 직선값 | 실제 (내림) |
|---|---|---|
| 도굴꾼 명중 버프 5 → 10 | 5 / 6.25 / 7.5 / 8.75 / 10 | **5 / 6 / 7 / 8 / 10** |
| 그림자 은신 회피 10 → 15 | 10 / 11.25 / 12.5 / 13.75 / 15 | **10 / 11 / 12 / 13 / 15** |
| 신비학자 재구축 13 → 22 | 13 / 15.25 / 17.5 / 19.75 / 22 | **13 / 15 / 17 / 19 / 22** |
| 도굴꾼 중독 킬러 20 → 33 | 20 / 23.25 / 26.5 / 29.75 / 33 | **20 / 23 / 26 / 29 / 33** |

소수를 버리다 보니 **버린 몫이 마지막 칸에 모입니다.** 설계자가 5레벨을 우대한 게 아니라 산술의 결과입니다.

### 값이 클 때: 읽기 좋은 증가폭 + 마지막에 몰아주기

| 예 | 내림 보간이라면 | 실제 |
|---|---|---|
| 저격·조준사격 50 → 100 | 50 / 62 / 75 / 87 / 100 | **50 / 60 / 70 / 80 / 100** (+10 ×3, 마지막 +20) |
| 노상강도 권총 사격 25 → 50 | 25 / 31 / 37 / 43 / 50 | **25 / 30 / 35 / 40 / 50** (+5 ×3, 마지막 +10) |
| 야만인 아드레날린 피해 20 → 30 | 20 / 22 / 25 / 27 / 30 | **20 / 22 / 24 / 26 / 30** (+2 ×3, 마지막 +4) |
| 성녀 신성한 위무 2 → 4.5 (평균) | 2 / 2.6 / 3.25 / 3.9 / 4.5 | **2 / 2.5 / 3 / 3.5 / 4.5** (+0.5 ×3, 마지막 +1) |

62·31·87 같은 숫자를 툴팁에 띄우기 싫으니, **+10 / +5 / +2 / +0.5처럼 보기 좋은 간격을 쓰고 남는 몫을 마지막에 붙인 것**입니다.

## 회복 기술에 그대로 적용하면

| 기술 | 1 → 5레벨 (차이) | 4등분 | 결과 |
|---|---|---|---|
| 성녀 신성한 은총 | 4.5 → 8.5 (4.0) | 가능 (+1) | **등차** |
| 조련사 상처 핥기 | 4 → 8 (4) | 가능 (+1) | **등차** |
| 석궁사수 붕대 | 2.5 → 4.5 (2.0) | 가능 (+0.5) | **등차** |
| 역병 의사 야전 의술 | 1 → 3 (2.0) | 가능 (+0.5) | **등차** |
| **성녀 신성한 위무** | 2 → 4.5 (**2.5**) | **불가** | 마지막 도약 |
| **신비학자 재구축** | 6.5 → 11 (**4.5**) | **불가** | 마지막 도약 |
| **고행자 구제** | 33 → 43 (**10**) | **불가** | 마지막 도약 |
| 고행자 재기 | 턴당 값과 지속 턴이 따로 성장 | - | 곱한 총량이 들쭉날쭉 |

즉 **어떤 기술이 관행을 따르느냐가 아니라, 끝값을 어떻게 잡았느냐가 형태를 결정**합니다. 4로 안 나뉘는 끝값을 고르면 자동으로 마지막이 커집니다.

| 역병 의사 야전 의술 | 3 / 4 / 5 / 6 / 6.5 | **3 / 4 / 5 / 6 / 7** (3-3 / 4-4 / 5-5 / 6-6 / **7-7**) |
