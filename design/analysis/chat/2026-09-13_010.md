## 2. 성장 공식

기본 능력치(장비 레벨 1 값)에 아래 공식이 붙어 레벨 2~5 값이 정해집니다. **n = 장비 레벨(1~5)**이고, 반올림은 0.5에서 올립니다.

| 능력치 | 공식 |
|---|---|
| 최소 피해 | 반올림(레벨1 최소 피해 × (1 + r × (n−1))) |
| 최대 피해 | 반올림(레벨1 최대 피해 × (1 + r × (n−1))) |
| 최대 체력 | 레벨1 체력 + (n−1) × 반올림(레벨1 체력 × 20%) |
| 회피 | 레벨1 회피 + 5 × (n−1) |
| 치명타 | 레벨1 치명타 + (n−1) |
| 속도 | 레벨1 속도 + (n−1) ÷ 2 (내림) → 레벨마다 +0, +1, +0, +1 |
| 무기 명중·방어·방어구 속도 | 모든 레벨에서 0 |

**피해 성장률 r은 두 값 중 하나입니다.**
- 최대 피해: 매혹 시 열이 1이면 **15%**, 아니면 **20%**
- 최소 피해: 매혹 시 열이 1이면서 heavy이면 **15%**, 아니면 **20%**

"매혹 시 열"은 세이렌의 "욕망의 노래"에 걸려 적 편에서 싸울 때 서는 열입니다. 게임에 따로 이름이 없는 데이터 값입니다.

**피해와 체력은 반올림하는 위치가 다릅니다.**
- 피해는 레벨마다 계산 결과를 반올림합니다. 노상강도 최대 피해 10, r 15% → 11.5→12, 13, 14.5→15, 16. 그래서 증가량이 2, 1, 2, 1로 들쭉날쭉합니다.
- 체력은 증가량을 한 번만 반올림해서 매 레벨 같은 값을 더합니다. 그래서 늘 고르게 오릅니다.

**전투 기술 레벨(1~5)**
- 명중 +5 × (n−1): 104/104 일치
- 치명타 +1 × (n−1): 103/104 일치. 예외는 노상강도 **추적탄** (0 / 0 / 0.5 / 0.5 / 1)
- 피해 보정: 변하지 않음. 103/104 일치. 예외는 나병환자 **위협** (레벨 4부터 −85% → −80%)

**검증 결과:** 20명 × 장비 스탯 9개를 대입해 **17명은 전 항목 일치**했습니다.
- 최대 체력·회피·치명타·무기 명중·방어·방어구 속도: 각 20/20
- 최소 피해·최대 피해: 각 19/20
- 속도: 18/20

### 기본 능력치 사이의 교환 관계

| 관계 | 상관계수 | 뜻 |
|---|---|---|
| 체력 ↔ 속도 | −0.78 | 가장 강한 교환. 튼튼할수록 느림 |
| 체력 ↔ 피해 | +0.76 | 튼튼한 영웅이 세게 침 |
| 체력 ↔ 기술 명중 | −0.61 | 튼튼할수록 덜 정확함 |
| 속도 ↔ 기술 명중 | +0.63 | 빠를수록 정확함 |
| 체력 ↔ 회피 | −0.50 | 튼튼할수록 덜 피함 |
| 치명타 ↔ 나머지 전부 | 0.31 이하 | 다른 능력치와 따로 노는 개성값 |

즉 **"튼튼하고 느리고 세지만 덜 정확한" 영웅**과 **"약하고 빠르고 정확한" 영웅**이 한 축의 양 끝이고, 치명타는 그와 별개로 붙어 있습니다.

**숨은 예산 공식이 있는지 확인했습니다.**
- 체력 ≈ 21.5 − 1.06 × 속도 − 0.29 × 회피 + 1.39 × 평균 피해로 추정하면 설명력은 85%지만, 최대 오차가 체력 4.4입니다. 경향은 강하지만 정확한 공식은 아닙니다.
- 치명타는 피해·속도로 설명되는 부분이 2%뿐입니다.
- 기본 능력치 5개(체력·회피·속도·치명타·평균 피해)를 표준화해 합치면, 합이 가장 높은 영웅은 야만인 +2.84, 도굴꾼 +2.73, 괴인 +2.05입니다. 가장 낮은 영웅은 성녀 −3.67, 유물수집상 −3.47, 고행자 −3.24, 역병 의사 −2.12입니다.
- 능력치 합을 맞추는 예산은 없습니다. 낮은 쪽은 회복·보조형이고, 그 가치가 기본 능력치가 아니라 **전투 기술에 들어가 있습니다**.
