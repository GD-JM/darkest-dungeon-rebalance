## 판정

- **[2026-10-15 정정] 표식 딜은 같지 않다.** 표식 대상 한 대: 현상금 수거 (1+0)×2.0 = 무기 2.0배(5렙 무기 12 → 24), 사냥개 돌진 (1−0.25)×1.6 = 1.2배(10 → 12). 현상금 수거가 약 2배. 모델 총합이 +95/+94로 비슷했던 건 표식 조건 유지율(30~60%)이 특효를 희석하고, 돌진은 어느 열에서나 1·2·3·4열(3·4열 위협 1.41배)을 치고 출혈(+46)이 있어서다 → 표식 딜러는 현상금 사냥꾼, 돌진은 "사거리 + 출혈 + 표식 보너스".
- 후속: P-24(조련사는 딜↓ 유틸↑), HM-024(둔기 강타 −50%), HM-025(경비견 회피 +20~30).
- **겹치는 축은 셋**: 표식 특효 딜(돌진 +95 ↔ 현상금 수거 +94), 기절(둔기 강타 +53 ↔ 어퍼컷 +63), 출혈(몰이 +86 ↔ 마름쇠 +132). 둘 다 "표식 → 특효" 사냥꾼.
- **자리가 다르다**: 조련사는 열 점수가 네 열 모두 10~12(후열 원거리 + 지원), 현상금 사냥꾼은 1·2열 중심(9/10, 4열 6). 표식 특효 딜도 돌진은 어디서든 어디로든 원거리, 수거는 1·2·3 → 1·2 근접.
- **역할 차이**: 조련사 = 후열 딜 + 파티 지원(울부짖기 +169가 키트 최고), 현상금 사냥꾼 = 전열 처형 + 제어(끝장내기 +135, 끌어오기·섬광탄·어퍼컷).
- 그래서 "딱 경쟁군"은 **표식 딜러 자리 하나**에서만 맞붙는다. 같이 넣으면 휘파람·죽음의 표식이 서로의 특효를 열어 주는 상생 구도.
- 약한 기술: 현상금 사냥꾼 죽음의 표식 −43(방어 감소는 0 아래로 안 내려가 영웅 등급 적 56%에 무효), 섬광탄 +2(모델이 위치 섞기·후열 사용 가치를 낮게 봄). 조련사 경비견 +1(보호 가치 낮게 잡힘), 목표물 지정 +25.
