## 4. 상위 던전 몬스터가 얻는 회피 (던전 레벨별 고정 가산)

같은 몬스터 계열의 견습(A)·베테랑(B)·영웅(C) 파일을 비교했다. 회피 1000인 gatekeeper는 제외했다.

| 구간 | 회피 증가량 (몬스터 수) |
|---|---|
| 견습 → 베테랑 | +8.75 (90), +10 (1), 0 (12) |
| 베테랑 → 영웅 | +12.5 (58), +13.75 (26), +11.25 (6), +10 (1), 0 (12) |
| 견습 → 영웅 합계 | **+21.25 (58), +22.5 (26), +20 (7)**, 0 (12) |

- **회피가 오르지 않는 12종은 전부 싸우는 몬스터가 아니다.** 시체 3종, 고치, 커튼, 둥지, 장작더미 2종, 석상 3종, virago_shroom 같은 오브젝트·소환물이다.
- **원 개발사는 실제로 싸우는 몬스터 91종 전원에 던전 레벨별로 거의 같은 회피를 붙였다.** 베테랑 +8.75, 영웅 +20~22.5(대부분 +21.25).
- **영웅 쪽 대응은 기술 명중 +5/레벨뿐이다.** 3레벨 +10, 5레벨 +20.
  - 베테랑 던전 · 기술 3레벨: 영웅이 +1.25 앞선다.
  - 영웅 던전 · 기술 5레벨: 영웅이 −1.25~−2.5 뒤진다.
- **해석**: "상위 던전 몬스터가 회피를 달고 나온다"는 관찰은 데이터와 정확히 맞는다. 이 가산은 기술 성장으로 거의 상쇄되게 맞춰져 평균 명중률은 유지된다. 그래도 체감이 커지는 이유는 세 가지다.
  1. 1레벨 명중 85 이하 기술은 상한 95%까지 여유가 없어서, 회피 증가가 곧바로 빗나감으로 나타난다.
  2. 기술 업그레이드가 던전 레벨보다 늦으면 회피 가산만 먼저 붙는다(추론).
  3. 상한에 가려지던 차이, 빗나감 비용 증가 같은 나머지 원인은 `accuracy.md` 참고.
