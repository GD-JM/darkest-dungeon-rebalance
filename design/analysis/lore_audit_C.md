# 설정·전용 장신구·야영 기술 반영 감사 C (2026-10-22)

대상: 나병환자, 중보병, 신비학자, 역병 의사, 도망자, 방패 파괴자, 성녀 (7명 전원)
기준: `main` 브랜치 현재 데이터(`heroes/<id>/<id>.info.darkest`, `effects/rebalance_*.effects.darkest`, `shared/buffs/rebalance_*.buffs.json`). 바닐라는 `heroes/<id>/<id>.vanilla.txt`와 설치 폴더 `<id>.info원본.darkest`.
읽기 전용 감사다. 게임·영웅·효과·강화 효과·현지화 파일은 고치지 않았다.

## 읽는 법

- **상태**: 채움(설정·장신구가 요구하는 것을 키트가 준다) / 약함(있긴 한데 기술 1개뿐이거나 조건부·약함) / 못 채움(받쳐 줄 기술이 없음) / 반대(현재 설계가 요구와 정반대)
- 수치는 모두 **1레벨**이다(명중·치명 보정·효과 확률·지속). 효과 크기는 필요하면 1~5 수열을 붙인다.
- 장신구 `in_rank` 값은 0부터 센다: `in_rank:0` = 1열, `in_rank:1` = 2열, `in_rank:3` = 4열.
- 야영 기술 수치는 `camping_skills.json`의 `amount` 값이다(강화 효과 템플릿 값이 아님). 이 모드는 야영 기술을 바꾸지 않는다.
- 출처 줄임: 길드 = `action_verbose_body_guild_*`, 대장간 = `..._blacksmith_*`, 야영 문구 = `..._camping_trainer_*` (한국어·영어 둘 다 확인).
- 장신구 원본: `trinkets/base.entries.trinkets.json`, `dlc/580100_crimson_court/.../crimson_court.entries/sets.trinkets.json`, `dlc/735730_color_of_madness/trinkets/com.entries.trinkets.json`, `dlc/702540_shieldbreaker/trinkets/*`, `dlc/4964110_fires_edge/features/runaway/trinkets/*`. 강화 효과 id는 모두 실제 값으로 풀었다.

### 바닐라 → 현재 변경 요약 (1레벨)
- **위협(intimidate)**: 바닐라 = 1열 사용, **대상 1·2·3·4열**, 명중 95, 피해 −85%, 은신 무시. 적 피해 −20%·속도 −3(3턴), **자기 표식(4턴)**, **은신 해제**, 자기 속도 +2. → 현재 = 1열 → **1열만**, 명중 85, 피해 −40%, 치명 3%, 적 방어 −30%(2턴, 100%; 5렙 −50%) 하나. (LEP-001~005)

- 나머지(토막치기 명중 75·치명 3%, 가르기 75/−50%, 축출 85/−40%·밀치기 3·시체 제거·자기 명중 +5, 인내 방어 +20%·저항·자기 표식, 평온 회복 6·스트레스 5) 바닐라 그대로.

### 바닐라 대비 사라진 것 (설정·장신구 관점)
- 위협의 **2·3·4열 도달**(1열에서 적 4열까지 닿는 희소한 능력)과 **은신 해제**가 사라졌다. 나병 전용 장신구·설정 중 이것에 의존하는 것은 없다. 다만 "후열 도달 희소성" 기록에 비추어 큰 체감 변화다.
- 위협의 자기 표식(4턴) 삭제: 표식 받기는 인내가 계속 담당(나병 장신구에 표식 관련 없음).
- 결론: 나병환자는 **장신구·야영과 충돌하는 항목이 없다.** 유일한 논점은 '위협' 이름과 방어 감소의 맞물림(P-19 해석).

### 장신구 관점 결론 (P-20 점검)
- **효과가 사라져 갈 곳을 잃은 전용 장신구: 0개.** 7명 전원의 전용·진홍빛 궁정·광기의 색·세트 장신구가 강화하는 능력치(기절·약화·이동·중독·출혈·화상·치명·근접·원거리·표식 대상·반격·회복)는 현재 키트에 최소 1개 기술이 있다.
- **기술 1개에만 의존하는 장신구**(바닐라와 같음, 모드가 해당 기술을 하향하지 않음): 역병 핏빛 약초·해부용 도구 → 절개(명중 85 → 90 상향), 중보병 성벽 방패·낡은 군기 → 성채의 일격·포효, 성녀 속죄의 목걸이 → 철퇴(상향), 성녀 세트 기절 +35% → 눈부신 광채(4·3열 전용).
- **열 조건 장신구**: 나병 참회의 팔찌(1열) 채움, 중보병 수호자의 방패(4열) 채움·강화, 성녀 불경한 두루마리(2열) 채움(단일 회복으로).
- **검증 전**: 신비학자 취약화 주술의 저항 감소가 약화 확률 장신구(악마의 가마솥·저주받은 향료·모래 약병)의 영향을 받는지, 피의 계약물 출혈 확률 −25%가 재구축의 아군 출혈에 적용되는지.
