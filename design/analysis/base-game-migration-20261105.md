# WS-BASE-001 — 기존 창작마당 본편판 전환

기존 형식을 유지한 15영웅판으로 전환한다. 원본 20영웅·장신구·수치는 보존한다. DLC 영웅 데이터와 총사 전용 현지화는 배포에서 제외한다. 유물수집상·성녀가 쓰는 도망자 화상 효과 두 종류는 동일 수치의 고유 이름 효과로 포장해 DLC 파일 의존성을 끊는다. 단독 DLC 패키지와 효과 이름도 충돌하지 않는다.

별도 DLC 5개는 기존 공개 ID를 안내하며, 본편판의 필수 구독으로 지정하지 않는다. 합본은 향후 별도 출시한다. 기존 예약 재시도 프로세스만 사용자 승인으로 취소했다.

## 추가 승인과 검증
사용자는 배포 후 안내 댓글 게시도 승인했다. 이유는 DLC 미보유자의 실행 불가 해소이며, 리브랜딩과 함께 접근성을 개선하고 기존 구독자에게 번거로움을 사과한다.
본편 15영웅 데이터는 두 효과의 내부 참조명만 바꾸고 동일하다. 634개 재귀 효과 참조를 본편 원본+이번 출력으로 확인했으며 누락 효과·강화가 없다. 별도 DLC 5개 빌드의 영웅 데이터는 기존 main과 같고 본편 출력과 겹치는 커스텀 효과·강화 ID는 없다. 게임 실행 검증은 별도다.
