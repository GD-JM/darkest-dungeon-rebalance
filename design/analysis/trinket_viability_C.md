# 전용 장신구 가치 감사 C — "죽은 장신구" 가드레일 (2026-10-23)

대상: 중보병·신비학자·역병 의사·도망자·방패 파괴자·성녀, 전용 장신구 전수(기본 + 진홍빛 궁정 세트 + 광기의 색 + DLC 세트, 투기장 제외).
데이터: `test` 브랜치 작업 트리(2026-10-23, 깨끗한 상태, HEAD 3f2dbae) + 설치 원본(설치 파일 = `*.info원본.darkest` 6명 모두 일치 확인). 읽기 전용 분석이며 수치 변경 승인이 아니다.

## 기준

- **가드레일**: 전용 장신구는 영웅의 선택지를 넓힌다. 모드가 그 장신구가 곱하거나 기대는 대상(기술 피해 보정, 효과 확률을 받는 기술, 사용 열, 조건)을 줄여서 장신구가 **쓸 이유가 없는 물건**이 되면 위반이다.
- **판정**: 살아있음(바닐라와 같거나 더 좋음) / 약해짐(아직 고를 만하지만 기대는 대상 일부가 사라짐) / 버려짐(장착 이유가 사라짐).
- **수치**: 명중·효과 확률·치명 보정은 기술 **1레벨**, 범위는 1→5레벨. 효과 확률은 저항 전 값. 피해 계산은 작업 가정 V-01(기술 피해 보정 × (1 + 강화 합))을 따른다(게임 검증 전).
- 장신구 `in_rank` 값은 0부터 센다(`in_rank:3` = 4열, `in_rank:1` = 2열). `actorStatus tagged` = 대상이 표식 상태.
- **모드는 장신구 정의·장신구 버프·장신구 발동 효과를 하나도 덮어쓰지 않는다** (모드 `shared/buffs`에 `TRINKET_`/`SET_`/`block_guard` 0건, 모드 효과 파일에 도망자 장신구 효과 0건, 모드 장신구 파일 없음). 따라서 가치 변화는 전부 **영웅 키트 변경**에서 온다.

## 결론 요약

- **버려짐 0개.** 6명 전용 장신구 53개 + 세트 효과 6개(총 59항목) 중 가드레일 위반은 없다.
- **약해짐 2개**:
  1. 방패 파괴자 **송곳니 창끝**(sb_4) — 찌르기 4열 도달 삭제(SB-002→SB-013)로 4열 표식 대상에 +35%를 실어 줄 주력 기술이 없어짐. 2·3열 표식 대상은 SB-016으로 오히려 강해짐 → 경미.
  2. 성녀 **진홍빛 궁정 세트 효과**(`cc_vest`) — 광채 2열 사용 삭제(VES-003)로 속죄의 목걸이(근접)를 살리는 1·2열 위치에서 세트의 기절 +35%p를 쓸 기술이 없음. 약화 +35%p 절반은 살아 있음.
- **주의(살아있음이지만 대가가 커짐)**: 방패 파괴자 세트 `sb_set1`(보호받기 불가 + SB-017로 1열 자기 방어 0), 중보병 성벽 방패(피해 −15%가 이제 응징·반격 같은 피해 행동에도 걸림), 신비학자 약화 확률 장신구 3개(취약화 주술 OCC-003 적용 여부 미검증).
- 모드가 오히려 키운 장신구: 수호자의 방패(MAA-010/013/016), 응징 세트(MAA-004), 핏빛 약초·해부용 도구(PD-002), 맹독을 담은 병·흑요석 단검·공허한 창끝(SB-020), 무희의 발싸개(SB-010), 속죄의 목걸이(VES-001), 신성한 두루마리·치유의 서·일기장(VES-004/005), 이단의 길(VES-009).

## 검증 대기 (게임)

1. 약화 확률 장신구(악마의 가마솥·저주받은 향료·모래 약병)가 취약화 주술의 저항 감소(`buff_ids`)에 적용되는지 — 적용되지 않으면 신비학자 약화 장신구 3개가 받치는 기술이 약화 저주 1개로 줄어 "약해짐"으로 내려간다.
2. 지옥불 석탄 4열 당기기가 화톳불(피해 −100% 광역) 적중에도 발동하는지.
3. 피해 곱셈 순서 V-01(기술 보정 × (1 + 강화 합)) — 송곳니 창끝·성벽 방패 수치는 이 가정에 기댄다.
