## 변경 방식

- 원문 한국어 주석, 데이터 행과 빈 줄을 바꾸지 않고 `// ID [trace 2026-10-05] 의도`를 바로 아래 추가했다. 같은 기술의 연속 레벨은 한 주석을 공유한다.

- 효과 편집 사본과 파생 효과는 바뀐 효과 한 줄마다 ID·의도 주석을 달았다. 원본과 같은 편집 효과에는 불필요한 수정 표시를 하지 않았다.

- 기존 주석이 예전 수치를 설명하는 경우 최신 추적 주석을 앞에 두고, 옛 주석은 지우지 않았다. 변경 문서의 날짜별 섹션에 원본/현재 값·의도·원문 메모·Git 출처를 적었다.

- 원본 효과 재사용과 게임용 파생 효과의 원본 정의도 연결했다. 같은 수치의 중복 효과를 새로 만들지 않았다.

- 영문 의도 주석은 기존 적용 도구가 재생성할 때 복사할 수 있다. 한국어 원문 메모도 보존했다.
