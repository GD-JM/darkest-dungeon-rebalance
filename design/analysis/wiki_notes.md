# 나무위키에서 얻은 정보 (게임 데이터에 없던 것만)

원칙: **게임 빌드 데이터가 기준**이다. 위키는 최신이 아닐 수 있다. 아래는 저장소 데이터·분석에 없던 내용만 추린 것이고, 데이터와 다르면 데이터를 따른다. 엔진 규칙(데이터 파일로 확인 불가)은 게임 검증 대상이다.

읽은 문서 (2026-10-03): 「다키스트 던전」(2026-09-08 판), 「다키스트 던전/시스템」(09-13), 「다키스트 던전/붕괴」(09-07).

## 모델에 반영한 것

| 내용 | 위키 | 데이터 확인 | 반영 |
|---|---|---|---|
| 비아냥 범위: 고통 영웅 자신의 돌발 행동·피격 → 파티 전체, 다른 영웅 행동에 반응 → 그 영웅만 | 붕괴 2절 | 불가(엔진) → **V-14** | `affliction_margin` 고통 비용 72 → 94 HP, 스트레스 1 = HP 1.51 → 1.67 |
| 고통은 스트레스 0 또는 영지 시설로 해제, 귀환해도 유지 | 붕괴 2절 | 불가 | 고통 유지 10라운드 가정의 근거 |

## 기록만 한 것 (분석 근거로 쓸 수 있음)

- **심장마비**: 스트레스 200 → 체력 0·죽음의 문턱, 스트레스 170. 문턱이면 즉사. 고통 비용에 아직 넣지 않았다(하한).
- **미덕 확률**: 영웅 레벨이 던전보다 낮으면 레벨당 −5%(최소 1%, 최대 95%). 데이터 `effectiveDifficultyAfflictionOnsetModifiers`와 일치.
- **미덕 상태에서도 스트레스가 100을 넘을 수 있고, 200이 되면 스트레스 0·미덕 해제**(광기의 색채 업데이트 이후).
- **같은 고통·미덕이 반복될 확률**: 겪은 종류일수록 높다. 데이터 `*_history_WF`와 일치.
- **아군 공격 피해**: 맞는 영웅 최대 체력 x (100 − 직업별 보정)%. 괴인 −85%(15%) + 중독 3x3, 성전사 −90% + 기절 등.
- **고통 돌발 행동 방식**: 턴마다 약 30%로 '돌발 여부'를 먼저 뽑고, 그다음 종류를 뽑는다(데이터 가중치 `nothing`과 같은 구조).
- **스트레스 변동 목록**: 적 치명타 피격 +10, 동료가 치명타 피격 50% +5, 동료 사망 50% +12, 치명타 회복을 받으면 −4, 함정 해체 −8, 함정 +15, 식사 거름 +15~20 등. 데이터로 확인한 것은 `analysis/affliction.md` 5절.
- **밝기**: 낮을수록 보상↑, 스트레스↑, 양쪽 치명타↑. 칠흑(Stygian) 난이도: 몬스터 체력 +20%, 치명타 +3%, 통로 횃불 소모 6 → 7.
- **죽음의 일격 저항 상한 87%**, 문턱 약화(필멸)는 일부 야영 기술로만 해제, 고행자는 예외.
- **고행자 황홀경 / 굴절(광기의 색채)**: DLC 전용 고통.
- 위키가 데이터와 다른 것: 장기전 스트레스 +6(위키) vs +5(데이터 `stall_stress`).

# wiki.gg (공식 영문 위키, 2026-10-03)

읽은 문서: Combat Mechanics, Status Effects, Critical Hit, Affliction, Bark, Runaway, Highwayman/Strategy.

## 모델에 반영한 것

| 내용 | 위키 | 데이터 확인 | 반영 |
|---|---|---|---|
| 적중 95% 이상이면 무조건 명중 | Combat Mechanics | **확인** `cutoffAlwaysHit 0.95` | `hit()` 95% 상한 → 100% |
| 반격은 맞든 피하든 발동 | Status Effects | **확인** 반격 효과 `riposte_on_miss_chance_add 100%` | 반격 횟수 = 맞은 수 → 받은 공격 수(x 1/적 적중률) |
| **V-01: 기술 피해 보정 x (1 + 강화·조건부)**, 강화끼리는 가산 | Highwayman/Strategy("Duelist's Advance는 85% + X%, Pistol Shot은 85% x (1 + X%)"), Combat Mechanics("무기 x 기술 배율 후 나머지 보정") | 불가(엔진) | `DMG_STACK='mult'`. 이전 가산은 민감도로 남김 |
| 속도 동점이면 영웅이 먼저 (같은 편이면 앞 열이 먼저) | Combat Mechanics | 불가 | `p_before` 동점 절반 → 영웅. 행동 순서 = 속도 + 1~8도 위키와 일치(V-09 공식 부분) |
| 회복 치명타: 회복 2배 + 스트레스 −4, 단일 12% / 광역 대상별 5% 고정 | Critical Hit | 불가 | 회복 기술에 `HEAL_CRIT_SGL/AOE` |
| 비아냥 범위(V-14) | Affliction: "고통 영웅이 공격받거나 돌발 행동이면 파티 전체, 다른 영웅이 공격하거나 공격받아 나온 반응이면 그 1명" | 불가 | 나무위키와 같은 내용 → 이미 반영 |
| 흩날리는 불티 약화 = **화상 감소 −50%** (감소를 늦춤) | Runaway | 데이터는 `hp_dot_burn_decay_percent 0.5`만 | V-12-2 해석(감소 늦춤) 지지 |

## 기록만 한 것

- **기절 회복 저항**: 기절이 풀리면 기절 저항 +50%(2턴), 연속 기절이면 중첩. 데이터 `STUNRECOVERYBUFF` 확인. 모델의 기절 가치는 연속 기절 감쇠를 세지 않는다(같은 적을 매 턴 기절시키는 운용은 과대).
- **돌발 행동은 같은 영웅이 연속으로 못 하고, 두 영웅이 연달아 못 한다** → 고통 비용이 약간 과대일 수 있다.
- **고통 종류 가중치**: 기본 4, 겪을 때마다 +2(미덕은 +1). 데이터 `*_history_WF` 일치.
- **아군 공격**: 대상 최대 체력 x 직업별 비율(괴인 15% + 중독 3, 성전사 10% + 기절 …), 자해 10%.
- **죽음의 문턱**: 명중 −10, 피해 −25%, 속도 −5, 받는 스트레스 +33% / 회복 후 원정 끝까지 −2, −5%, −1, +10%(중첩 안 됨). 데이터 `deathsdoor*`, `mortality*` 확인. 죽음의 일격 저항 67%(고행자 73%), 상한 87%.
- **보호**: 보호자와 피보호자를 함께 치는 광역은 보호 무시, 보호자가 기절하면 보호 해제, 보호 사슬 불가.
- **표식**: 저항 불가.
- **무료 행동**(괴인 변신·결투가 예상)은 턴이 아니라 지속 피해·지속 시간이 줄지 않는다.
- **방어도 상한 80%**, 지속 피해는 방어도 무시.
- 도망자 통제된 화상 3/4/5는 9/24 효과 패치 이전 값(데이터 2~4가 기준).
- 괴인(도살자의 서커스 PvP): 야수 턴당 스트레스 12 — 일반 모드는 6(제작자 확인 V-13).

## 반영하지 않은 것 (검증 대상)

- **V-15 숨은 명중 +5**: 위키는 "모든 기술에 숨은 명중 +5, 최소 적중 5%"라고 하지만 데이터는 `cutoffAlwaysMiss 0.00`(0 이하는 빗나감)·`cutoffAlwaysHit 0.95`만 있다. 게임에서 표시 적중 0%인 공격이 맞는지 보면 확인된다.
