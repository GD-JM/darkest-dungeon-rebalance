확인 범위 (읽기 전용)
- info 파일: 모드 `heroes/<영웅>/<영웅>.info.darkest`를 바닐라 설치본(`heroes/highwayman`, `heroes/vestal`, `dlc/4964110_fires_edge/.../runaway`)과 주석·공백을 빼고 직접 diff했다. 설치본 = `info원본` 파일과 바이트 동일(cmp)이라 바닐라가 맞다. 차이는 감사 묶음의 diff와 정확히 같다(기술 줄 외 능력치·저항·무기·방어구·반격 기술 차이 없음).
- 효과·강화: `effects/rebalance_highwayman.effects.darkest`, `effects/rebalance_vestal.effects.darkest`, `shared/buffs/rebalance_vestal.buffs.json`, 그리고 성녀가 참조하는 `effects/rebalance_antiquarian.effects.darkest`의 `RB ANT Flash Burn 1~5`. 도망자 RB 효과 파일은 없다.
- 기타 데이터: 야영 기술(`raid/camping/default.camping_skills.json`) 바뀐 항목은 석궁사수·총사 것뿐, 장신구 파일 바뀐 항목은 총사 것뿐, 지역화 loc2는 총사 문자열뿐 → 세 영웅과 무관.
- `tools/check_comments.py highwayman vestal runaway` 통과(모든 변경 줄에 ID 주석 있음).
- 수치 표기: 명중·치명 보정·효과 확률은 1렙, 효과 크기는 1렙(→5렙). 모델 값은 감사 묶음의 강함 모델(5렙) %p.

## 판단 보류·질문

1. **창작마당 W 후보가 이 세 영웅에는 없다.** 데이터 차이 20개 묶음 모두 제작자 방향 결정(리워크·정렬·느낌 수치)이거나 원칙 위배다. 노상강도·성녀는 기술끼리 효과를 맞바꾼 리워크(HWY-004/005, VES-001/002)가 중심이라 일부만 떼어 올리기도 어렵다. 창작마당판에서 두 영웅을 통째로 빼고 바닐라로 둘지, 리워크 묶음 전체를 C로 넣을지 결정이 필요하다.
2. **주석·데이터 불일치 (P-02 추적성)**: `check_comments.py`는 통과하지만 옛 주석이 현재 값과 다르게 읽힌다.
   - 칼질: `HWY-008 … 명중 85 -> 90, dmg 0% -> +15%`, `HWY-014 … dmg 0% -> +15% 복귀`. 실제 데이터는 85 / 0%다.
   - 진격: `HWY-005 명중 90 -> 95`, `dmg -20% -> -40%`, `HWY-013 … Tracking Buff 바닐라 수치 복원`. 실제는 90 / −20% / 레벨당 +1 버프다.
   - 정맥 절개: `HWY-006 dmg -15% -> -40%`와 사용자 메모 "명중 95 -> 90, 데미지 15 -> 25"가 남아 있다. 실제는 95 / −30%다.
   - 추적탄: `HWY-004 dmg -80% -> -75%`, 실제는 −60%다.
   - 포도탄: `HWY-007 dmg -75% -> -70%`, "데미지 50 -> 70", 실제는 −60%다.
   - 성녀 효과 파일: `VES-011 … +10%~+15%` 줄이 `VES-012 +20~25%`와 함께 있다.
   - 창작마당판 정리 때 최신 값만 남길지 결정이 필요하다.
3. **VES-006 근거 불일치**: 주석은 "1열에 쓸게 없어서 사용열 321 → 4321"인데, 바닐라 321은 이미 1열을 포함한다. 실제로 생긴 변화는 4열 사용 추가(후열 성녀 강화)다. 의도가 4열 추가였는지 확인이 필요하다.
4. **HWY-001/017 영거리 사격**: HWY-000이 정의한 문제(가격표 +51, "사기스킬")를 고치려던 변경인데 모델 값은 +95 → +113으로 올랐다. 밀치기 2칸이 메인 플랜 가치(R-VALUE-07)를 더했기 때문이다. 의도(연속 사용 억제)가 실제로 이루어지는지는 플레이로만 확인된다.
5. **노상강도 총량 (P-11)**: 모델 순위 8 → 14위로, HWY-000 목표(5위 전후)보다 크게 아래다. 모델은 도구(P-16)지만, 의도한 하향폭인지 확인이 필요하다.
