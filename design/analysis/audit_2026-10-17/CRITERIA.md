# 리밸런스 모드 감사 기준 (창작마당판 선별용)

목적: 제작자가 지금까지 만든 리밸런스(개인 커스텀판)는 그대로 두고, 창작마당에 올릴 판에는 "검증된·확실한 변경"만 넣는다. 감사자는 각 영웅의 **실제로 게임에 들어간 변경**(바닐라와 다른 데이터)을 하나도 빠짐없이 분류한다.

## 읽을 자료 (모두 `C:\Program Files (x86)\Steam\steamapps\common\DarkestDungeon\mods\Rebalance\` 기준)
- 원칙: `design/intent.md` (G-00~G-05 목표, P-01~P-25 원칙), `design/rules.md` (R-xx 규칙, 특히 R-TRADE-02 명중+5=피해10%p, R-STUN-01~03, R-DATA-01 중복 효과 금지, R-VALUE-xx 모델 규칙, 원칙 이탈 목록, 게임 내 검증 목록 V-xx)
- 영웅별 기록: `design/changes/<영웅>.md` (항목 ID, 상태, 근거, 제작자 원문)
- 감사 묶음: `C:\Users\lemm1\AppData\Local\Temp\claude\C--Program-Files--x86--Steam-steamapps-common-DarkestDungeon\cc3c95a9-aeea-4409-9feb-eb162a738694\scratchpad\audit\<영웅>.md` — 바닐라 대비 실제 데이터 차이(diff, `//` 주석에 변경 ID), RB 효과·강화 파일, 기술별 모델(5렙) 가치 바닐라→RB, 영웅 총점·순위
- 필요하면 데이터 원본: `heroes/<영웅>/<영웅>.info.darkest`, 바닐라 `../../heroes/<영웅>/<영웅>.info원본.darkest` 또는 `../../dlc/*/heroes/<영웅>/`
- 모델 값 단위: 표준 평타 대비 %p, 5렙 계산. 기술 수치(명중·치명 보정·확률)는 1렙으로 말한다(레벨당 명중 +5, 치명 +1, 확률 +10%p).

## 분류 (변경 단위 = 실제 데이터 차이 하나 또는 같은 ID로 묶인 변경 묶음)
- **W 창작마당 후보 (검증됨)**: 아래를 모두 만족
  1) 문제가 데이터로 확인됨 — 같은 역할 기술 대비 모델 값이 튐/처짐, 원본 규칙(rules.md) 위반을 바로잡음, 명백한 버그·툴팁 오류·중복 중첩 버그 수정
  2) 변경이 그 문제만 고침(P-09 최소 수정, P-12 체감 보존), 원칙 위배 없음
  3) 근거와 수치가 기록에 있음(P-01, P-02)
- **C 커스텀 전용 (주관)**: 제작자 취향·방향 결정이 핵심인 변경. 예: 정체성 리워크(효과를 통째로 바꿈), 제작자 방향 원칙(P-23 괴인, P-24 조련사, P-25 유물수집상)에 따른 변경, 데이터 근거 없이 "느낌"으로 정한 수치, 새 기믹 추가(다른 영웅 장치 이식 등)
- **X 원칙 위배**: intent.md P-xx / G-xx 또는 rules.md R-xx에 어긋나는 내용. 반드시 어느 원칙인지 인용. (예: R-DATA-01 바닐라와 같은 효과의 RB 사본, P-17 바닐라 공유 파일 덮어쓰기, P-04 기술 ID 변경, P-20 장신구 연계 효과 제거, P-22 공식 설정 이탈, R-STUN-03 피해 기절 명중 90 기준 이탈인데 대가 없음, R-TRADE-02 교환 불균형, 주석 누락)
- **V 게임 검증 필요**: 엔진 동작 가정에 기대는 변경(rules.md V-목록, 툴팁 해석 등) — W/C와 함께 표시 가능

판단이 갈리면 근거를 적고 보수적으로(C 쪽으로) 분류. 기록 문서에만 있고 데이터에 없는 항목(기각·롤백·제안)은 분류하지 않되 "데이터에 없음"으로 한 줄 표시.

## 출력 (반드시 이 파일로 저장)
`...\scratchpad\audit\result_<그룹이름>.md`

영웅마다:
```
## <영웅 한국어> (<id>)
| 변경 ID | 기술/효과 | 바닐라 → RB (1렙 수치) | 모델(5렙) 바닐라→RB | 분류 | 근거 (원칙 인용, 한두 문장) |
```
그리고 끝에 "원칙 위배(X) 목록"과 "판단 보류·질문" 목록. 추측 금지 — 데이터와 문서에서 확인한 것만.
