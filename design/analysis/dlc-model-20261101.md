# R-DLC-029 결투가·도망자 통합 모델 보정

사용자 요청: “모델이 결투가나 도망자 모든 스킬 전부 반영되게 고쳐”.
수치 검토의 최신 정정: “반격 피해 20~ 30”. 게임 데이터 편집 승인이 아니라, 현재 안을 평가하고 모델 누락을 고치는 작업이다.

## 구현 범위
`strength.py`의 기술 평가 경로에 `dlc_valuation.py`를 연결했다. 두 영웅의 14개 기술을 명시적으로 분기한다. 바닐라와 리밸런스, 기술 1~5단계를 모두 평가한다. 신규 기술 ID를 발견하면 오류로 중단한다. 기존 모델 재현은 `--legacy-dlc`; 상태 입력은 `--dlc-state <JSON>`이다. 후자는 `State`에 선언된 필드만 허용한다.

- 예상: 전환 전 자세에 대응하는 효과만 발동한다. 두 자세 강화의 동시 합산을 제거. 무료 반격 유지와 개전 반격 피해 감소, 반격 치명타의 부수효과를 구분한다.
- 찌르기: 바닐라 전용 회피 강화는 첫 회피 후 소모. 공격 노출이 포아송 분포라는 명시적 가정에서 `소모 전 유효 공격 수 / 전체 공격 수 = (1-exp(-lambda*q))/(lambda*q)`로 보정한다. q는 강화 중 회피 확률. 반복 사용 중첩에 대한 실전 엔진 검증을 대신하지 않는다.
- 눈속임: 반격 전용 피해 강화를 일반 평타 강화와 분리. 자기 표식의 추가 반격 기회 반영. 표식은 중첩이 아니라 갱신이므로 반복 행동 표에서는 유지 기간으로 나눠 중복 가격을 줄인다.
- 회수: 후퇴 후 4열 회피 노출을 평가. 다음 공격의 사용열/대상열 제한 해제는 같은 적에 대한 실제 직접 공격 후보의 최댓값 차이로 계산한다. 다음 목표 열을 지정하지 않으면 4개 열 균등 가정이다.
- 날쌘 돌진: 전진/표식/직접·치명 및 후보의 공격 자세 회피 약화를 구분한다. 이동은 고정된 HP 벌점이 아니라 다음 행동의 합법성 입력이다.
- 최후의 일격: 기절 대상 치명타 +100%, 방어 무시, 정수 피해와 현재 HP에 따른 처치 확률을 계산. 다른 적이 남았을 때만 `처치확률 × 다음 행동 가치`를 더한다. 다음 행동 기본값 7.17 HP는 기존 모델의 아군 행동 가격이며, 관측치로 새로 확인한 수치가 아니다. 연쇄 처치 전체 탐색은 수행하지 않는다.
- 부츠: 동일한 현재 HP로 직접 피해 후 생존·기절을 공동 계산. 밀치기와 전진을 별도 처리한다.
- 작열하는 타격: 불타는 대상 추가 피해, 치명타 화상량, 기존 중첩 대비 증가분.
- 흩날리는 불티: 치명 화상량과 감소 지연 약화의 저항/지속. 바닐라와 현재 효과 참조를 그대로 읽는다.
- 도피: 후퇴, 은신의 보호 가치, 은신 유지 중 재생과 남은 체력 상한. 다음 공격 시 은신 해제/앞열 조건은 상태 전이에서 확인한다.
- 판 뒤엎기: 은신 명중, 직접 피해/치명, 당기기, 실제 시체 존재, 전진.
- 화톳불: 명중 지원/바닐라의 조건부 치명 지원, 은신 해제, 현재의 불타는 대상 감소 지연. 빗나감과 약화 저항을 분리하고 실효 이벤트 수를 데이터에서 읽는다.
- 통제된 화상: 최초 화상과 빗나가도 생기는 지면을 구분. 지면은 라운드, 화상과 감소 지연은 적 행동 기준으로 계산. 성공한 추가 지면 진입만 추가하며, 2회 제한/웨이브 초기화를 상태 전이로 검증한다.
- 불길 역류: 첫 대상과 뒤 대상의 기존 화상량을 각각 사용해 직접 피해를 계산. 실제 뒤 대상 존재, 앞 화상 제거, 뒤로 복사하는 화상과 치명 증폭을 함께 계산. 같은 중첩의 단순 이동을 새 화상 총량으로 중복 가산하지 않는다.

## 화상 산식과 근거
기존 로컬 엔진 검토 `outputs/runaway-engine-comparison-20261101.py`, `design/analysis/runaway-design-20261101.md`를 사용한다. `next = B//2 + floor((B-B//2)*clamp(s,0,1))`. 일반적인 s를 무조건 `floor(B*(.5+.5*s))`로 바꾸면 안 된다(예: B=5,s=.25).
지면 발동 → 적 행동 시작 화상 → 감소 순서. 라운드당 여러 행동, 이미 행동했는지, 이동 진입, 실효 지연 이벤트 수를 입력으로 받는다. 화상은 라운드 말 발동이라는 과거 모델의 해석을 이 두 영웅 평가에는 사용하지 않는다.
들불은 설치본 공식 용어집에 따라 시체/인접 대상 정보를 요구하는 별도 함수로 계산한다. 시체를 남기면 인접 확산을 주지 않는다. 홀수 중첩 절반의 내림은 추가 엔진 확인 전 가정으로 표시한다. 전체 순위에 임의의 들불 보너스를 더하지 않는다.

## 해석 제한
14개 기술의 주요 효과 누락을 보완한 유한 노출·상태별 가치 모델이며 완전한 전투 시뮬레이터가 아니다. 장신구 자동 착용 최적화, 모든 장신구 발동, 적 AI, 아군 전열 이동의 전체 편성 효과, 연쇄 추가 행동의 최적 정책은 포함하지 않는다. 장신구의 피해/명중/치명/화상 보정은 명시적 상태 입력으로 비교하며 발동 장신구의 전체 가치를 계산했다고 주장하지 않는다.

상태 없는 종합 순위는 조건 유지율·노출량·다음 행동 가격의 가정에 영향을 받는다. 상위 3기술 평균을 사용하는 기존 종합 지표 역시 유지되므로, 사용 빈도가 낮은 기술을 하향해도 종합 점수가 달라지지 않을 수 있다. 기술별 결과와 조건부 처치/화상 계산을 함께 봐야 한다. 장신구나 보스까지 포함한 절대 순위로 쓰지 않는다.
횃불 및 스톨링 플래그는 기존 사용자 원칙대로 직접 HP 가격에 넣지 않는다. 접근 가능성(보호 무시/은신 해제/이동)은 적 상태 없이 항상 보너스로 주지 않는다.

## 검토 후보 — 미적용
찌르기 바닐라 고정, 부츠 피해−60, 최후의 일격−70, 날쌘 돌진+10 및 기존 미사용 `Duelist Fleche Self Debuff`(공격 자세 회피−10, 자세 해제 시 제거, 데이터 지속4), 눈속임 방어−15/17/20/22/25 및 반격 피해+20/22/25/27/30, 회수 유지. 사용자의 “반격 피해20~30” 정정을 최종 후보로 사용한다. 후보는 메모리에서만 평가하고 게임 파일에는 반영하지 않는다.
