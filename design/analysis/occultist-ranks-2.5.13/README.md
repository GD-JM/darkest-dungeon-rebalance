# 신비학자 3열·4열 비교 (2.5.13)

설치된 Rebalance 모델을 사용한다. 챔피언 적 4종, 무기·기술 5단계, 중립 조명, 장신구 조합 3종. 직접 피해는 사용당 HP, 확률은 0~1. 기술 값은 실제 대상열에서만 유효하다. 전체 원정 승률이 아닌 행동 단위 비교다.

3열 조류대가 집중 공격에는 제물 암습(반지+가마솥 15.28 HP), 4열 가죽 사냥꾼을 끌어올 때는 악마의 아귀팔(약병+가마솥 이동 성공 79.6%), 방어 45% 방패병에게 아군 물리 14 피해 두 번이 적중하면 약화 저주(반지+가마솥 11.83 HP 상당)가 유리하다. 당기기·저주는 3열에서도 사용 가능하다. 4열은 동료에게 3열을 내준다.
