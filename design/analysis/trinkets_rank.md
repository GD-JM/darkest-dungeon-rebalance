# 열 조건 장신구 분석 (G-03 장신구 방향 근거)

원본 데이터 기준.
- 장신구 615개 중 킥스타터 등급 294개는 획득 조건을 확인하지 않아 별도로 빼고, 나머지 321개를 분석했다.
- 열 조건(`in_rank`) 값은 0부터 세므로 +1 해서 표기한다.

## 1. 요약

- 일반 장신구 321개 중 열 조건 장신구는 **10개(약 3%)**뿐이다.
- 그중 6개는 원래 서는 열을 강화한다. **서브 열 활용을 돕는 것은 4개**이고, 전부 한 영웅 전용이다.
- 명중을 주는 열 조건 장신구는 2개(저격수의 반지, 예언자의 눈)이고 둘 다 4열 강화다. 명중은 영웅 던전의 핵심 병목이다(`accuracy.md`).
- **선례**: 원 개발사도 서브 열 장신구를 만든 적이 있다. 성녀 전용 불경한 두루마리는 2열에서 방어 +10%와 회복량 +33%를 주고, 받는 스트레스 +15%를 대가로 받는다. "성녀를 1·2열 서브로도 쓴다"는 방향(G-03)을 장신구로 뒷받침한 사례다.

## 2. 일반 풀의 열 조건 장신구 10개

|---|---|---|---|---|
| 분노의 두건 | 매우 희귀 | 석궁사수 | 4열 피해 +25% (약화 확률 +30%, 회복 −50%) | 주 열 강화 |
| 분노의 모자 | 매우 희귀 | 총사 | 4열 피해 +25% (약화 확률 +30%, 회복 −50%) | 주 열 강화 |
| 참회의 팔찌 | 일반 | 나병환자 | 1열 피해 +15% (의지 판정 −3%) | 주 열 강화 |

| 저격수의 반지 | 희귀 | 공용 | 4열 명중 +15, 치명타 +4 (속도 −2) | 전형 열(원거리 4열) 강화 |

## 3. 킥스타터 풀 (참고)

열 조건 장신구 82개. 대부분 공용이며, "한 열 강화 + 반대 열 페널티" 조합이다. 획득 조건을 확인하지 않아 판단에서는 뺐다.

## 4. 방향과 현실성 기준

**방향 [사용자]**: 영웅의 다른 열 활용 가능성을 키우고 실제로 가능하게 해 주는 장신구를 늘린다. 현실성이 있어야 한다.

**현실성 기준 [제안]**
1. **끼울 이유**: 같은 칸의 대안보다 서브 열에서 기대값이 높아야 한다. 대안의 예는 공용 명중 +10 장신구다. 영웅 던전의 병목이 명중이므로, 서브 열에서 명중이나 명중을 대체할 이득을 주는 것이 가장 강한 동기가 된다.
2. **운용 성립**: 장착했을 때 그 열에서 쓸 기술이 실제로 있어야 한다. 기술의 사용 열과 교차 확인하고, 기술 개편(G-03)과 짝으로 설계한다.
3. **주 열 대체 금지(P-05)**: 서브 열 보너스는 해당 열 한정으로 두고, 필요하면 주 열 페널티를 붙인다.
4. **원본 패턴 재사용**: 불경한 두루마리·수호자의 방패처럼 "영웅 전용 + 서브 열 한정 + 방어·회복 보강 + 대가" 구조를 따른다.
5. **원본 수치 범위 안에서**: 일반 풀 기준 명중 +4~15, 열 조건 피해 +15~25%, 회피 +10~20.
