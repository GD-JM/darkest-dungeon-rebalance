# WS-EDITOR-002: 배포 노트의 근거 범위

성녀 VES-018/019 배포에서 생성기가 raw diff의 WS-GALLERY-001(이전 도구 수정 기록)을 채택된 게임 변경으로 오해하고, 포함되지 않은 구현 근거를 요구해 중단했다. 게임 값과 VES-018/019 원문은 확인 가능했다.

검증된 user_intents 배열만 채택 근거로 다루도록 생성 지침을 명확히 했다. load_intents는 모든 게임 입력의 원문 포괄 검사를 유지한 뒤, 이번 배포 입력에 연결되지 않은 도구 전용 기록을 노트 생성 대상에서 제외한다. 혼합 기록은 배포 입력을 포함하면 유지한다. 기록 원본은 Git에서 삭제하지 않는다.

회귀 검사: 도구 기록은 노트 목록에서 제외되며 누락된 게임 의도를 대신 충족할 수 없다. 사용자 원문이 없는 게임 수치는 계속 거부된다. 이전 실패 결과는 job의 result-blocked-tooling-evidence.json에 보존했다. 두 번째 생성은 VES-018/019만 인용한 영어/중국어 노트를 생성했다. 게임 수치 변경 없음.
